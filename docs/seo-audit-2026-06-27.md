## The #1 systemic issue — thin prerender / CSR content gap
The prerendered HTML is a thin shell (~200 words: meta + breadcrumbs + TL;DR + CTA + footer).
The actual learning content (lessons, NCERT solutions, practice, answers) loads via React/Firestore
**after** mount. So Google and AI engines (ChatGPT/Perplexity/AI Overviews) index the scaffold, not the
substance. Three of the top-5 issues trace back to this. **Highest-leverage fix:** render key content
(chapter summaries, key facts, worked-example snippets) into the prerendered HTML.
