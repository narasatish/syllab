What is a Linear Equation in Two Variables?

  • An equation with two variables.
  • Each variable has a power of 1.
  • Example: x + y = 7.

🎙️ A linear equation in two variables is an equation where you have two different variables, and the highest power of each variable is 1. For example, if you add two numbers 'x' and 'y' and their sum is 7, that's a linear equation in two variables.

Standard Form: Ax + By + C = 0

  • A, B, C are real numbers.
  • A and B cannot both be zero.
  • x and y are the variables.

🎙️ The general or standard form of a linear equation in two variables is Ax + By + C = 0. Here, A, B, and C are constants, and 'x' and 'y' are the variables. It's crucial that A and B are not both zero, otherwise, it wouldn't be a two-variable equation.

🎙️ Let's say a notebook costs twice as much as a pen. If we let 'x' be the cost of the notebook and 'y' be the cost of the pen, we can form the equation x = 2y. This shows how LE2V helps model everyday situations.

Worked Example: Expressing in Standard Form

  • Problem: 2x = 5y - 7.
  • Rearrange terms to get Ax + By + C = 0.
  • Solution: 2x - 5y + 7 = 0.

🎙️ Let's practice converting an equation into its standard form. If you have 2x = 5y - 7, you need to bring all terms to one side, equating it to zero. By moving 5y and -7, we get 2x - 5y + 7 = 0, which is the standard form.

1Start: 2x = 5y - 7
2Move 5y: 2x - 5y = -7
3Move -7: 2x - 5y + 7 = 0

What is a Solution to a LE2V?

  • A pair of values (x, y).
  • Makes the equation true.
  • Example: For x+y=5, (2,3) is a solution.

🎙️ A solution to a linear equation in two variables is a specific pair of numbers, one for 'x' and one for 'y', that when substituted into the equation, makes both sides equal. For instance, in x + y = 5, if x=2 and y=3, then 2+3=5, so (2,3) is a solution.

Finding Solutions: Method 2 (Choosing Values)

  • Choose a value for one variable (e.g., x).
  • Solve the equation for the other variable (y).
  • Repeat to find multiple solutions.

🎙️ A more systematic way is to pick any value for one variable, say 'x', and then solve the equation to find the corresponding 'y' value. You can do this multiple times to find many different solutions for the same equation.

Worked Example: Finding 4 Solutions

  • Equation: x + y = 7.
  • If x=0, y=7. Solution: (0,7).
  • If x=1, y=6. Solution: (1,6).
  • If x=7, y=0. Solution: (7,0).
  • If x=-1, y=8. Solution: (-1,8).

🎙️ Let's find four solutions for x + y = 7. If x is 0, y must be 7. If x is 1, y is 6. If x is 7, y is 0. And if x is -1, y is 8. Notice how each pair satisfies the equation, demonstrating multiple solutions exist.

Steps to Graph a LE2V

  • 1. Find at least two solutions (x,y) for the equation.
  • 2. Plot these points on a coordinate plane.
  • 3. Draw a straight line passing through these points.
  • 4. Extend the line in both directions.

🎙️ To graph a linear equation, first find at least two solutions, as two points are enough to define a straight line. Then, plot these points on your graph paper. Finally, use a ruler to draw a straight line through these points and extend it in both directions with arrows.

Every Point on the Line is a Solution

  • Any point (x,y) lying on the line.
  • Will satisfy the equation.
  • There are infinite points on a line, hence infinite solutions.

🎙️ It's a fundamental property: if a point lies on the graph of a linear equation, its coordinates (x,y) will always make that equation true. This means every single point on that line is a valid solution to the equation.

Real-life Application: Distance and Time

  • Distance = Speed × Time (d = st).
  • If speed is constant (e.g., 60 km/h): d = 60t.
  • This is a LE2V (d - 60t = 0).

🎙️ Consider a car traveling at a constant speed of 60 km/h. The distance covered (d) is 60 times the time taken (t). So, d = 60t. This is a linear equation in two variables, d and t, which can be written as d - 60t = 0.

Quick Check 3: Which Point is NOT a Solution?

  • Equation: 2x + y = 6.
  • Test (1,4): 2(1)+4=6. Yes.
  • Test (3,0): 2(3)+0=6. Yes.
  • Test (2,1): 2(2)+1=5. No, this is not 6.

🎙️ For the equation 2x + y = 6, let's see which point does not satisfy it. (1,4) works: 2(1)+4=6. (3,0) works: 2(3)+0=6. But for (2,1), 2(2)+1 equals 5, not 6. So, (2,1) is not a solution and would not lie on the line.

Recap: Key Takeaways

  • LE2V has two variables, each with power 1.
  • Standard form: Ax + By + C = 0.
  • Has infinitely many solutions.
  • Its graph is always a straight line.

🎙️ To summarize, linear equations in two variables are powerful tools for modeling situations with two unknowns. They have a standard form, possess an infinite number of solutions, and when graphed, these solutions always align to form a straight line.
