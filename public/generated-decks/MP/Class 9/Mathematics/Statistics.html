What is Frequency?

  • The number of times a particular observation occurs.
  • How often a specific value appears in a dataset.

🎙️ If five students in your class say their favorite fruit is 'apple', then the frequency of 'apple' as a favorite fruit is 5. It simply tells us how often something shows up in our data.

Grouped Frequency Distribution

  • Used when data is very large.
  • Observations are grouped into intervals or classes.
  • Helps manage and present vast amounts of data.

🎙️ Imagine you have the heights of all 500 students in your school. Listing each individual height would make a very long and confusing table. Grouping heights into ranges, like 140-150 cm, makes it much more manageable.

Class Interval

  • A range of values within which observations fall.
  • For example, 0-10, 10-20, 20-30.
  • Each group in a grouped frequency distribution.

🎙️ A class interval defines the boundaries for a group of data points. If we're looking at marks, a class interval of '0-10' means all students who scored between 0 and 10 marks are in this group.

↔️
Data Range
11 / 25

Upper and Lower Limits

  • Lower limit: The smallest value in a class interval.
  • Upper limit: The largest value in a class interval.
  • For 10-20, 10 is the lower limit and 20 is the upper limit.

🎙️ These limits clearly define where a class interval starts and ends. It's important to be careful with overlapping intervals, usually the upper limit is exclusive (e.g., 10-20 means up to but not including 20, then next interval starts at 20).

⬆️⬇️
Boundaries
12 / 25

Class Size or Width

  • The difference between the upper and lower class limits.
  • Also called class length.
  • For 10-20, the class size is 20 - 10 = 10.

🎙️ The class size tells us how wide each group or interval is. Keeping the class size consistent across all intervals helps in fair comparison and makes the data easier to understand.

Bar Graphs

  • Used for categorical data (e.g., favorite colors, types of fruits).
  • Bars are of uniform width.
  • Gaps between bars indicate distinct categories.

🎙️ Bar graphs are great for showing comparisons between different, separate items. Each bar represents a category, and its height shows the frequency or quantity for that category.

Histograms

  • Used for grouped frequency distributions (continuous data).
  • Bars are adjacent (no gaps).
  • Width of bars represents class interval, height represents frequency.

🎙️ Unlike bar graphs, histograms show continuous data, so the bars touch each other. This shows that the data is continuous and there are no gaps in the values. It’s perfect for data like heights or ages grouped into ranges.

Frequency Polygon

  • Another way to represent grouped frequency distribution.
  • Points are plotted at the class marks (midpoints) of each interval.
  • These points are then joined by line segments.

🎙️ A frequency polygon gives a good visual representation of the shape of the distribution. It's often used to compare two or more frequency distributions on the same graph.

📉
Line Graph of Frequencies
22 / 25

Example: Daily Temperatures

  • Plot midpoints of temperature ranges against their frequencies.
  • Join the points with straight lines.
  • Often closed by connecting to an imaginary class before and after.

🎙️ If you have temperature ranges like 20-25°C, 25-30°C, you'd find the midpoints (22.5, 27.5) and plot the frequency for each. Connecting these points gives you the frequency polygon.
