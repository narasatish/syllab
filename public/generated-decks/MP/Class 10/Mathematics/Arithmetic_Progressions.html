What is a Sequence?

  • An ordered list of numbers.
  • Each number is called a term.
  • Terms follow a specific rule or pattern.

🎙️ A sequence is simply a list of numbers arranged in a particular order. Think of it like a train, where each compartment is a term, and they follow each other in a set way.

What is an Arithmetic Progression (AP)?

  • A sequence where the difference between consecutive terms is constant.
  • This constant difference is called the 'common difference'.
  • It's like climbing stairs with equal steps.

🎙️ An Arithmetic Progression, or AP, is a special kind of sequence. The key idea is that if you subtract any term from its next term, you always get the same number.

Understanding the Common Difference (d)

  • The constant difference between any two consecutive terms.
  • Found by subtracting a term from its succeeding term (a₂ - a₁).
  • Can be positive, negative, or zero.

🎙️ This 'constant difference' is super important and we call it the 'common difference', denoted by 'd'. Remember, you always subtract the previous term from the current term to find 'd'.

Is this an AP? Example 1

  • Sequence: 2, 4, 6, 8, ...
  • Step 1: Find a₂ - a₁
  • Step 2: Find a₃ - a₂
  • Step 3: Check if differences are equal.

🎙️ Let's check if the sequence 2, 4, 6, 8 is an AP. We calculate the difference between consecutive terms. Since the difference is constant, it is indeed an AP.

14 - 2 = 2
26 - 4 = 2
38 - 6 = 2
4Yes, it's an AP!

The General Form of an AP

  • If 'a' is the first term and 'd' is the common difference:
  • The AP can be written as: a, a+d, a+2d, a+3d, ...
  • Each term is found by adding 'd' to the previous term.

🎙️ We can write any AP using its first term 'a' and common difference 'd'. This general form helps us understand the structure of an AP and predict its terms.

Finding the nth Term (aₙ)

  • The formula for the nth term is: aₙ = a + (n-1)d
  • Where 'a' is the first term.
  • 'd' is the common difference.
  • 'n' is the term number you want to find.

🎙️ This formula is very powerful! It allows us to find any term in an AP without having to list all the terms before it. Just plug in the first term, common difference, and the term number.

🔍
Term Finder

Worked Example: Find the 10th Term

  • AP: 2, 7, 12, ...
  • Here, a = 2, d = 7 - 2 = 5
  • We need to find the 10th term, so n = 10.
  • Using aₙ = a + (n-1)d

🎙️ Let's apply the formula. For the AP 2, 7, 12, the first term is 2 and the common difference is 5. We substitute these values into the formula to find the 10th term.

1a₁₀ = 2 + (10-1)5
2a₁₀ = 2 + 9 * 5
3a₁₀ = 2 + 45
4a₁₀ = 47

Worked Example: Which Term is -81?

  • AP: 21, 18, 15, ...
  • Here, a = 21, d = 18 - 21 = -3
  • We are given aₙ = -81. We need to find 'n'.
  • Using aₙ = a + (n-1)d

🎙️ Sometimes, we know the value of a term but need to find its position 'n'. This example shows how to use the same formula but solve for 'n' instead of aₙ. Be careful with negative numbers!

1-81 = 21 + (n-1)(-3)
2-81 - 21 = (n-1)(-3)
3-102 = -3(n-1)
434 = n-1 => n = 35

Sum of First n Terms (Sₙ)

  • Sometimes we need to find the sum of all terms up to a certain point.
  • Formula: Sₙ = n/2 [2a + (n-1)d]
  • Where 'n' is the number of terms, 'a' is the first term, 'd' is the common difference.

🎙️ Just as we found individual terms, we can also find the sum of a certain number of terms in an AP. This formula is very useful for adding up many numbers quickly.

Total Sum

Alternative Sum Formula for Sₙ

  • If the last term (aₙ or l) is known:
  • Sₙ = n/2 [a + aₙ]
  • This formula is often simpler when the last term is given.

🎙️ There's a simpler version of the sum formula if you already know the last term of the AP. It saves you a step by directly using the first and last terms.

Worked Example: Sum of First 20 Terms

  • AP: 1, 3, 5, ...
  • Find the sum of the first 20 terms.
  • Here, a = 1, d = 2, n = 20.
  • Using Sₙ = n/2 [2a + (n-1)d]

🎙️ Let's calculate the sum of the first 20 terms of this AP. We identify 'a', 'd', and 'n', then substitute them into the formula for Sₙ. Follow the order of operations carefully.

1S₂₀ = 20/2 [2(1) + (20-1)2]
2S₂₀ = 10 [2 + 19 * 2]
3S₂₀ = 10 [2 + 38]
4S₂₀ = 10 * 40 = 400

Worked Example: Sum of AP up to 84

  • AP: 7, 10.5, 14, ..., 84
  • Here, a = 7, d = 3.5, aₙ = 84.
  • First, find 'n' using aₙ = a + (n-1)d.
  • Then, use Sₙ = n/2 [a + aₙ].

🎙️ This problem requires two steps. First, we need to find out how many terms are in the AP up to 84. Once we have 'n', we can use the simpler sum formula with the first and last terms.

184 = 7 + (n-1)3.5 => n=23
2S₂₃ = 23/2 [7 + 84]
3S₂₃ = 23/2 * 91
4S₂₃ = 1046.5

Chapter Recap: Arithmetic Progressions

  • An AP has a constant common difference (d).
  • General form: a, a+d, a+2d, ...
  • nth term: aₙ = a + (n-1)d
  • Sum of n terms: Sₙ = n/2 [2a + (n-1)d] or Sₙ = n/2 [a + aₙ]

🎙️ Let's quickly review what we've covered. Remember the definition of an AP, how to find its terms, and how to calculate the sum of its terms. These are the core concepts.
