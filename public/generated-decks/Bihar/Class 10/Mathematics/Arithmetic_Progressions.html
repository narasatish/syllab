What is an Arithmetic Progression?

  • A sequence where the difference between consecutive terms is constant.
  • This constant difference is called the 'common difference' (d).
  • Each term is obtained by adding 'd' to the previous term.

🎙️ An Arithmetic Progression, or AP, is a special kind of sequence. The main feature is that if you pick any two consecutive numbers, their difference is always the same. We call this special difference the 'common difference'.

Checking if a Sequence is an AP

  • Subtract any term from its succeeding term.
  • If the difference is the same for all pairs, it's an AP.
  • This constant difference is 'd'.

🎙️ To check if a given list of numbers is an AP, you simply need to find the difference between consecutive terms. If a2 - a1, a3 - a2, a4 - a3, and so on, are all the same value, then congratulations, you have an AP!

1Term 2 - Term 1
2Term 3 - Term 2
3Term 4 - Term 3
4Are they equal?
7 / 25

Example: Is 2, 5, 8, 11... an AP?

  • a2 - a1 = 5 - 2 = 3
  • a3 - a2 = 8 - 5 = 3
  • a4 - a3 = 11 - 8 = 3
  • Yes, it is an AP with common difference d = 3.

🎙️ Let's apply our rule. For the sequence 2, 5, 8, 11..., we calculate the differences. We find that the difference is 3 every time. Since the common difference is constant, this sequence is indeed an Arithmetic Progression.

The General Form of an AP

  • If 'a' is the first term and 'd' is the common difference, then the AP is:
  • a, a + d, a + 2d, a + 3d, ..., a + (n-1)d, ...

🎙️ We can write any AP using its first term, 'a', and its common difference, 'd'. The first term is 'a', the second is 'a+d', the third is 'a+2d', and so on. This pattern helps us understand how an AP grows.

Constructing an AP

  • Given: First term (a) = 5, Common difference (d) = 3
  • AP: 5, (5+3), (5+2*3), (5+3*3)...
  • AP: 5, 8, 11, 14...

🎙️ Let's say we know the first term is 5 and the common difference is 3. We can easily build the AP. The terms would be 5, then 5+3=8, then 8+3=11, and so on. It's like building a tower, brick by brick.

Finding the 'nth' Term of an AP

  • We need a formula to find any specific term (e.g., the 10th, 50th term) without listing them all.
  • The formula is: an = a + (n-1)d, where 'an' is the nth term.

🎙️ What if we need to find the 100th term of an AP? Listing all 99 terms before it would be very time-consuming. Luckily, there's a powerful formula that helps us jump directly to any term we want.

🔍
Specific Term

Breaking Down the 'nth' Term Formula

  • 'a' is the first term, 'd' is the common difference, 'n' is the term number we want to find (e.g., 5th, 10th).
  • (n-1) means we add 'd' (n-1) times to the first term.

🎙️ Let's understand why the formula an = a + (n-1)d works. For the 1st term, n=1, so (1-1)d=0, giving 'a'. For the 2nd term, n=2, so (2-1)d=d, giving 'a+d'. It perfectly matches our general form!

1Start with 'a'
2Add 'd' for 2nd term
3Add 'd' twice for 3rd term
4Add 'd' (n-1) times for 'nth' term
12 / 25

Example: Find the 10th term of AP: 2, 7, 12...

  • Here, a = 2, d = 7 - 2 = 5, n = 10
  • Using an = a + (n-1)d
  • a10 = 2 + (10-1)5 = 2 + 9*5 = 2 + 45 = 47.

🎙️ In this AP, the first term 'a' is 2, and the common difference 'd' is 5. We want the 10th term, so 'n' is 10. Plugging these values into the formula gives us 2 + (9 * 5), which simplifies to 47. So, the 10th term is 47.

Saving Money: An AP Example

  • A person saves ₹100 in the first month, ₹150 in the second, ₹200 in the third, and so on.
  • How much will they save in the 12th month?
  • Here, a=100, d=50, n=12. a12 = 100 + (12-1)50 = ₹650.

🎙️ This is a great real-world use of APs. Each month, the person saves an additional ₹50. To find out how much they save in the 12th month, we use the nth term formula, treating the monthly savings as terms in our AP.

Sum of the First 'n' Terms (Sn)

  • Sometimes we need to add up all the terms in an AP up to a certain point.
  • Example: Total savings over 12 months.
  • The formula is: Sn = n/2 [2a + (n-1)d]

🎙️ Just like finding a specific term, we also have a formula to find the sum of a certain number of terms in an AP. This is incredibly useful for calculating totals quickly, like total interest earned or total distance covered.

Another Way to Calculate the Sum

  • Since an = a + (n-1)d, we can rewrite the sum formula.
  • Sn = n/2 [a + {a + (n-1)d}]
  • Sn = n/2 [a + l], where 'l' is the last term (an).

🎙️ This second formula is very handy when you already know the first term 'a', the last term 'l' (or 'an'), and the number of terms 'n'. It saves a step of calculation compared to the first formula.

1Sn = n/2 [a + a + (n-1)d]
2Sn = n/2 [a + an]
3Sn = n/2 [a + l]
20 / 25

Example: Sum of First 10 Terms of 2, 7, 12...

  • Here, a = 2, d = 5, n = 10
  • Using Sn = n/2 [2a + (n-1)d]
  • S10 = 10/2 [2*2 + (10-1)5] = 5 [4 + 9*5] = 5 [4 + 45] = 5 * 49 = 245.

🎙️ Let's find the sum of the first 10 terms for our earlier AP. We have 'a'=2, 'd'=5, and 'n'=10. Substituting these values into the sum formula, we get 5 times (4 plus 45), which simplifies to 245.

Building Blocks: Sum of Terms

  • A stack of logs has 20 logs in the bottom row, 19 in the next, and so on, up to 1 log at the top.
  • How many logs are there in total if there are 20 rows?
  • This is an AP: 20, 19, ..., 1. Here, a=20, d=-1, l=1, n=20. S20 = 20/2 (20+1) = 10 * 21 = 210 logs.

🎙️ This is a classic example. The number of logs in each row forms an AP. Since we know the first term, the last term, and the number of rows, we can easily find the total number of logs using the sum formula.

Example: Sum of Multiples

  • Find the sum of the first 15 multiples of 8.
  • The AP is: 8, 16, 24, ..., (8*15=120).
  • Here, a=8, d=8, n=15, l=120. S15 = 15/2 (8 + 120) = 15/2 * 128 = 15 * 64 = 960.

🎙️ Multiples of a number always form an AP! Here, the first term is 8, and the common difference is also 8. We need the sum of the first 15 terms. Using the formula with 'a', 'l', and 'n' makes this calculation very efficient.

Key Takeaways from APs

  • An AP has a constant common difference (d).
  • General form: a, a+d, a+2d...
  • nth Term: an = a + (n-1)d
  • Sum of n terms: Sn = n/2 [2a + (n-1)d] or Sn = n/2 [a + l]

🎙️ We've covered the core concepts of Arithmetic Progressions today. Remember the definition, the general form, and especially the two main formulas for the nth term and the sum of n terms. These are your tools!
