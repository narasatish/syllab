What is a Linear Equation?

  • An equation with the highest power of the variable as 1.
  • Its graph is always a straight line.
  • Example: x + 5 = 10 (here 'x' is the variable).

🎙️ First, let's quickly recall what a linear equation is. It's an equation where the highest power of any variable is one. When you plot a linear equation on a graph, it always forms a straight line, which is why it's called 'linear'.

Linear Equation in Two Variables

  • An equation with two variables (usually 'x' and 'y').
  • Each variable has a power of 1.
  • General form: ax + by + c = 0 (where a, b, c are real numbers, a ≠ 0, b ≠ 0).
  • Example: 2x + 3y = 7.

🎙️ Now, let's add another variable! A linear equation in two variables means we have two unknown quantities, typically represented by 'x' and 'y'. The general form helps us understand its structure, where 'a' and 'b' cannot be zero, otherwise it would become a single variable equation.

What is a Pair of Linear Equations?

  • Two linear equations involving the same two variables.
  • We look for values of x and y that satisfy BOTH equations simultaneously.
  • General form: a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0.

🎙️ When we have two such linear equations together, they form a 'pair'. Our goal is often to find a solution, which means finding values for 'x' and 'y' that make both equations true at the same time. Think of it as solving two puzzles at once!

  • Solving problems with two unknown quantities.

Methods to Solve: Graphical Method

  • Each equation represents a straight line.
  • The solution is the point where the lines intersect.
  • We plot both lines on the same coordinate plane.

🎙️ There are two main ways to solve a pair of linear equations: graphically and algebraically. We'll start with the graphical method. In this method, we visualize each equation as a line on a graph. The point where these lines meet, if they do, is our solution.

📊
Plotting Lines

Graphical Method: Case 1 - Intersecting Lines

  • The two lines cross each other at exactly one point.
  • This point is the unique solution to the pair of equations.
  • It means there is exactly ONE value for x and ONE for y that satisfies both equations.

🎙️ Our first case is when the two lines intersect. This is the most common scenario. When the lines cross at a single point, that specific point (x, y) is the only solution that works for both equations. We call this a 'unique solution'.

✖️
One Solution
8 / 25

Example: Intersecting Lines

  • Equations: x + y = 5 and x - y = 1.
  • Plot points for each equation.
  • Line 1 (x+y=5): (0,5), (5,0), (2,3)
  • Line 2 (x-y=1): (0,-1), (1,0), (3,2)
  • Intersection point: (3, 2). So, x=3, y=2 is the solution.

🎙️ Let's work through an example. For x + y = 5, if x is 0, y is 5, and if y is 0, x is 5. For x - y = 1, if x is 0, y is -1, and if y is 0, x is 1. Plotting these lines carefully reveals they cross at the point (3, 2). This means x=3 and y=2 is the unique solution.

Graphical Method: Case 2 - Parallel Lines

  • The two lines never intersect; they run side-by-side.
  • This means there is NO common point.
  • Therefore, there is NO solution to the pair of equations.

🎙️ The second case is when the lines are parallel. Just like railway tracks, parallel lines never meet, no matter how far they extend. If there's no common point, it means there's no pair of (x, y) values that can satisfy both equations at once. Hence, there is no solution.

No Solution

Example: Parallel Lines

  • Equations: x + 2y = 4 and 2x + 4y = 12.
  • Plot points for each equation.
  • Line 1 (x+2y=4): (0,2), (4,0)
  • Line 2 (2x+4y=12): (0,3), (6,0)
  • When plotted, these lines will be parallel and never meet. No solution.

🎙️ Consider these two equations. If you plot points for x + 2y = 4, you get points like (0,2) and (4,0). For 2x + 4y = 12, you get points like (0,3) and (6,0). If you draw these lines, you will observe they are parallel and will never intersect, confirming there is no solution.

Graphical Method: Case 3 - Coincident Lines

  • The two lines are exactly the same; one lies directly on top of the other.
  • Every point on the first line is also on the second line.
  • This means there are INFINITELY MANY solutions.

🎙️ Our third and final case for the graphical method is when the lines are coincident. This means they are essentially the same line. Since every point on one line is also on the other, there are infinitely many points of intersection. Therefore, there are infinitely many solutions.

♾️
Infinite Solutions

Example: Coincident Lines

  • Equations: x + y = 3 and 2x + 2y = 6.
  • Plot points for each equation.
  • Line 1 (x+y=3): (0,3), (3,0)
  • Line 2 (2x+2y=6): (0,3), (3,0)
  • Both equations represent the exact same line. Infinitely many solutions.

🎙️ Let's look at this example. For x + y = 3, we can find points (0,3) and (3,0). Now, for 2x + 2y = 6, if you divide the entire equation by 2, you get x + y = 3, which is identical to the first equation. This means both equations represent the same line, leading to infinitely many solutions.

Methods to Solve: Algebraic Methods

  • These methods involve manipulating equations using algebra.
  • They provide exact solutions, unlike graphical method which can be approximate.
  • Three main methods: Substitution, Elimination, Cross-Multiplication.

🎙️ While the graphical method gives us a visual understanding, algebraic methods are more precise and often faster for finding exact solutions. We will learn three powerful algebraic techniques: Substitution, Elimination, and Cross-Multiplication. Each has its own way of simplifying the problem.

Algebraic Method 1: Substitution Method

  • Step 1: Express one variable in terms of the other from one equation.
  • Step 2: Substitute this expression into the second equation.
  • Step 3: Solve the resulting single-variable equation.
  • Step 4: Substitute the found value back into the expression from Step 1 to find the other variable.

🎙️ The substitution method is like replacing one piece of information with another. You pick one equation, isolate one variable, and then 'substitute' that expression into the other equation. This reduces the problem to a single-variable equation, which is easier to solve.

1Isolate a Variable
2Substitute
3Solve for One Variable
4Find the Other Variable
16 / 25

Example: Substitution Method

  • Equations: x + y = 14 (1) and x - y = 4 (2).
  • From (1): x = 14 - y.
  • Substitute x in (2): (14 - y) - y = 4.
  • Solve: 14 - 2y = 4 => 2y = 10 => y = 5.
  • Substitute y=5 back into x = 14 - y: x = 14 - 5 => x = 9. Solution: (9, 5).

🎙️ Let's apply the substitution method. From the first equation, we can easily say x equals 14 minus y. Now, wherever we see 'x' in the second equation, we replace it with '14 - y'. This gives us an equation with only 'y', which we can solve. Once we have 'y', finding 'x' is simple!

17 / 25

Algebraic Method 2: Elimination Method

  • Step 1: Multiply equations by suitable numbers to make coefficients of one variable equal.
  • Step 2: Add or subtract the equations to eliminate that variable.
  • Step 3: Solve the resulting single-variable equation.
  • Step 4: Substitute the found value into one of the original equations to find the other variable.

🎙️ The elimination method aims to 'eliminate' one variable by making its coefficients the same in both equations, then adding or subtracting the equations. This way, one variable disappears, and we are left with a simpler equation to solve. It's often very efficient.

1Make Coefficients Equal
2Add/Subtract Equations
3Solve for One Variable
4Find the Other Variable
18 / 25

Example: Elimination Method

  • Equations: 2x + 3y = 8 (1) and 3x + y = 5 (2).
  • Multiply (2) by 3: 9x + 3y = 15 (3).
  • Subtract (1) from (3): (9x + 3y) - (2x + 3y) = 15 - 8.
  • Solve: 7x = 7 => x = 1.
  • Substitute x=1 into (2): 3(1) + y = 5 => 3 + y = 5 => y = 2. Solution: (1, 2).

🎙️ Let's use elimination. Notice that the 'y' coefficient in the first equation is 3, and in the second, it's 1. If we multiply the second equation by 3, the 'y' coefficients will match. Then, by subtracting the equations, the 'y' terms cancel out, leaving us with only 'x' to solve.

Algebraic Method 3: Cross-Multiplication Method

  • Step 1: Write equations in standard form: a₁x + b₁y + c₁ = 0, a₂x + b₂y + c₂ = 0.
  • Step 2: Use the cross-multiplication formula: x / (b₁c₂ - b₂c₁) = y / (c₁a₂ - c₂a₁) = 1 / (a₁b₂ - a₂b₁).
  • Step 3: Equate each part to find x and y.

🎙️ The cross-multiplication method is a formula-based approach. It looks a bit complex initially, but once you understand the pattern for coefficients, it becomes straightforward. Remember to arrange your equations in the standard form with zero on one side before applying the formula.

1Standard Form
2Apply Formula
3Calculate x and y
20 / 25

Example: Cross-Multiplication Method

  • Equations: 2x + y = 5 => 2x + y - 5 = 0 (1)
  • x + 2y = 4 => x + 2y - 4 = 0 (2)
  • Here, a₁=2, b₁=1, c₁=-5 and a₂=1, b₂=2, c₂=-4.
  • x / (1(-4) - 2(-5)) = y / ((-5)(1) - (-4)(2)) = 1 / (2(2) - 1(1))
  • x / (-4 + 10) = y / (-5 + 8) = 1 / (4 - 1)
  • x / 6 = y / 3 = 1 / 3. So, x = 6/3 = 2, y = 3/3 = 1. Solution: (2, 1).

🎙️ Let's apply the cross-multiplication formula to this example. First, make sure both equations are set to zero. Then, carefully identify a₁, b₁, c₁, a₂, b₂, c₂. Plug these values into the formula and solve for x and y. Pay close attention to the signs while calculating.

Solving the Real-Life Problem

  • Let the two numbers be x and y.
  • Equation 1: x + y = 20 (Sum is 20)
  • Equation 2: x - y = 4 (Difference is 4)
  • Using Elimination: (x + y) + (x - y) = 20 + 4 => 2x = 24 => x = 12.
  • Substitute x=12 into x + y = 20 => 12 + y = 20 => y = 8.
  • The two numbers are 12 and 8.

🎙️ By setting up the equations x + y = 20 and x - y = 4, we can easily solve this using the elimination method. Adding the two equations eliminates 'y', giving us 'x'. Once 'x' is found, we substitute it back into either original equation to find 'y'. Simple, right?
