What is an Equation?

  • A statement that two mathematical expressions are equal.
  • Always contains an '=' sign.
  • Example: x + 5 = 10

🎙️ Remember, an equation is like a balanced scale. Whatever is on one side must be equal to what's on the other. It helps us find unknown values.

Recap: Linear Equation in One Variable

  • An equation with only one unknown value.
  • The highest power of the variable is 1.
  • Example: 2x + 3 = 7

🎙️ We've already mastered equations like 2x + 3 = 7. Here, 'x' is our single variable, and its power is 1, making it a linear equation.

Definition: Linear Equation in Two Variables

  • An equation with two variables.
  • Each variable has a power of 1.
  • Example: x + y = 10

🎙️ So, a linear equation in two variables is simply an equation where we have two different unknown letters, and neither of them is raised to a power greater than one.

The Standard Form: ax + by + c = 0

  • Most common way to write these equations.
  • ax + by + c = 0
  • a, b, c are real numbers, and a ≠ 0, b ≠ 0.

🎙️ Just like we have a standard way to write numbers, equations also have a standard form. This helps us easily identify 'a', 'b', and 'c' for any given equation.

What is a Solution to the Equation?

  • A pair of values (x, y) that satisfies the equation.
  • When substituted, makes the Left Hand Side (LHS) equal to the Right Hand Side (RHS).
  • Example: For x+y=5, (2,3) is a solution.

🎙️ A solution is like finding the correct key that perfectly fits the lock. It's the specific pair of 'x' and 'y' values that makes the equation true.

✅
Correct Pair

Finding Solutions: Substitution Method

  • Choose a value for one variable (e.g., x).
  • Substitute it into the equation.
  • Solve for the other variable (y).
  • Repeat to find more solutions.

🎙️ This is one way to find solutions. You can pick any number for 'x' or 'y', put it into the equation, and then calculate what the other variable must be.

1Pick x-value
2Substitute into equation
3Solve for y
4Write (x,y) pair
12 / 25

Worked Example: Find Solutions

  • Equation: x + y = 7
  • If x = 1, then 1 + y = 7 => y = 6. Solution: (1, 6)
  • If x = 0, then 0 + y = 7 => y = 7. Solution: (0, 7)
  • If y = 3, then x + 3 = 7 => x = 4. Solution: (4, 3)

🎙️ See how by choosing different values for 'x' or 'y', we get different pairs that still satisfy the equation? Try finding one more solution on your own!

How Many Solutions? Infinite!

  • A linear equation in two variables has infinitely many solutions.
  • You can choose any real number for one variable.
  • This will always give a corresponding real number for the other variable.

🎙️ This is a key difference from linear equations in one variable, which usually have only one solution. Here, because we can pick any value for x or y, there are endless possibilities!

Visualizing Solutions: Graphing!

  • Each solution (x, y) represents a point on a coordinate plane.
  • When plotted, all solutions of a linear equation lie on a straight line.
  • This is why it's called 'linear' equation!

🎙️ The beauty of linear equations is that their solutions, when drawn on a graph, form a straight line. This gives us a visual representation of all possible solutions.

📈
Plotting Points
15 / 25

Steps to Graph an Equation

  • 1. Find at least two solutions (x, y) for the equation.
  • 2. Plot these points on the Cartesian plane.
  • 3. Draw a straight line passing through these points.
  • 4. Extend the line in both directions.

🎙️ Remember, you only need two points to define a straight line. However, finding a third point can help you check for accuracy.

1Find 2+ solutions
2Plot points
3Draw line
4Extend line

Worked Example: Graphing x + y = 5

  • Solutions found: (0, 5), (5, 0), (2, 3)
  • Plot (0,5) on Y-axis.
  • Plot (5,0) on X-axis.
  • Plot (2,3) in the first quadrant. Draw line.

🎙️ After plotting these three points, you'll see they all fall on the same straight line. Use a ruler to connect them and extend the line with arrows.

Special Cases: Lines Parallel to Axes

  • Equation x = a: A line parallel to the Y-axis.
  • Equation y = b: A line parallel to the X-axis.
  • These can be written in ax + by + c = 0 form (e.g., x - a = 0 or y - b = 0).

🎙️ Even though they seem to have only one variable, they are still considered linear equations in two variables. For example, x = 3 can be written as 1x + 0y - 3 = 0.

x = 3 (vertical)
y = 2 (horizontal)
