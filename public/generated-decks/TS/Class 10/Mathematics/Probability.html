Key Terms: Experiment, Outcome, Event

  • Experiment: A process with well-defined results
  • Outcome: A possible result of an experiment
  • Event: A collection of one or more outcomes

🎙️ Let's define some important words. An experiment is like tossing a coin. An outcome is what happens, like 'heads'. An event is a specific result we are interested in, like 'getting heads'.

Key Terms: Sample Space

  • Set of all possible outcomes of an experiment
  • Represented by 'S'
  • Crucial for calculating probability

🎙️ The sample space is like a complete list of everything that *could* happen. For example, if you roll a die, the sample space is {1, 2, 3, 4, 5, 6}. It's the universe of our experiment.

Formula for Probability P(E)

  • P(E) = (Number of Favorable Outcomes) / (Total Number of Outcomes)
  • P(E) is the probability of an Event E
  • Favorable outcomes are what we want to happen

🎙️ This is the most important formula! To find the probability of an event, you divide the number of ways that event can happen by the total number of possible outcomes in the sample space.

Properties of Probability: Range

  • Probability always lies between 0 and 1 (inclusive)
  • 0 ≤ P(E) ≤ 1
  • A probability cannot be negative or greater than 1

🎙️ Remember, probability is a fraction or a decimal between 0 and 1. If you calculate a probability that's negative or more than 1, you know you've made a mistake!

Properties of Probability: Sure Event & Impossible Event

  • Sure Event: Probability is 1 (certain to happen)
  • Impossible Event: Probability is 0 (cannot happen)
  • Example: Sun rising in the East is a sure event

🎙️ If an event is absolutely certain to happen, its probability is 1. For instance, the sun rising from the east. If an event can never happen, its probability is 0, like rolling a 7 on a standard die.

Properties of Probability: Complementary Events

  • Two events are complementary if one happens ONLY if the other doesn't
  • P(E) + P(not E) = 1
  • P(not E) is also written as P(E̅)

🎙️ Complementary events cover all possibilities. For example, if the probability of rain is 0.3, then the probability of *no* rain is 1 - 0.3 = 0.7. They always add up to 1.

Worked Example: Coin Toss Probability

  • What is the probability of getting a 'Head'?
  • Sample Space (S) = {H, T}, Total Outcomes = 2
  • Favorable Outcome (E): {H}, Number of Favorable Outcomes = 1

🎙️ Let's apply the formula. For getting a head, there's 1 favorable outcome (H) out of 2 total outcomes (H, T). So, P(Head) = 1/2. Simple, right?

Worked Example: Bag of Balls

  • A bag contains 3 red, 4 blue, and 5 green balls. What is P(blue ball)?
  • Total Outcomes = 3 + 4 + 5 = 12 balls
  • Favorable Outcomes = 4 (blue balls)

🎙️ First, find the total number of balls in the bag, which is 12. Then, identify how many are blue, which is 4. So, P(blue ball) = 4/12, simplifying to 1/3.
