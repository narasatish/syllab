What is a Set?

  • A well-defined collection of distinct objects.
  • Objects are called elements or members.
  • Order of elements does not matter.

🎙️ Think of a set as a special kind of box where you put specific items. The key is 'well-defined' – everyone must agree on what belongs and what doesn't.

Real-life Example of a Set

  • Collection of all books in your school library.
  • Collection of all vowels in the English alphabet: {a, e, i, o, u}.
  • Collection of all even numbers less than 10: {2, 4, 6, 8}.

🎙️ Imagine collecting all the pens on your desk. That's a set! Or the set of all students in our Class 10. Each item in the collection is an element.

Elements of a Set

  • Individual objects within a set.
  • Represented by lowercase letters (a, b, c...).

🎙️ If you have a set of fruits {apple, banana, cherry}, then apple, banana, and cherry are the elements of that set. We use a special symbol '∈' to show an element belongs to a set.

Notation of a Set: Roster Form (Tabular Form)

  • List all elements, separated by commas.
  • Enclose elements within curly braces { }.
  • Example: Set of prime numbers less than 10 is {2, 3, 5, 7}.

🎙️ This is like making a grocery list for your set. You just write down everything that's inside, one by one, and put it all in a basket, which are our curly braces.

1List all elements
2Separate with commas
3Use curly braces { }
6 / 25

Notation of a Set: Set-Builder Form (Rule Method)

  • Describe the common property of all elements.
  • Format: {x : P(x)} where P(x) is the property.
  • Example: {x : x is a prime number less than 10}.

🎙️ Instead of listing everything, you describe the rule that all elements must follow to be part of the set. It's like giving a recipe rather than the finished dish.

1Define variable (x)
2Add colon ( : ) or vertical bar ( | )
3State property P(x)
4Use curly braces { }

Example: Roster vs Set-Builder Form

  • Set A = {1, 2, 3, 4, 5}
  • Set B = {x : x is a natural number and 1 ≤ x ≤ 5}

🎙️ Notice how both forms represent the exact same set. Roster form is direct, while Set-Builder form is more descriptive, especially useful for very large or infinite sets.

Types of Sets - Empty Set (Null Set or Void Set)

  • A set containing no elements.
  • Denoted by {} or ∅ (phi).
  • Example: Set of even prime numbers greater than 2 is {}.

🎙️ Imagine an empty basket. That's what an empty set is – a set with absolutely nothing in it. It's still a valid set, just an empty one.

∅
Nothing inside

Example: Empty Set

  • Set of students in Class 10 who are 2 years old.
  • Set of months with 32 days.
  • Set of triangles with four sides.

🎙️ Can you think of any student in our class who is 2 years old? No, right? So, the set of such students is an empty set. It's a set that cannot have any members.

Types of Sets - Finite Set

  • A set with a definite, countable number of elements.
  • The process of counting elements comes to an end.
  • Example: Set of days in a week: {Monday, ..., Sunday}.

🎙️ If you can count all the elements in a set and eventually finish counting, then it's a finite set. Like counting the number of fingers on your hand – you'll eventually stop at ten.

🛑
Countable limit

Types of Sets - Infinite Set

  • A set with an unlimited number of elements.
  • The process of counting elements never ends.
  • Example: Set of natural numbers: {1, 2, 3, ...}.

🎙️ An infinite set is like counting stars in the sky – you can keep counting forever and never reach the end. There are always more elements.

♾️
Never-ending

  • Infinite: Set of all points on a line.

Types of Sets - Equal Sets

  • Two sets A and B are equal if they have exactly the same elements.
  • Order of elements does not matter.
  • Example: A = {1, 2, 3}, B = {3, 1, 2}. Then A = B.

🎙️ Think of two identical baskets, even if the items inside are arranged differently, if they contain the exact same items, the baskets are equal.

⚖️
Perfectly balanced

Types of Sets - Equivalent Sets

  • Two finite sets A and B are equivalent if they have the same number of elements.
  • Denoted by A ≈ B.
  • Example: A = {a, b, c}, B = {1, 2, 3}. A ≈ B (both have 3 elements).

🎙️ Equivalent sets are like two different types of fruit baskets, but both have, say, five fruits each. The fruits might be different, but the *count* is the same.

🤝
Same count

Example: Equal vs Equivalent Sets

  • Set A = {red, blue}, Set B = {blue, red}. A = B (Equal).
  • Set C = {apple, banana}, Set D = {pen, pencil}. C ≈ D (Equivalent).

🎙️ Remember, all equal sets are also equivalent, but not all equivalent sets are equal. Equality is a stricter condition.

Subsets

  • Set A is a subset of Set B if every element of A is also an element of B.
  • Denoted by A ⊆ B.
  • Example: If B = {1, 2, 3, 4} and A = {1, 2}, then A ⊆ B.

🎙️ Imagine a drawer full of clothes. If you take out only shirts, the set of shirts is a subset of the set of all clothes in the drawer.

⊂
Part of a larger set

Example: Subsets

  • Set of 'red apples' is a subset of the set of 'all apples'.
  • Set of 'natural numbers' is a subset of the set of 'integers'.

🎙️ If you have a group of 6 apples, and 3 of them are red, then the set of red apples is a subset of the set of all apples. Every red apple is, indeed, an apple.

Proper Subsets and Super Sets

  • A is a proper subset of B (A ⊂ B) if A ⊆ B and A ≠ B.
  • If A ⊆ B, then B is a Super Set of A (B ⊇ A).
  • Example: If A = {1, 2} and B = {1, 2, 3}, then A is a proper subset of B.

🎙️ A proper subset means it's a subset, but it's not the *entire* set. It's strictly smaller. The set that contains the proper subset is called the super set.

Universal Set

  • The largest set relevant to a particular context or discussion.
  • All other sets under consideration are subsets of the universal set.
  • Denoted by U or ξ.
  • Example: For sets of numbers, the set of Real Numbers (R) can be a universal set.

🎙️ Think of the universe itself. In set theory, the universal set is like the 'big picture' or the 'frame' that contains all the elements we are currently interested in.

🌍
All-encompassing

Power Set

  • The set of all possible subsets of a given set A.
  • Denoted by P(A).
  • If a set A has 'n' elements, then P(A) has 2^n elements.
  • Example: If A = {1, 2}, P(A) = { {}, {1}, {2}, {1, 2} }.

🎙️ The power set is like taking a set and finding every single way you can form smaller sets from its elements, including the empty set and the set itself. It's a powerful concept!

💪
All combinations
