Mean for Ungrouped Data (Direct Method)

  • Formula: Sum of observations / Number of observations
  • Simple and direct calculation
  • Example: Marks of 5 students: 10, 15, 20, 25, 30

🎙️ For ungrouped data, it's straightforward. Just add up all the numbers and divide by how many numbers there are. For the example marks, the sum is 100 and there are 5 students, so the mean is 100/5 = 20.

1Sum all values (Σx)
2Count number of values (n)
3Mean = Σx / n
12 / 31

Mean for Grouped Data (Direct Method)

  • Use class marks (mid-points) for intervals
  • Formula: Σfᵢxᵢ / Σfᵢ
  • Multiply frequency by class mark

🎙️ When data is grouped, we don't have exact values. We assume the midpoint of each class interval, called the class mark, represents all values in that interval. Then we use the formula involving frequencies and class marks.

1Find class mark (xᵢ) for each interval
2Multiply fᵢ × xᵢ
3Sum all fᵢxᵢ (Σfᵢxᵢ)
4Sum all frequencies (Σfᵢ)
5Mean = Σfᵢxᵢ / Σfᵢ
13 / 31

Mean for Grouped Data (Assumed Mean Method)

  • Simplifies calculations for large numbers
  • Choose an assumed mean (A) from class marks
  • Formula: A + (Σfᵢdᵢ / Σfᵢ) where dᵢ = xᵢ - A

🎙️ The Assumed Mean method is a shortcut. We pick a 'guess' for the mean, usually a class mark in the middle, and then calculate how much each point 'deviates' from this guess. It makes the numbers smaller and easier to work with.

1Choose Assumed Mean (A)
2Calculate deviations (dᵢ = xᵢ - A)
3Multiply fᵢ × dᵢ
4Sum fᵢdᵢ and fᵢ
5Calculate Mean
14 / 31

Mean for Grouped Data (Step Deviation Method)

  • Further simplifies calculations
  • Useful when class sizes are equal
  • Formula: A + (Σfᵢuᵢ / Σfᵢ) × h where uᵢ = dᵢ / h

🎙️ The Step Deviation method is an even cooler trick! If all your class intervals have the same width 'h', you can divide the deviations by 'h' to get even smaller numbers, making calculations super easy. Remember 'h' is the class size.

1Choose Assumed Mean (A)
2Calculate uᵢ = (xᵢ - A) / h
3Multiply fᵢ × uᵢ
4Sum fᵢuᵢ and fᵢ
5Calculate Mean

Median: The Middle Value

  • The value exactly in the middle of sorted data
  • Like finding the middle person in a line
  • Unaffected by extreme values

🎙️ The Median is literally the middle value. If you line up all your data points from smallest to largest, the one in the very centre is the median. It's often a better representation if there are some unusually high or low values.

🎯
The Exact Middle
17 / 31

Median for Ungrouped Data

  • Step 1: Arrange data in ascending order
  • If 'n' is odd: Median = ((n+1)/2)ᵗʰ observation
  • If 'n' is even: Median = average of (n/2)ᵗʰ and ((n/2)+1)ᵗʰ observations

🎙️ The first step is crucial: always sort your data! Then, if you have an odd number of items, there's one clear middle. If you have an even number, you take the average of the two middle items.

1Arrange Data
2Count 'n'
3Find Middle Position
4Identify Median
18 / 31

Median for Grouped Data

  • Requires cumulative frequency
  • Formula: L + (((n/2) - cf) / f) × h
  • L = lower limit of median class, n = total frequency

🎙️ For grouped data, we can't find an exact middle value. Instead, we find the 'median class' – the class interval where the median lies – using cumulative frequency. Then we use a specific formula to pinpoint the median within that class.

1Calculate Cumulative Frequency
2Find n/2
3Identify Median Class
4Apply Formula

Mode for Grouped Data

  • Find the 'modal class' (class with highest frequency)
  • Formula: L + ((f₁ - f₀) / (2f₁ - f₀ - f₂)) × h
  • L = lower limit of modal class, f₁ = frequency of modal class

🎙️ Similar to the median, for grouped data, we first identify the 'modal class' – the class interval with the highest frequency. Then, we use a special formula to estimate the mode within that class, considering the frequencies of the classes before and after it.

1Identify Modal Class (highest frequency)
2Note f₀, f₁, f₂, L, h
3Apply Formula
4Calculate Mode

Relationship Between Mean, Median, and Mode

  • They are related for moderately skewed data
  • Empirical Formula: Mode ≈ 3 Median - 2 Mean
  • Helps estimate one if others are known

🎙️ These three measures of central tendency are not always independent. For data that is not perfectly symmetrical, there's an approximate relationship between them, often called the empirical formula. This can be a handy way to check your answers or estimate a missing value.

Cumulative Frequency: 'Less Than' Type

  • Counts observations 'less than' the upper class boundary
  • Starts from the first class
  • Each value adds to the previous total

🎙️ To create a 'less than' cumulative frequency table, you add up frequencies as you go. For example, 'number of students scoring less than 20 marks' would include all students from 0-10 and 10-20 marks.

1List upper limits
2Add frequencies cumulatively
3Plot points (upper limit, CF)
27 / 31

Cumulative Frequency: 'More Than' Type

  • Counts observations 'more than or equal to' the lower class boundary
  • Starts from the total frequency
  • Each value subtracts from the previous total

🎙️ For a 'more than' cumulative frequency table, you start with the total frequency and subtract as you move down the classes. For example, 'number of students scoring more than or equal to 30 marks' would include all students from 30-40, 40-50, etc.

1List lower limits
2Subtract frequencies cumulatively
3Plot points (lower limit, CF)

Drawing Ogives and Finding Median

  • Plot points for Less Than Ogive (upper limit, CF)
  • Plot points for More Than Ogive (lower limit, CF)
  • The intersection point gives the Median!

🎙️ Once you have your cumulative frequencies, you plot them on a graph. The 'less than' ogive always goes up, and the 'more than' ogive always goes down. Where these two curves cross, the x-coordinate is your median!

Common Mistakes to Avoid!

  • Not sorting data for Median
  • Calculation errors in formulas
  • Confusing class limits with class marks
  • Incorrectly identifying modal/median class

🎙️ Watch out for these common pitfalls! Always double-check if you've sorted data for median. Be careful with arithmetic, especially with signs. Make sure you use the correct values for L, f, cf, and h in your formulas.
