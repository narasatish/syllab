Defining Linear Equations in Two Variables

  • An equation with two variables (e.g., x and y).
  • Each variable has a power of 1.
  • No product of variables (like xy).

🎙️ So, a linear equation in two variables means we have two unknown values, and when we plot them, they form a straight line. The 'linear' part is crucial here – it means no curves or bends.

The Standard Form: ax + by + c = 0

  • Any linear equation in two variables can be written as: ax + by + c = 0
  • 'a', 'b', 'c' are real numbers.
  • 'a' and 'b' cannot both be zero.

🎙️ This form, ax + by + c = 0, is like the universal address for all linear equations in two variables. It helps us organize and easily identify the coefficients 'a', 'b', and the constant 'c'.

Example 1: Identifying a, b, c

  • Express 2x + 3y = 5 in standard form.
  • Move 5 to the left side: 2x + 3y - 5 = 0
  • Here, a = 2, b = 3, c = -5

🎙️ Let's try an example. To find 'a', 'b', and 'c', first ensure the equation is in the ax + by + c = 0 format. Remember, the sign of 'c' is important, so 5 becomes -5 when moved to the left.

What are Solutions?

  • A pair of values (x, y) that satisfies the equation.
  • Makes the Left Hand Side (LHS) equal to the Right Hand Side (RHS).
  • Example: For x+y=5, (2,3) is a solution.

🎙️ Finding a solution means finding a specific pair of numbers for 'x' and 'y' that makes the equation true. It's like finding the exact coordinates that fit perfectly into our equation's rule.

🎯
Hitting the Mark

How to Find Solutions?

  • Choose a value for one variable (e.g., x).
  • Substitute it into the equation.
  • Solve for the other variable (e.g., y).

🎙️ To find solutions, we can pick any value for one variable, say 'x', and then calculate what 'y' must be to make the equation true. We can do this repeatedly to find multiple solutions.

Example: Finding Solutions for x + y = 7

  • If x = 0, then 0 + y = 7 => y = 7. Solution: (0, 7)
  • If x = 3, then 3 + y = 7 => y = 4. Solution: (3, 4)
  • If y = 1, then x + 1 = 7 => x = 6. Solution: (6, 1)

🎙️ Let's apply the method. For x + y = 7, if x is 0, y must be 7. If x is 3, y must be 4. We can find many such pairs. Each pair is a valid solution to the equation.

How Many Solutions Does a Linear Equation Have?

  • A linear equation in two variables has infinitely many solutions.
  • For every value of x, there is a corresponding value of y.
  • These solutions form a continuous line when plotted.

🎙️ Unlike linear equations in one variable which have a unique solution, equations in two variables have an infinite number of solutions. You can pick any number for 'x' and always find a 'y' that fits.

Visualizing Solutions: The Graph

  • Each solution (x, y) can be plotted as a point on a coordinate plane.
  • All points representing solutions lie on a straight line.
  • This line is the graph of the linear equation.

🎙️ This is where it gets really interesting! When you plot all those infinite solutions we just talked about, they don't scatter randomly. They all fall perfectly onto a straight line. That line is the visual representation of our equation.

📈

Steps to Draw a Graph

  • Find at least two solutions (x, y) for the equation.
  • Plot these points on a Cartesian plane.
  • Draw a straight line passing through these points.

🎙️ To draw the graph, you only need two points, but finding three is a good idea to check for accuracy. Once you have the points, connect them with a ruler to form a straight line.

What do Points on the Line Represent?

  • Every point on the line is a solution to the equation.
  • Every solution to the equation lies on the line.
  • If a point is NOT on the line, it is NOT a solution.

🎙️ This is a fundamental concept. The line itself is a visual representation of all possible solutions. If a point is on the line, it satisfies the equation. If it's not, it doesn't.

Special Cases: Equations of Axes

  • The equation of the x-axis is y = 0.
  • The equation of the y-axis is x = 0.
  • These are linear equations in two variables (e.g., 0x + 1y + 0 = 0).

🎙️ The x-axis and y-axis themselves are also linear equations! On the x-axis, every point has a y-coordinate of 0. Similarly, on the y-axis, every point has an x-coordinate of 0.
