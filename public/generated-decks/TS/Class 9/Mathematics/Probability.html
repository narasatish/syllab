Experiments and Outcomes

  • An Experiment is an action that results in well-defined outcomes.
  • An Outcome is a possible result of an experiment.
  • Example: Tossing a coin is an experiment.

🎙️ In probability, we start with an 'experiment,' which is any activity we perform. Each possible result of that experiment is called an 'outcome.' For instance, when you toss a coin, the act of tossing is the experiment, and 'Heads' or 'Tails' are the possible outcomes.

Trial and Event

  • A Trial is a single performance of an experiment.
  • An Event is one or more outcomes of an experiment.
  • Example: Getting 'Heads' is an event in a coin toss.

🎙️ A 'trial' is simply doing an experiment once. If you toss a coin three times, that's three trials. An 'event' is a specific outcome or a group of outcomes we are interested in. So, if we toss a coin and get 'Heads,' that's an event. If we roll a dice and want an even number, getting 2, 4, or 6 are all outcomes that make up that event.

What is a Random Experiment?

  • An experiment where all possible outcomes are known.
  • But the exact outcome cannot be predicted beforehand.
  • Example: Rolling a die – you know 1-6, but not which one.

🎙️ A random experiment is key in probability. We know all the things that *could* happen, but we can't be sure *which* one will happen until we do the experiment. Think about rolling a die: you know you'll get a number from 1 to 6, but you can't predict if it will be a 3 or a 5 before you roll it.

Equally Likely Outcomes

  • Outcomes that have the same chance of occurring.
  • No outcome is preferred over another.
  • Example: A fair coin has equally likely Heads and Tails.

🎙️ When all outcomes of an experiment have the same chance of happening, we call them 'equally likely.' A fair coin is a great example – Heads and Tails are equally likely. If a coin is biased, then the outcomes are not equally likely. This concept is important for calculating probabilities correctly.

The Probability Formula

  • P(E) = (Number of Favourable Outcomes) / (Total Number of Possible Outcomes)
  • P(E) stands for 'Probability of Event E'.
  • This is the fundamental formula we use.

🎙️ This formula is the heart of probability! To find the probability of an event, you count how many ways that specific event can happen (favourable outcomes) and divide it by the total number of all possible outcomes. Remember this formula, as we will use it constantly.

➗
Favourable / Total

Probability Always Between 0 and 1

  • The probability of any event (E) is always between 0 and 1.
  • 0 ≤ P(E) ≤ 1
  • P(E) cannot be negative or greater than 1.

🎙️ It's crucial to remember that a probability value will always fall between 0 and 1, inclusive. A probability of 0 means the event will never happen, and a probability of 1 means it will definitely happen. If your calculated probability is outside this range, you've made a mistake!

The Impossible Event

  • An event that cannot happen.
  • Its probability is 0.
  • Example: Getting an 8 when rolling a standard six-sided die.

🎙️ An impossible event is exactly what it sounds like – something that absolutely cannot occur. The probability of such an event is always 0. For example, if you roll a standard die, it's impossible to get a 7, so the probability of rolling a 7 is 0.

🚫
P(E) = 0

The Sure Event (Certain Event)

  • An event that is certain to happen.
  • Its probability is 1.
  • Example: Getting a number less than 7 when rolling a standard die.

🎙️ On the other end of the spectrum is the sure or certain event. This is an event that is guaranteed to happen, and its probability is 1. If you roll a standard die, you are certain to get a number less than 7 (1, 2, 3, 4, 5, or 6), so the probability is 1.

✅
P(E) = 1

Worked Example: Coin Toss

  • Experiment: Tossing a fair coin.
  • Possible Outcomes: Heads (H), Tails (T). Total = 2.
  • Event E: Getting a Head. Favourable Outcomes = 1 (H).
  • P(Head) = 1/2.

🎙️ Let's apply the formula! When we toss a fair coin, there are two equally likely outcomes: Heads or Tails. If we want to find the probability of getting a Head, there's only one favourable outcome (Head) out of two total possible outcomes. So, the probability is 1/2.

Worked Example: Rolling a Die

  • Experiment: Rolling a fair six-sided die.
  • Possible Outcomes: 1, 2, 3, 4, 5, 6. Total = 6.
  • Event E: Getting an even number (2, 4, 6). Favourable = 3.
  • P(Even Number) = 3/6 = 1/2.

🎙️ Now, let's try with a die. When you roll a standard die, there are six possible outcomes. If the event we're interested in is getting an even number, then 2, 4, and 6 are our favourable outcomes. That's 3 favourable outcomes out of a total of 6, giving us a probability of 3/6, which simplifies to 1/2.

Complementary Events

  • Two events are complementary if one happens if and only if the other doesn't.
  • If E is an event, then 'not E' (or E') is its complementary event.
  • P(E) + P(not E) = 1.

🎙️ Complementary events are very useful. If an event E happens, its complement, 'not E', means E does *not* happen. The sum of the probabilities of an event and its complementary event is always 1. This means if you know P(E), you can easily find P(not E) by subtracting P(E) from 1.

➕
P(E) + P(E') = 1

Worked Example: Complementary Event

  • The probability of rain today is 0.3.
  • Event E: It rains today. P(E) = 0.3.
  • Event 'not E': It does not rain today.
  • P(not E) = 1 - P(E) = 1 - 0.3 = 0.7.

🎙️ Let's see this in action. If the weather forecast says there's a 0.3 probability of rain, what's the probability that it *won't* rain? Using the concept of complementary events, we simply subtract the probability of rain from 1. So, the probability of no rain is 0.7.

Worked Example: Drawing a Card

  • Experiment: Drawing one card from a well-shuffled deck.
  • Total Possible Outcomes = 52.
  • Event E: Drawing a Heart. Favourable Outcomes = 13 (all Hearts).
  • P(Heart) = 13/52 = 1/4.

🎙️ If you draw a single card from a complete deck, there are 52 possible outcomes. If we want to find the probability of drawing a Heart, we know there are 13 Heart cards in the deck. So, the probability is 13 out of 52, which simplifies to 1/4.

Worked Example: Experimental Probability

  • A coin is tossed 100 times.
  • Heads appeared 45 times, Tails appeared 55 times.
  • P(Heads) = 45/100 = 0.45
  • P(Tails) = 55/100 = 0.55

🎙️ In experimental probability, we actually perform the experiment and record the results. If a coin is tossed 100 times and Heads come up 45 times, then the experimental probability of getting Heads is 45/100. This is different from theoretical probability, which assumes ideal conditions like a perfectly fair coin.

Key Concepts Recap

  • Probability: Likelihood of an event.

  • Equally Likely Outcomes: Fair chances.
  • P(E) = Favourable Outcomes / Total Outcomes.
