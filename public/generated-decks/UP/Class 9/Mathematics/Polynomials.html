Variables and Constants: The Building Blocks

  • Constants: Fixed numerical values (e.g., 5, -2, π).
  • Variables: Symbols representing unknown values (e.g., x, y, a).
  • Variables can take different values, constants stay the same.

🎙️ Think of constants as specific numbers like '5' or '10'. Variables are like placeholders, usually letters, that can represent different numbers.

What Exactly is a Polynomial?

  • A special type of algebraic expression.
  • Contains variables raised to non-negative integer powers.
  • No variables in the denominator, no fractional powers, no roots of variables.

🎙️ Now, let's define our main topic. A polynomial is a specific kind of algebraic expression that follows certain rules. The most important rule is about the powers of the variables.

📚
Structured Expression
7 / 25

The Golden Rule: Exponents Must Be Just Right!

  • Powers of variables must be 0, 1, 2, 3, ... (whole numbers).
  • Cannot be negative (e.g., x⁻¹ is not allowed).
  • Cannot be fractions (e.g., x¹/² or √x is not allowed).

🎙️ This is the most crucial condition for an expression to be a polynomial. The powers of your variables must always be whole numbers. No negative powers, and no fractional powers!

🚫
No Negatives, No Fractions

Is it a Polynomial? Let's Check!

  • Example 1: 3x² + 5x - 2 (Yes, exponents are 2, 1, 0).
  • Example 2: 4/√x + 7 (No, √x means x¹/²).
  • Example 3: 5x³ + 2/x (No, 2/x means 2x⁻¹).

🎙️ Let's practice identifying polynomials. Remember to look closely at the powers of each variable. If any variable has a negative or fractional power, it's not a polynomial.

1Look at variables
2Check all exponents
3Are they whole numbers?

Degree of a Polynomial: Its Highest Power

  • The highest power (exponent) of the variable in a polynomial.
  • For a single variable polynomial, it's easy to find.
  • Example: In 5x³ + 2x² - 7, the degree is 3.

🎙️ The degree tells us a lot about a polynomial. It's simply the largest exponent you see on any variable in the expression. For polynomials with one variable, it's straightforward.

Classifying Polynomials by Degree

  • Degree 1: Linear Polynomial (e.g., 2x + 5).
  • Degree 2: Quadratic Polynomial (e.g., 3x² - x + 1).
  • Degree 3: Cubic Polynomial (e.g., x³ - 8).

🎙️ Polynomials are often named based on their degree. A degree 1 polynomial is 'linear', degree 2 is 'quadratic', and degree 3 is 'cubic'. These terms are very important.

Classifying Polynomials by Number of Terms

  • One term: Monomial (e.g., 7x², 5).
  • Two terms: Binomial (e.g., x + 3, 2y - 5).
  • Three terms: Trinomial (e.g., x² + 2x - 1).

🎙️ We can also classify polynomials by how many terms they have. One term is a monomial, two terms is a binomial, and three terms is a trinomial. These names come from Latin prefixes.

Zero of a Polynomial: When P(x) = 0

  • A value of the variable that makes the polynomial equal to zero.
  • If P(x) is a polynomial, then 'a' is a zero if P(a) = 0.
  • Also called a 'root' of the polynomial.

🎙️ The 'zero' of a polynomial is a very important concept. It's simply the specific value you can put into the polynomial for 'x' that makes the entire expression evaluate to zero.

Finding the Zero of a Linear Polynomial

  • For P(x) = ax + b, set P(x) = 0.
  • So, ax + b = 0.
  • Solve for x: x = -b/a.

🎙️ Finding the zero for a linear polynomial is straightforward. You just set the expression equal to zero and solve for the variable 'x'. This gives you the value that 'nullifies' the polynomial.

1Set P(x) = 0
2Isolate 'x' term
3Solve for 'x'

Adding Polynomials: Combine Like Terms

  • Group terms with the same variable and exponent.
  • Add their coefficients.
  • Example: (2x + 3) + (x - 1) = 3x + 2.

🎙️ Adding polynomials is like combining similar items. You look for terms that have the exact same variable part, and then you just add their numerical coefficients.

1Remove parentheses
2Identify like terms
3Combine coefficients

Subtracting Polynomials: Change & Combine

  • Distribute the negative sign to all terms in the second polynomial.
  • Then, combine like terms as in addition.
  • Example: (5x + 2) - (2x - 1) = 3x + 3.

🎙️ Subtraction is similar to addition, but with an important first step: you must change the sign of every term in the polynomial being subtracted before combining like terms.

1Distribute minus sign
2Change signs of 2nd poly
3Combine like terms

Multiplying Polynomials: Distribute Each Term

  • Multiply each term of the first polynomial by each term of the second.
  • Add the exponents of the same variables.
  • Combine any like terms in the final result.

🎙️ When multiplying polynomials, remember the distributive property. Each term in the first polynomial needs to be multiplied by every term in the second polynomial. Then simplify by combining like terms.

1Multiply each term
2Add exponents
3Combine like terms
