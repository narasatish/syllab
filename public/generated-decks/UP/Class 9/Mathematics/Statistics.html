Types of Data: Primary Data

  • Collected by the investigator directly
  • First-hand information, fresh and original
  • Example: Surveying your classmates about their favorite sport

🎙️ Primary data is like cooking a meal from scratch – you gather all the ingredients yourself. When you go out and collect information directly for your own study, that's primary data. It's often more accurate for your specific needs.

Types of Data: Secondary Data

  • Collected by someone else and used by you
  • Second-hand information, already processed
  • Example: Using census reports or newspaper articles for research

🎙️ Secondary data is like eating a meal prepared by someone else. You're using data that has already been collected and published. It saves time and effort, but you need to be careful about its source and relevance to your study.

Primary vs. Secondary: An Example

  • To find average height of students in your class:
  • Primary: Measure each student directly
  • Secondary: Get height data from school records

🎙️ See the difference? Measuring heights yourself gives you primary data. If the school already has this data recorded and you use it, that's secondary data. Both have their uses depending on the situation.

What is Frequency?

  • The number of times a particular observation occurs
  • How often something appears in a dataset
  • Helps summarize data effectively

🎙️ Frequency tells us 'how many.' If we are looking at the marks obtained by students, the frequency of a certain mark would be the number of students who got that exact mark. It's a simple but powerful concept.

🔁

Making a Frequency Distribution Table

  • A table showing each observation and its frequency
  • Uses tally marks to count occurrences
  • Organizes raw data into a clear format

🎙️ A frequency distribution table is a neat way to present data. Instead of a long list of numbers, we list each unique value and how many times it appears. Tally marks are a great way to count as you go through the raw data.

Example: Marks of 10 Students

  • Raw Data: 5, 7, 6, 5, 8, 7, 5, 6, 9, 5
  • Observation | Tally Marks | Frequency
  • 5 | |||| | 4
  • 6 | || | 2
  • 7 | || | 2
  • 8 | | | 1
  • 9 | | | 1

🎙️ Here, we have the marks of 10 students. Notice how the frequency table quickly shows us that '5' is the most common mark, occurring 4 times. This is much clearer than just looking at the raw data list.

Grouped Frequency Distribution: Handling Large Data

  • Used when the range of data is very wide
  • Data is divided into classes or groups
  • Each class has a range of values

🎙️ What if you have the marks of 100 students, ranging from 1 to 100? Creating a frequency table for each individual mark would be too long. That's where grouped frequency distribution comes in, putting data into convenient groups.

Class Interval and Class Size

  • Class Interval: The range of values in each group (e.g., 0-10, 10-20)
  • Class Size (or Width): The difference between the upper and lower class limits
  • Example: For 0-10, class size is 10 - 0 = 10

🎙️ A class interval defines the boundaries for a group of data. The class size tells us how wide that group is. For example, if we have marks from 0-10, 10-20, and so on, each group has a class size of 10.

↔️
Range of Values

Upper and Lower Class Limits

  • Lower Class Limit: The smallest value in a class interval
  • Upper Class Limit: The largest value in a class interval
  • In 10-20, 10 is the lower limit, 20 is the upper limit

🎙️ Each class interval has a lower and an upper boundary. For example, in the interval 10-20, 10 is the starting point (lower limit) and 20 is the ending point (upper limit). These limits help us categorize each data point correctly.

⬆️⬇️
Boundaries

Class Mark: The Mid-Point

  • The mid-point of a class interval
  • Calculated as (Lower Limit + Upper Limit) / 2
  • Example: For 10-20, class mark is (10+20)/2 = 15

🎙️ The class mark is a single value that represents the entire class interval. It's like finding the average value within that group. We often use the class mark for calculations and plotting graphs later on.

Example: Grouped Frequency Table

  • Heights (cm) of 20 Students:
  • 145, 150, 153, 160, 148, 155, 162, 158, 147, 151, 159, 161, 154, 146, 157, 152, 163, 149, 156, 150
  • Class Interval | Tally Marks | Frequency
  • 145-150 | |||| || | 7
  • 150-155 | |||| ||| | 8
  • 155-160 | |||| | 5
  • 160-165 | ||| | 3

🎙️ Here, we've grouped the heights into intervals. Note that usually, the upper limit of one class is the lower limit of the next. For '145-150', we include 145 but typically exclude 150, which goes into the next class '150-155'.

Visualizing Data: Bar Graphs

  • Uses bars of uniform width
  • Height of bars represents frequency
  • Bars are separated by equal spaces

🎙️ Bar graphs are excellent for comparing different categories. Each bar stands for a category, and its height shows how many times that category appears. Remember, the bars don't touch each other.

Visualizing Data: Histograms

  • Similar to bar graphs, but for grouped data
  • Bars are adjacent (touching) as there are no gaps between class intervals
  • Width of bars represents class interval, height represents frequency

🎙️ Histograms are specifically for grouped frequency distributions. Since the class intervals are continuous (like 0-10, then 10-20), the bars in a histogram touch each other, showing a continuous range of data.

Visualizing Data: Frequency Polygons

  • A line graph connecting the mid-points of the top of histogram bars
  • Can also be drawn without a histogram, using class marks
  • Useful for comparing two or more frequency distributions

🎙️ A frequency polygon gives us a visual representation of the overall shape of the distribution. By connecting the midpoints, we can see the general trend or pattern in the data more clearly, especially when comparing multiple datasets.
