Introduction to Arithmetic Progression (AP)

  • A special type of sequence
  • Each term is obtained by adding a fixed number
  • The fixed number is called the 'common difference'

🎙️ Now, let's define an Arithmetic Progression, or AP. It's a sequence where the difference between any two consecutive terms is always the same. This constant difference is what makes it an AP.

Understanding the Common Difference (d)

  • The fixed number added in an AP
  • Can be positive, negative, or zero
  • Calculated as: (any term) - (previous term)

🎙️ The common difference, denoted by 'd', is the heart of an AP. It's the constant value you add to get the next term. Remember, you can find 'd' by subtracting any term from its succeeding term.

Formula for the nth Term (an)

  • an = a + (n-1)d
  • an: the nth term
  • a: the first term
  • n: the term number (position)
  • d: the common difference

🎙️ This is a very important formula. The nth term, denoted by 'an', can be found by adding 'n-1' times the common difference 'd' to the first term 'a'. Memorize this formula well, as it's used frequently.

Worked Example: Finding a Specific Term

  • Problem: Find the 10th term of the AP: 2, 7, 12, ...
  • Solution: a=2, d=5, n=10
  • a10 = 2 + (10-1)5 = 2 + 9*5 = 2 + 45 = 47

🎙️ Let's apply the formula. Here, the first term is 2, and the common difference is 5. We want the 10th term, so n=10. Substitute these values into the formula to get the answer.

Understanding the Sum Formula

  • Consider an AP: a, a+d, ..., l-d, l
  • Sum Sn = a + (a+d) + ... + (l-d) + l
  • Also Sn = l + (l-d) + ... + (a+d) + a
  • Adding both: 2Sn = n * (a+l)

🎙️ The formula for the sum of an AP was famously discovered by young Gauss. By writing the sum forwards and backwards and adding them, we can see a pattern emerge where each pair sums to (a+l). This simple trick leads us to the formula.

Formula for the Sum of n Terms (Sn)

  • Sn = n/2 [2a + (n-1)d]
  • OR Sn = n/2 [a + l] (where 'l' is the last term, an)
  • Sn: sum of the first n terms
  • n: number of terms
  • a: first term
  • d: common difference
  • l: last term

🎙️ Here are the two main formulas for the sum of 'n' terms. The first one uses 'a', 'n', and 'd'. The second one is very useful if you already know the last term 'l'. Choose the formula that best fits the information given in the problem.

Worked Example: Calculating the Sum

  • Problem: Find the sum of the first 20 terms of the AP: 1, 4, 7, 10, ...
  • Solution: a=1, d=3, n=20
  • S20 = 20/2 [2*1 + (20-1)3]
  • S20 = 10 [2 + 19*3] = 10 [2 + 57] = 10 * 59 = 590

Worked Example: Finding 'n' given the Sum

  • Problem: How many terms of the AP: 9, 17, 25, ... must be taken to give a sum of 636?
  • Solution: a=9, d=8, Sn=636
  • 636 = n/2 [2*9 + (n-1)8]
  • 1272 = n [18 + 8n - 8] => 1272 = n [10 + 8n]
  • 8n^2 + 10n - 1272 = 0 => 4n^2 + 5n - 636 = 0 (Solve quadratic for n)

🎙️ This type of problem requires a bit more algebra. When the sum is given, and you need to find 'n', you will often end up with a quadratic equation. Remember to solve the quadratic equation for 'n', and 'n' must be a positive integer.

Key Takeaways: Arithmetic Progressions

  • An AP has a constant common difference (d)
  • nth term formula: an = a + (n-1)d
  • Sum of n terms formula: Sn = n/2 [2a + (n-1)d] or Sn = n/2 [a + l]
  • AP concepts are used in many real-life situations

🎙️ Let's quickly recap what we've learned today. Remember the definition of an AP, how to find the common difference, and most importantly, the two key formulas for the nth term and the sum of n terms. These are your essential tools!
