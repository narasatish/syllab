  • To compare things (like exam scores).

What is Data?

  • Raw facts and figures.
  • Information collected for a specific purpose.
  • Can be numbers, names, or observations.

🎙️ Data is simply information. It's the raw material that statistics works with. Imagine you want to know the heights of all students in your class – those measurements are your data.

Primary Data

  • Collected directly by the investigator.
  • First-hand information.
  • More reliable and specific.

🎙️ When you collect data yourself, directly from the source, it's called primary data. For example, if you go around your class and ask each student their favorite subject, that's primary data.

Secondary Data

  • Easier to collect but might not be specific.

🎙️ Secondary data is like using information that's already been gathered. If you find the average rainfall data for Rajasthan from a government website, that's secondary data.

Primary vs. Secondary Data

Understanding Frequency

  • The number of times a particular observation occurs.
  • How often something happens.
  • Helps to count occurrences.

🎙️ Frequency simply means 'how many times'. If we count how many students scored 8 marks in a test, that count is the frequency of the mark '8'.

Ungrouped Frequency Table

  • Organizes raw data for distinct values.
  • Lists each unique observation.
  • Shows its corresponding frequency.

🎙️ An ungrouped frequency table is used when your data values are distinct and not too many. You list each unique value and then count how many times it appears using tally marks.

1List Data Points
2Tally Marks
3Count Frequency
12 / 25

Example: Ungrouped FDT

  • Marks of 10 students: 5, 7, 5, 8, 6, 7, 5, 9, 8, 7
  • Marks | Tally | Frequency
  • 5 | ||| | 3
  • 6 | | | 1
  • 7 | ||| | 3
  • 8 | || | 2
  • 9 | | | 1

🎙️ Here, we can clearly see that '5' marks and '7' marks were scored by 3 students each. This table makes the data much easier to read and understand than the raw list.

Grouped Frequency Table

  • Used when data has a wide range of values.
  • Observations are grouped into class intervals.
  • Each interval has a frequency.

🎙️ When you have a very large number of different data points, it's not practical to list each one separately. So, we group them into ranges, called class intervals, to make the table manageable.

📦
Data in Groups

Class Intervals & Size

  • Class Interval: The range of values in a group (e.g., 0-10, 10-20).
  • Class Size/Width: The difference between the upper and lower class limits (e.g., 10-0 = 10).

🎙️ A class interval defines the boundaries of a group, like 'marks between 0 and 10'. The class size tells us how wide each group is. We usually keep the class size uniform for all intervals.

↔️
Range of Data
15 / 25

Upper and Lower Class Limits

  • Lower Class Limit: The smallest value in a class interval.
  • Upper Class Limit: The largest value in a class interval.
  • For 10-20, 10 is lower, 20 is upper.

🎙️ Every class interval has a lower and an upper limit. These limits define exactly where the group begins and ends. It's important to be clear about which limit includes the value.

👆👇
Boundaries
16 / 25

Example: Grouped FDT

  • Marks of 20 students (0-50): 12, 25, 38, 5, 15, 22, 30, 45, 18, 28, 33, 8, 40, 20, 10, 35, 27, 42, 11, 29
  • Class Interval | Frequency
  • 0-10 | 2
  • 10-20 | 5
  • 20-30 | 6
  • 30-40 | 4
  • 40-50 | 3

🎙️ In this example, marks are grouped into intervals of 10. For instance, the interval 10-20 includes marks from 10 up to (but not including) 20. This makes a long list of marks much more manageable.

Visualizing Data

  • Pictures make data easier to understand.
  • Graphs help to compare and see trends quickly.
  • Common types: Bar Graphs, Histograms, Frequency Polygons.

🎙️ Once data is organized, representing it visually is the next powerful step. A good graph can tell a story much faster than a table of numbers alone, making comparisons very clear.

🖼️

Bar Graphs

  • Used for categorical data or ungrouped frequencies.
  • Bars are of uniform width.
  • Gaps between bars.
  • Height of bar represents frequency.

🎙️ Bar graphs are excellent for comparing different categories. For example, comparing the number of students who prefer different sports. Each bar stands alone with a gap.

Histograms

  • Used for continuous data (grouped frequency).
  • Bars are adjacent (no gaps).
  • Width of bar represents class interval.
  • Height represents frequency.

🎙️ Unlike bar graphs, histograms are specifically for continuous data like heights or marks in intervals. The bars touch each other because the data flows continuously from one interval to the next.

📈
Continuous Data

Frequency Polygons

  • Another way to represent grouped frequency.
  • Mid-points of class intervals are plotted.
  • Points are joined by line segments.
  • Good for comparing two distributions.

🎙️ Frequency polygons offer a different perspective on grouped data. We mark the middle point of each class interval at the height of its frequency and then connect these points to form a polygon.
