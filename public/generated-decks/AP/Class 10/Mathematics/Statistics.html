Mean: The Average

  • Sum of all observations divided by the number of observations.
  • Our everyday 'average'.
  • Distributes values equally.

🎙️ Think of it like sharing sweets equally among friends. If you have 10 sweets and 2 friends, each gets 5. That's the mean! It's the most common measure of central tendency.

🍬🍬🍬🍬🍬🍬
Sharing Equally
13 / 30

Mean for Ungrouped Data

  • Formula: Mean (x̄) = (Sum of all observations) / (Total number of observations)
  • Example: Marks 15, 20, 18, 22, 15
  • Sum = 15+20+18+22+15 = 90. Count = 5. Mean = 90/5 = 18.

🎙️ This is the simplest form of calculating the mean. Just add up all the numbers and divide by how many numbers there are. Remember the symbol x̄ (x-bar) for mean.

➕
Sum and Divide

Mean for Grouped Data: Direct Method

  • Find class mark (mid-point) for each interval (xᵢ).
  • Multiply frequency (fᵢ) by class mark (xᵢ) for each interval (fᵢxᵢ).
  • Formula: Mean (x̄) = (Σfᵢxᵢ) / (Σfᵢ)

🎙️ For grouped data, we can't use individual values. So, we assume each value in a class interval is represented by its midpoint, called the class mark. Then we use the formula involving the sum of (frequency × class mark).

Mean for Grouped Data Example

🎙️ For 0-10, xᵢ = 5. fᵢxᵢ = 2*5 = 10. For 10-20, xᵢ = 15. fᵢxᵢ = 5*15 = 75. For 20-30, xᵢ = 25. fᵢxᵢ = 3*25 = 75. Σfᵢ = 10, Σfᵢxᵢ = 160. Mean = 160/10 = 16.

Median: The Middle Value

  • The middlemost observation when data is arranged in order.
  • Divides data into two equal halves.
  • Less affected by extreme values than mean.

🎙️ Imagine lining up all your friends by height. The person exactly in the middle is the median height. It's about position, not necessarily the average value.

🧍
Middle Person

Median for Ungrouped Data

  • Step 1: Arrange data in ascending or descending order.
  • Step 2: Count the total number of observations (n).
  • If n is odd: Median = ((n+1)/2)th observation.
  • If n is even: Median = ( (n/2)th observation + ((n/2)+1)th observation ) / 2

🎙️ The most crucial step is to arrange the data first. Many students forget this and end up with the wrong median. Always order the data before finding the middle position.

Median for Ungrouped Data Example

  • Odd 'n': 10, 12, 15, 18, 20 (n=5). Median = (5+1)/2 = 3rd observation = 15.
  • Even 'n': 10, 12, 15, 18, 20, 22 (n=6). Median = (15+18)/2 = 16.5.
  • Ordering is key!

🎙️ Here you can clearly see how the median changes based on whether you have an odd or even number of observations. For even numbers, it's the average of the two middle values.

Median for Grouped Data: Using Cumulative Frequency

  • Requires a 'Cumulative Frequency' table.
  • Locate the 'median class' using n/2.
  • Formula: Median = L + [ (n/2 - CF) / f ] * h

🎙️ When data is grouped, we can't find an exact middle value. We find the class interval where the median lies, called the median class, and then use a specific formula to approximate the median.

Cumulative Frequency (CF): The Running Total

  • Sum of frequencies up to a particular class interval.
  • Helps identify the position of values.
  • Essential for finding the median of grouped data.

🎙️ If the frequencies are 2, 5, 3, the cumulative frequencies would be 2, (2+5)=7, (7+3)=10. It tells you how many observations are 'up to' a certain point.

Median for Grouped Data Example

  • Class | Freq | CF
  • 0-10 | 2 | 2
  • 10-20 | 5 | 7 (Median Class)

Mode: The Most Frequent

  • The value that appears most often in a dataset.
  • Represents the most popular or common item.
  • Can have one mode (unimodal), multiple modes (multimodal), or no mode.

🎙️ If most students prefer vanilla ice cream, then vanilla is the mode of ice cream preferences in the class. It's simply about what's most common or repeated.

Mode for Grouped Data

  • Identify the 'modal class' (class with highest frequency).
  • Formula: Mode = L + [ (f₁ - f₀) / (2f₁ - f₀ - f₂) ] * h
  • L = lower limit of modal class, f₁ = frequency of modal class.

🎙️ For grouped data, we first find the class interval with the highest frequency – this is our modal class. Then, we use a formula that considers the frequencies of the modal class and its adjacent classes.

📊
Highest Bar
26 / 30

Mode for Grouped Data Example

  • Class | Frequency
  • 0-10 | 2
  • 10-20 | 5 (f₀)
  • 20-30 | 8 (f₁, Modal Class)
  • 30-40 | 3 (f₂)

🎙️ Here, 20-30 is the modal class (f₁=8). L=20, f₀=5, f₂=3, h=10. Mode = 20 + [(8-5)/(2*8-5-3)]*10 = 20 + [3/(16-8)]*10 = 20 + (3/8)*10 = 20 + 3.75 = 23.75.

Common Mistakes to Avoid!

  • Forgetting to order data for Median.
  • Incorrectly calculating class marks (midpoints).
  • Mixing up formula terms (f₁, f₀, f₂) for Mode.
  • Calculation errors with fractions in formulas.

🎙️ These are the typical pitfalls students encounter. Always double-check your ordering for median, and be very careful with the subscripts in the mode formula. Practice is key to avoiding these errors!

Recap: Your Data Tools!

  • Data can be Raw or Grouped.
  • Mean: The average (Σfx/Σf).
  • Median: The middle value (L + [(N/2 - CF)/f]*h).
  • Mode: The most frequent value (L + [(f₁-f₀)/(2f₁-f₀-f₂)]*h).

🎙️ You've now learned the fundamental tools of statistics! Mean, Median, and Mode are powerful ways to summarize data and understand its central tendency. Keep practicing, and you'll master them in no time!
