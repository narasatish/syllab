What is Probability?

  • The measure of how likely an event is to occur
  • Expressed as a number between 0 and 1
  • Helps us quantify uncertainty

🎙️ Simply put, probability is about measuring how likely something is to happen. Think of it as a way to put a number on uncertainty. It's always a value between 0 and 1, where 0 means impossible and 1 means certain.

Key Terms: Experiment & Outcome

  • An action or process that leads to well-defined results
  • The result of an experiment is called an outcome

🎙️ Before we calculate, let's understand some basic terms. An 'experiment' is any activity where we observe what happens, like flipping a coin. Each possible result of that experiment is called an 'outcome', such as getting 'Heads' or 'Tails'.

Key Terms: Sample Space

  • The set of all possible outcomes of an experiment
  • Denoted by 'S'

🎙️ Imagine all the possible outcomes of an experiment grouped together. That collection is called the 'Sample Space'. For example, if you roll a standard die, the sample space is {1, 2, 3, 4, 5, 6}, because these are all the numbers you can possibly get.

All Possibilities

Key Terms: Event

  • One or more outcomes of an experiment
  • A subset of the sample space

🎙️ An 'event' is what we are interested in happening. It's a specific outcome or a group of outcomes from our sample space. For instance, when rolling a die, 'getting an even number' is an event, which includes the outcomes {2, 4, 6}.

🎯
Specific Outcome

Calculating Probability: The Formula

  • P(E) = (Number of Favorable Outcomes) / (Total Number of Possible Outcomes)
  • Favorable outcomes are those that satisfy the event 'E'

🎙️ Now for the core! The probability of an event 'E', written as P(E), is found by dividing the number of ways that event can happen by the total number of possible outcomes. It's a simple yet powerful ratio.

Example 1: Coin Toss (Simple Event)

  • Experiment: Tossing a fair coin
  • Sample Space (S) = {Heads, Tails}
  • Event (E): Getting a Head

🎙️ Let's apply the formula. When you toss a coin, there are two possible outcomes: Heads or Tails. So, total outcomes = 2. If we want to find the probability of getting a Head, there's only one favorable outcome. So, P(Head) = 1/2.

Example 2: Rolling a Die (Multiple Outcomes)

  • Experiment: Rolling a standard six-sided die
  • Sample Space (S) = {1, 2, 3, 4, 5, 6}
  • Event (E): Getting an even number

🎙️ Consider rolling a die. The total possible outcomes are 6. If our event is 'getting an even number', the favorable outcomes are {2, 4, 6}. There are 3 such outcomes. So, P(Even Number) = 3/6, which simplifies to 1/2.

Probability Scale: 0 to 1

  • Probability values always lie between 0 and 1, inclusive
  • 0 means the event is impossible
  • 1 means the event is certain

🎙️ Remember, probability is a fraction or a decimal between 0 and 1. A probability of 0 means something absolutely cannot happen, while a probability of 1 means it definitely will happen. Everything else falls somewhere in between.

Impossible Event (P(E) = 0)

  • An event that cannot happen
  • Number of favorable outcomes is 0

🎙️ An impossible event has zero probability. For example, if you're rolling a standard six-sided die, the event 'getting a 7' is impossible. There are no 7s on a die, so the number of favorable outcomes is 0, making P(7) = 0/6 = 0.

🚫
No Chance
12 / 25

Certain Event (P(E) = 1)

  • An event that is sure to happen
  • Number of favorable outcomes equals total outcomes

🎙️ A certain event has a probability of 1. If you roll a standard die, the event 'getting a number less than 7' is certain. All numbers (1, 2, 3, 4, 5, 6) are less than 7, so favorable outcomes = 6, total outcomes = 6. P(<7) = 6/6 = 1.

✅
Sure Thing

Complementary Events

  • Two events are complementary if one event happening means the other cannot
  • P(E) + P(not E) = 1
  • P(not E) is also written as P(E')

🎙️ Complementary events are like two sides of a coin. If one happens, the other doesn't. The sum of their probabilities is always 1. This means if you know the probability of an event, you can easily find the probability of it NOT happening by subtracting from 1.

🔄
Opposite Events

Example 3: Complementary Event (Card Deck)

  • Event (E): Drawing a red card from a deck
  • P(E) = 26/52 = 1/2
  • P(not E): Drawing a black card

🎙️ A standard deck has 52 cards, 26 red and 26 black. The probability of drawing a red card is 26/52 or 1/2. The event 'not drawing a red card' is the same as 'drawing a black card'. Using the complementary rule, P(not Red) = 1 - P(Red) = 1 - 1/2 = 1/2.
