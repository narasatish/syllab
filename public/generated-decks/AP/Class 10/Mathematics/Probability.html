What is Probability?

  • Probability is the measure of how likely an event is to occur.
  • It's a number between 0 and 1, inclusive.
  • 0 means impossible, 1 means certain.

🎙️ Formally, probability quantifies uncertainty. It's a numerical value that tells us the chance of something happening. This value always falls between 0 and 1. If an event has a probability of 0, it simply cannot happen, while a probability of 1 means it's guaranteed to happen.

Events and Outcomes

  • An 'Experiment' is an action with well-defined results.
  • An 'Outcome' is a possible result of an experiment.
  • An 'Event' is one or more outcomes of an experiment.

🎙️ Let's clarify some key terms. When you roll a die, that's an experiment. The numbers you can get (1, 2, 3, 4, 5, 6) are the outcomes. An 'event' could be 'getting an even number' (outcomes 2, 4, 6) or 'getting a 3' (outcome 3). Understanding these distinctions is crucial for calculating probabilities.

🎙️ In probability, an experiment is simply any process that generates a set of outcomes. It's not always a complex lab setup! Tossing a coin is an experiment, and so is spinning a spinner. The key is that we can clearly define all possible results.

Formula for Probability

  • P(E) = (Number of Favourable Outcomes) / (Total Number of Possible Outcomes)

🎙️ This formula is the heart of probability! To find the probability of any event 'E', we count how many outcomes satisfy our event (favourable outcomes) and divide that by the total number of unique outcomes possible in the experiment. Remember this formula well, as we will use it repeatedly.

Example 1: Tossing a Coin

  • Experiment: Tossing a fair coin.
  • Total possible outcomes: {Heads, Tails} = 2 outcomes.
  • Event E: Getting a Head.
  • Favourable outcomes for E: {Heads} = 1 outcome.

🎙️ Let's apply our formula to a coin toss. The total possible outcomes are Heads or Tails, so there are 2. If our event is getting a Head, there's only one favourable outcome. So, the probability of getting a Head is 1 divided by 2, which is 1/2 or 0.5.

Sure Event: It Will Happen!

  • An event that is certain to occur is called a Sure Event.
  • Its probability is always 1.
  • Example: The sun rising in the East.

🎙️ A sure event is something that will definitely happen. For instance, if you're asked 'What is the probability of getting a number less than 7 when rolling a standard die?', the answer is 1, because all outcomes (1, 2, 3, 4, 5, 6) are less than 7. It's a guaranteed outcome.

Impossible Event: No Chance!

  • An event that cannot occur is called an Impossible Event.
  • Its probability is always 0.
  • Example: Getting an '8' when rolling a six-sided die.

🎙️ On the other end of the spectrum is the impossible event. This is an event that has absolutely no chance of happening. Rolling a standard die and getting an 8 is impossible, as the die only has faces numbered 1 to 6. Its probability is always 0.

Elementary Event: One Outcome

  • An event having only one outcome of the experiment is an Elementary Event.
  • Example: Getting a '3' when rolling a die.
  • Each coin toss (Heads or Tails) is an elementary event.

🎙️ An elementary event is the simplest type of event, consisting of just one single outcome from the experiment. For example, if you roll a die, getting a '1' is an elementary event. Getting a '2' is another elementary event, and so on. They represent the most basic results of an experiment.

Complementary Events: The 'Not' Factor

  • If E is an event, then 'not E' (or E') is its complementary event.
  • E' represents all outcomes that are NOT in E.
  • The sum of probabilities P(E) + P(E') = 1.

🎙️ Complementary events are like two sides of a coin – if one happens, the other doesn't. If 'E' is the event of rain, then 'E'' is the event of no rain. The crucial property is that the probability of an event plus the probability of its complement always adds up to 1. This relationship is very useful for calculations.

Example 2: Not Getting a 4

  • Experiment: Rolling a fair six-sided die.
  • Event E: Getting a '4'. P(E) = 1/6.
  • Event E': Not getting a '4'.

🎙️ Let's use the complementary event concept. If the probability of getting a '4' on a die is 1/6, then the probability of NOT getting a '4' is 1 minus 1/6, which is 5/6. This saves us from counting all the outcomes that are not 4 (1, 2, 3, 5, 6).

The Probability Formula Revisited

  • P(E) = (Number of Favourable Outcomes) / (Total Number of Possible Outcomes)
  • This formula applies to all 'equally likely' outcomes.
  • 'Equally likely' means each outcome has the same chance.

🎙️ Let's reinforce the core probability formula. It's crucial to remember that this formula works when all possible outcomes of an experiment are 'equally likely'. This means there's no bias towards any particular outcome, like a fair coin or a fair die. We'll now apply this to more complex scenarios.

Example 3: Drawing a King

  • Experiment: Drawing one card from a well-shuffled deck of 52 cards.
  • Total possible outcomes: 52.
  • Event E: Drawing a King.
  • Favourable outcomes for E: There are 4 Kings (one in each suit).

🎙️ Let's calculate the probability of drawing a King. We know there are 52 cards in total. How many Kings are there? Four – one for each suit. So, the probability is 4 divided by 52, which simplifies to 1/13. Simple, right?

2Kings = 4

Example 5: Sum of 7 with Two Dice

  • Experiment: Rolling two fair dice.
  • Total possible outcomes: 36.
  • Event E: Getting a sum of 7.
  • Favourable outcomes for E: {(1,6), (2,5), (3,4), (4,3), (5,2), (6,1)} = 6 outcomes.

🎙️ Let's find the probability of getting a sum of 7 when rolling two dice. We know there are 36 total outcomes. Now, list the pairs that add up to 7: (1,6), (2,5), (3,4), (4,3), (5,2), and (6,1). There are 6 such favourable outcomes. So, the probability is 6/36, which simplifies to 1/6.

The Probability Scale: 0 to 1

  • Probability values always lie between 0 and 1, inclusive.
  • P(E) = 0 for an Impossible Event.
  • P(E) = 1 for a Sure Event.
  • 0 ≤ P(E) ≤ 1 is the fundamental property of probability.

🎙️ It's vital to remember that a probability can never be less than 0 or greater than 1. This range is a fundamental property. If you calculate a probability outside this range, you know you've made a mistake! This visual helps us understand the spectrum from impossible to certain.

Common Mistakes to Avoid!

  • Miscounting total possible outcomes.
  • Miscounting favourable outcomes.
  • Forgetting P(E) + P(E') = 1 for complementary events.
  • Giving probability as a percentage without converting to decimal/fraction.

🎙️ Students often make a few common errors. Always double-check your total outcomes and favourable outcomes. Don't forget the complementary event rule, it's a powerful shortcut. And remember, probability is usually expressed as a fraction or a decimal, not a percentage, unless specifically asked.
