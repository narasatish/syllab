Introduction to Arithmetic Progressions (AP)

  • A sequence where each term (after the first) is obtained by adding a fixed number to the preceding term.
  • This fixed number is called the 'common difference'.
  • Example: 2, 4, 6, 8, ... (adding 2 each time)

🎙️ An Arithmetic Progression, or AP, is a special kind of sequence. What makes it special is that the difference between any two consecutive terms is always the same. This constant difference is very important.

Steady Growth

How to Identify an AP?

  • Calculate the difference between consecutive terms.
  • If the difference is constant, it's an AP.
  • Example: 5, 10, 15, 20. Differences: 5, 5, 5.

🎙️ To check if a given sequence is an AP, you simply need to find the difference between each term and its preceding term. If all these differences are identical, then you've found an AP!

The Common Difference (d)

  • The fixed number added to get the next term.
  • Can be positive, negative, or zero.
  • Calculated as: d = a₂ - a₁ = a₃ - a₂ = ...
  • Where a₁, a₂, a₃ are terms of the AP.

🎙️ The common difference, denoted by 'd', is the heart of an AP. It's the constant value you add or subtract to move from one term to the next. It can be any real number.

↔️
Constant Gap

Example: Finding the Common Difference

  • Sequence: 7, 10, 13, 16, ...
  • a₂ - a₁ = 10 - 7 = 3
  • a₃ - a₂ = 13 - 10 = 3
  • The common difference (d) is 3.

🎙️ Let's practice finding 'd'. For the sequence 7, 10, 13, 16, we subtract the first term from the second, and the second from the third. Since both differences are 3, the common difference is indeed 3.

General Form of an AP

  • If 'a' is the first term and 'd' is the common difference,
  • The AP can be written as: a, a+d, a+2d, a+3d, ...
  • This pattern helps us find any term.

🎙️ The general form gives us a blueprint for any AP. Knowing the first term 'a' and the common difference 'd', we can construct the entire sequence. Each term is just 'a' plus a multiple of 'd'.

The nth Term of an AP (an)

  • The formula to find any term in an AP without listing all terms.
  • Formula: aₙ = a + (n-1)d
  • Where aₙ is the nth term, a is the first term, n is the term number, and d is the common difference.

🎙️ This is a very powerful formula! The nth term formula allows us to directly calculate any term in an AP, whether it's the 10th term or the 100th term, just by knowing the first term, the common difference, and the term's position.

🎯
Targeting a Term

Worked Example: Finding the 15th Term

  • Given AP: 3, 7, 11, 15, ...
  • First term (a) = 3
  • Common difference (d) = 7 - 3 = 4
  • To find the 15th term (n=15): a₁₅ = a + (15-1)d = 3 + (14)4 = 3 + 56 = 59.

🎙️ Let's apply the formula. For the AP 3, 7, 11, 15, the first term is 3 and the common difference is 4. Plugging these values into the nth term formula for n=15, we find that the 15th term is 59.

Finding How Many Terms are in an AP

  • Given AP: 5, 8, 11, ..., 62.
  • Here, a = 5, d = 3, and aₙ = 62.
  • Use aₙ = a + (n-1)d to find 'n'.
  • 62 = 5 + (n-1)3 => 57 = (n-1)3 => 19 = n-1 => n = 20.

🎙️ Sometimes, you know the last term of an AP and need to find out how many terms there are. By rearranging the nth term formula, we can solve for 'n'. In this example, we find there are 20 terms in the given AP.

Sum of First n Terms of an AP (Sn)

  • To find the sum of a certain number of terms in an AP.
  • Formula: Sₙ = n/2 [2a + (n-1)d]
  • Where Sₙ is the sum, n is the number of terms, a is the first term, and d is the common difference.

🎙️ Just as we can find any specific term, we can also find the sum of the first 'n' terms of an AP. This formula is incredibly useful for calculating totals quickly, without having to add each term individually.

➕
Total Value
18 / 25

Worked Example: Sum of First 10 Terms

  • AP: 1, 3, 5, 7, ...
  • Find the sum of the first 10 terms (S₁₀).
  • a = 1, d = 2, n = 10.
  • S₁₀ = 10/2 [2(1) + (10-1)2] = 5 [2 + 9(2)] = 5 [2 + 18] = 5 [20] = 100.

🎙️ Let's apply the sum formula. For the AP of odd numbers, the first term is 1, and the common difference is 2. To find the sum of the first 10 terms, we plug these values into the formula and get 100.

  • The sum formula can be simplified: Sₙ = n/2 (a + l)

Worked Example: Sum with Last Term

  • AP: 2, 4, 6, ..., 20.
  • Find the sum of these terms.
  • First, find 'n': a=2, d=2, aₙ=20 => 20 = 2 + (n-1)2 => n=10.
  • Now, S₁₀ = 10/2 (2 + 20) = 5 (22) = 110.

🎙️ Let's use the simplified sum formula. For the AP 2, 4, ..., 20, we first found that there are 10 terms. Now, knowing the first term (2) and the last term (20), we can quickly calculate the sum to be 110.

Properties of an AP

  • If a constant is added/subtracted to each term, the new sequence is also an AP.
  • If each term is multiplied/divided by a non-zero constant, the new sequence is also an AP.
  • The common difference changes accordingly.

🎙️ Arithmetic Progressions have some interesting properties. If you modify each term of an AP in a consistent way – by adding, subtracting, multiplying, or dividing by a constant – the resulting sequence will also be an AP. Only the common difference will change proportionally.

Arithmetic Mean

  • If a, b, c are in AP, then 'b' is the Arithmetic Mean of 'a' and 'c'.
  • Formula: b = (a + c) / 2
  • It's the middle term of any three consecutive terms in an AP.

🎙️ The concept of an Arithmetic Mean is quite straightforward. For any three consecutive terms in an AP, the middle term is simply the average of the first and the third term. It represents the balance point between them.
