What is a Linear Equation?

  • The highest power of the variable is 1.
  • When graphed, it forms a straight line.
  • No curves or bends.

🎙️ A linear equation is special because the highest power of any variable in it is always one. This means if you were to draw its graph, you would always get a perfectly straight line, never a curve.

Linear Equation in TWO Variables

  • Contains two unknown values.
  • Example: x + y = 7.
  • Many possible solutions.

🎙️ Now, imagine an equation with two different unknowns, say 'x' and 'y'. For example, 'x + y = 7'. There are many pairs of numbers that could satisfy this, like (1, 6), (2, 5), and so on. This introduces a new level of problem-solving.

General Form: ax + by + c = 0

  • a, b, c are real numbers.
  • a and b cannot both be zero.
  • This is the standard way to write it.

🎙️ The standard way to write a linear equation in two variables is 'ax + by + c = 0'. Here, 'a', 'b', and 'c' are any real numbers, but 'a' and 'b' cannot both be zero, otherwise, it wouldn't be a two-variable equation anymore.

🎙️ Imagine you go to a stationery shop. You buy two pens and three notebooks, and the total bill is ₹70. If we let 'x' be the cost of one pen and 'y' be the cost of one notebook, we can form an equation: 2x + 3y = 70. This is a linear equation in two variables.

What is a 'Pair' of Linear Equations?

  • Two linear equations.
  • Involving the SAME two variables.
  • Solved together to find common solutions.

🎙️ Now, what if we have two such situations or conditions involving the same two variables? That's when we talk about a 'pair' of linear equations. We need to solve them together to find values for 'x' and 'y' that satisfy both equations simultaneously.

👯
Two Equations

General Form of a PAIR

  • Equation 1: a₁x + b₁y + c₁ = 0
  • Equation 2: a₂x + b₂y + c₂ = 0
  • Subscripts 1 and 2 distinguish the equations.

🎙️ When we have a pair, we write them like this: 'a₁x + b₁y + c₁ = 0' and 'a₂x + b₂y + c₂ = 0'. The subscripts '1' and '2' simply help us tell the coefficients of the first equation apart from the second.

Solutions to a Linear Equation

  • A pair of values (x, y).
  • Makes the equation true.
  • A single equation has infinite solutions.

🎙️ For a single linear equation in two variables, any pair of (x, y) values that satisfies it is a solution. There are actually infinitely many such pairs, forming a straight line when graphed.

Graphical Representation of a Single Linear Equation

  • Each solution is a point on the graph.
  • Connecting these points forms a straight line.
  • The line represents all possible solutions.

🎙️ If you plot all the possible solutions (x, y) for a single linear equation on a graph, they will all lie on a single straight line. This line visually represents all the infinite solutions to that equation.

Solutions to a PAIR of Linear Equations

  • A common pair of values (x, y).
  • Satisfies BOTH equations simultaneously.
  • This is what we aim to find.

🎙️ When we have a 'pair' of linear equations, we are looking for a special (x, y) pair that works for the first equation AND the second equation at the same time. This common solution is the key to solving problems involving two conditions.

Graphical Method: Visualizing Solutions

  • Draw the graph for each equation.
  • The intersection point is the solution.
  • A visual way to find common solutions.

🎙️ One powerful way to find the solution to a pair of linear equations is the graphical method. We simply draw the lines for both equations on the same graph paper. The point where these two lines meet, if they do, is our common solution.

Case 1: Intersecting Lines

  • The two lines cross at exactly one point.
  • This point is the unique solution.
  • Condition: a₁/a₂ ≠ b₁/b₂.

🎙️ In the first case, the two lines intersect at a single point. This means there is exactly one unique solution (x, y) that satisfies both equations. Mathematically, this happens when the ratio of their 'x' coefficients is not equal to the ratio of their 'y' coefficients.

✖️

Case 2: Parallel Lines

  • The two lines never meet.
  • They run side-by-side.
  • No common solution exists.

🎙️ Sometimes, the two lines you draw might be parallel. This means they will never intersect, no matter how far you extend them. In this scenario, there is no common point, and therefore, no solution to the pair of equations.

Real-Life Example: Railway Tracks

  • They maintain a constant distance.
  • They never cross each other.

🎙️ Think about railway tracks. They are designed to run parallel to each other, maintaining a constant distance. They never cross. This is a great real-world example of parallel lines, representing a system of equations with no solution.

Case 3: Coincident Lines

  • The two lines lie exactly on top of each other.
  • They are essentially the same line.
  • Infinitely many solutions.

🎙️ In the third case, if you plot both equations, you might find that the second line perfectly overlaps the first line. They are, in fact, the same line. This means every point on the line is a common solution, leading to infinitely many solutions.

⬆️
Overlapping Lines

Real-Life Example: Overlapping Paths

  • Two people follow the exact same route.
  • They walk on the same path.
  • Every point on the path is common.

🎙️ Imagine two people walking along the exact same path, one behind the other. Every single point on that path is common to both of them. This illustrates coincident lines, where there are infinitely many common solutions.

Summary: Types of Solutions

  • Intersecting: One unique solution.
  • Parallel: No solution.
  • Coincident: Infinitely many solutions.

🎙️ To summarize, when we graph a pair of linear equations, we can have three outcomes: intersecting lines giving one solution, parallel lines giving no solution, or coincident lines giving infinitely many solutions.
