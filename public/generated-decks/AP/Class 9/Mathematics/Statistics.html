Grouped Frequency Distribution

  • Used when data is very large and has many distinct values.
  • Observations are grouped into 'class intervals'.
  • Example: ages 0-10, 10-20, etc.

🎙️ What if you have the ages of 1000 people? Creating an ungrouped FDT would be too long! That's when we group data. It's like putting similar-sized books on the same shelf, even if their exact heights are slightly different.

Key Terms: Class Interval

  • A range of values into which observations are grouped.
  • Example: 0-10, 10-20, 20-30.
  • Each interval has a lower and an upper limit.

🎙️ Think of a class interval as a 'category' or a 'bucket' for your data. Instead of counting each individual age, you count how many ages fall within 0 to 10, then 10 to 20, and so on.

↔️
A specific range

Key Terms: Class Limits (Lower & Upper)

  • Lower Limit: The smallest value in a class interval (e.g., 10 in 10-20).
  • Upper Limit: The largest value in a class interval (e.g., 20 in 10-20).
  • These define the boundaries of each group.

🎙️ The class limits are like the start and end points of a street. They clearly mark where one group begins and another ends. Understanding these is vital for correctly placing data points.

📏
Defining boundaries
24 / 33

Key Terms: Class Size (or Width)

  • The difference between the upper and lower class limits.
  • It tells you the 'width' or 'span' of each class interval.
  • Example: For 10-20, the class size is 20 - 10 = 10.

🎙️ The class size tells you how many values are covered by each interval. It's important to keep the class size consistent across all intervals in a grouped frequency distribution for fair comparison.

↕️
The range of the group

Key Terms: Class Mark (Mid-point)

  • The midpoint of a class interval.
  • Calculated as (Lower Limit + Upper Limit) / 2.
  • Represents the 'average' value for that interval.

🎙️ The class mark is like finding the exact center point of your group. It's very useful when we need a single value to represent the entire class, especially when drawing graphs like frequency polygons.

Bar Graphs

  • Uses bars of uniform width.
  • Bars are drawn with equal spacing between them.
  • Height of each bar is proportional to the frequency.
  • Used for discrete data (distinct categories).

🎙️ Bar graphs are great for comparing different categories, like favorite fruits or colors. Each bar stands alone, showing that the categories are separate. The taller the bar, the higher the frequency or amount.

Histograms

  • Similar to bar graphs, but bars are adjacent (touching).
  • Width of bars is proportional to the class interval.
  • Height of bars is proportional to the frequency.
  • Used for continuous data (grouped frequency distribution).

🎙️ Histograms are special bar graphs for continuous data, where one group flows into the next. That's why the bars touch! They show how frequencies are distributed over a continuous range, like heights or ages.

Common Mistakes to Avoid!

  • Confusing Primary and Secondary Data: Always ask 'Who collected it, and for what purpose?'
  • Incorrect Tallying: Double-check your counts for frequency distribution tables.
  • Mixing up Bar Graphs & Histograms: Remember, bar graphs for discrete, histograms for continuous data (touching bars!).
  • Not labelling graph axes: Always label X and Y axes clearly.

🎙️ These are the typical pitfalls students encounter. A little extra attention to these details can save you marks. Practice makes perfect, especially with tallying and choosing the right graph type.
