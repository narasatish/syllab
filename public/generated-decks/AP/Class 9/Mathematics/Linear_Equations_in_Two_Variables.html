Expressions vs. Equations

  • Expressions: terms combined with operations (e.g., 2x + 3).
  • Equations: expressions with an equality sign (e.g., 2x + 3 = 7).

🎙️ The key difference is the equality sign. An expression is just a phrase, while an equation is a complete sentence that declares two things are equal.

What Does 'Linear' Mean?

  • Refers to a straight line.
  • Highest power of each variable is 1.
  • No x², y², or xy terms.

🎙️ The word 'linear' is crucial. It means that when we graph these equations, they will always form a straight line. This happens because the variables are only raised to the power of one.

Defining Linear Equations in Two Variables

  • An equation involving two variables.
  • Each variable has a degree of 1.
  • Can be written in a specific form.

🎙️ So, a linear equation in two variables is an algebraic statement where we have two unknown quantities, and each of them is raised to the power of one. This makes them 'linear'.

The Standard Form

  • General form: ax + by + c = 0.
  • a, b, c are real numbers.
  • a and b cannot both be zero.

🎙️ This is the universal way to write a linear equation in two variables. 'a', 'b', and 'c' are just numbers, and 'x' and 'y' are our variables. Remember, 'a' and 'b' can't both be zero, otherwise, it wouldn't be a two-variable equation!

📝
General Structure

Identifying a, b, and c

  • Example: 2x + 3y = 5
  • Rewrite as: 2x + 3y - 5 = 0
  • Here, a=2, b=3, c=-5

Finding Solutions: Step-by-Step

  • Choose a value for one variable (e.g., x).
  • Substitute it into the equation.
  • Solve for the other variable (y).

🎙️ To find solutions, we can pick any value for one variable, substitute it into the equation, and then solve for the second variable. This gives us a (x, y) pair.

1Pick x
2Substitute
3Solve for y

Example: Finding Solutions for x + y = 5

  • If x=1, then 1+y=5 => y=4. Solution: (1, 4).
  • If x=2, then 2+y=5 => y=3. Solution: (2, 3).
  • If y=0, then x+0=5 => x=5. Solution: (5, 0).

🎙️ Let's try this with x + y = 5. You can see that by choosing different values for x, we get corresponding values for y, forming different solution pairs.

How Many Solutions Can There Be?

  • A linear equation in two variables has infinitely many solutions.
  • Each solution is a point on the line.
  • The line extends indefinitely.

🎙️ This is an important point! Unlike one-variable equations which usually have one solution, two-variable linear equations have an infinite number of solutions. Each (x, y) pair that satisfies the equation is a point on the line.

The Graph of a Linear Equation

  • Every linear equation in two variables represents a straight line.
  • Each solution (x, y) is a point on this line.
  • Plotting these points gives the line.

🎙️ This is where the 'linear' part truly comes alive. When you plot all the infinite solutions of a linear equation in two variables on a coordinate plane, they will always form a perfect straight line.

📈
Straight Line Plot

Plotting Solutions to Draw the Graph

  • Find at least two distinct solutions (x, y) pairs.
  • Plot these points on a Cartesian plane.
  • Draw a straight line passing through them.

🎙️ To draw the graph, you only need two points, as two points define a unique straight line. However, finding a third point is a good way to check your work for accuracy.
