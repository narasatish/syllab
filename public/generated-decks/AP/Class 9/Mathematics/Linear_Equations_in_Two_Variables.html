Understanding Equations

  • It always contains an '=' sign.
  • Example: 2x + 5 = 11

🎙️ An equation is like a balanced scale; whatever is on one side must be equal to what's on the other. For instance, '2x + 5 = 11' means that the expression '2x + 5' has the same value as '11'.

The "Straight" Story of Linear Equations

  • A linear equation is an equation where the highest power of any variable is 1.
  • When graphed, a linear equation always forms a straight line.
  • Example: 3x + 2 = 8

🎙️ The word 'linear' comes from 'line'. This means that when we plot the solutions of such an equation on a graph, they will all fall on a straight line. The key is that no variable is raised to a power higher than one.

Defining Our New Friends

  • An equation of the form ax + by + c = 0, where a, b, and c are real numbers, and a and b are not both zero.
  • x and y are the two variables.
  • The highest power of x and y is 1.

🎙️ Formally, a linear equation in two variables is any equation that can be written in the form ax + by + c = 0. Here, 'a', 'b', and 'c' are just numbers, and 'x' and 'y' are our two variables. Remember, 'a' and 'b' can't both be zero, otherwise it wouldn't be a two-variable equation!

📝
The Definition

The Official Look: Standard Form

  • The general form is ax + by + c = 0.
  • a is the coefficient of x.
  • b is the coefficient of y.
  • c is the constant term.

🎙️ The standard form, ax + by + c = 0, helps us organize and compare equations. 'a' tells us what's multiplying 'x', 'b' tells us what's multiplying 'y', and 'c' is the number standing alone. Make sure the equation is set to zero on one side!

Spotting 'a', 'b', and 'c'

  • Example 1: 2x + 3y - 5 = 0 => a=2, b=3, c=-5
  • Example 2: 4x = 7y - 8 => 4x - 7y + 8 = 0 => a=4, b=-7, c=8
  • Example 3: y = 5x => 5x - y + 0 = 0 => a=5, b=-1, c=0

What Makes an Equation "Happy"?

  • A solution to a linear equation in two variables is a pair of values (x, y).
  • When these values are substituted into the equation, they make the equation true.
  • Example: For x + y = 5, (2, 3) is a solution because 2 + 3 = 5.

🎙️ Just like a lock needs the right key, an equation needs the right pair of values for x and y to be 'satisfied'. This pair, written as an ordered pair (x, y), is called a solution. When you plug these values in, both sides of the equation must be equal.

How to Find Solutions (Part 1)

  • Step 1: Choose any convenient value for one variable (e.g., x).
  • Step 2: Substitute this value into the equation.
  • Step 3: Solve the resulting linear equation in one variable for the other variable (e.g., y).

🎙️ To find solutions, we can pick a value for one variable, say x, and then solve for y. Let's say you choose x=0, then substitute it into the equation and find the corresponding y value. This method helps us generate ordered pairs.

1Pick a value for x (or y)
2Substitute into the equation
3Solve for the other variable

Let's Solve Together: 2x + y = 7

  • If x = 0: 2(0) + y = 7 => y = 7. Solution: (0, 7)
  • If x = 1: 2(1) + y = 7 => 2 + y = 7 => y = 5. Solution: (1, 5)
  • If y = 3: 2x + 3 = 7 => 2x = 4 => x = 2. Solution: (2, 3)

🎙️ Let's try an example. For the equation 2x + y = 7, if we choose x=0, we find y=7. So (0,7) is a solution. If we choose x=1, we find y=5, so (1,5) is another. We can also choose a value for y first, like y=3, and find x=2, giving us (2,3).

The Endless Possibilities!

  • Unlike linear equations in one variable, which have a unique solution...
  • A linear equation in two variables has infinitely many solutions!
  • For every value you choose for x, there's a corresponding value for y.

🎙️ This is a key difference! Because we can choose any real number for x (or y), there will always be a corresponding value for the other variable. This means there are an infinite number of ordered pairs (x, y) that will satisfy a linear equation in two variables.

Seeing Solutions: The Power of Graphs

  • Every solution (x, y) of a linear equation in two variables corresponds to a point on the Cartesian plane.
  • When all these points are plotted, they form a straight line.
  • This line is the graphical representation of the equation.

🎙️ The beauty of these equations is that their infinite solutions aren't random. When you plot each (x, y) solution as a point on a graph, they all line up perfectly to form a straight line. This line is essentially a visual picture of our equation.

📈

Your Map to Graphing

  • Step 1: Find at least two (preferably three) solutions (x, y) for the equation.
  • Step 2: Plot these ordered pairs as points on a Cartesian plane.
  • Step 3: Draw a straight line passing through all the plotted points. Extend the line in both directions.

🎙️ Graphing is a systematic process. First, calculate a few solution points. Then, carefully plot these points on your graph paper. Finally, connect them with a ruler to draw a straight line. Using three points helps verify your calculations; if they don't align, there's a mistake!

1Find 2-3 solutions
2Plot the points
3Draw a straight line

Special Lines: The X-axis

  • The equation of the x-axis is y = 0.
  • Every point on the x-axis has a y-coordinate of 0 (e.g., (1,0), (-5,0)).
  • It's a horizontal line.

🎙️ Did you know that the x-axis itself is a linear equation? Since every point on the x-axis has a y-coordinate of zero, its equation is simply y = 0. This is a special case of ax + by + c = 0 where a=0, b=1, and c=0.

Special Lines: The Y-axis

  • The equation of the y-axis is x = 0.
  • Every point on the y-axis has an x-coordinate of 0 (e.g., (0,2), (0,-4)).
  • It's a vertical line.

🎙️ Similarly, the y-axis also has its own equation. Since all points on the y-axis have an x-coordinate of zero, its equation is x = 0. This is another special case where a=1, b=0, and c=0 in our standard form.

Lines Parallel to the X-axis

  • Equations of the form y = k (where k is a constant) represent lines parallel to the x-axis.
  • Example: y = 3 is a horizontal line passing through (0, 3).
  • The y-coordinate remains constant for all points on this line.

🎙️ Any equation like y = 3 or y = -2 will result in a horizontal line. These lines are always parallel to the x-axis because the y-coordinate is fixed for all points, no matter what x-value you choose. They never intersect the x-axis unless k=0.

Lines Parallel to the Y-axis

  • Equations of the form x = k (where k is a constant) represent lines parallel to the y-axis.
  • Example: x = -2 is a vertical line passing through (-2, 0).
  • The x-coordinate remains constant for all points on this line.

🎙️ Conversely, equations like x = 5 or x = -2 produce vertical lines. These lines are always parallel to the y-axis because the x-coordinate is constant for every point on the line. They never intersect the y-axis unless k=0.

Watch Out! Common Pitfalls

  • Sign Errors: Forgetting to carry negative signs when rearranging or substituting.
  • Calculation Mistakes: Simple arithmetic errors when solving for the second variable.
  • Plotting Errors: Incorrectly plotting points on the Cartesian plane.
  • Drawing the Line: Not drawing a straight line or not extending it with arrows.

🎙️ Many students make common mistakes. Always double-check your signs, especially when moving terms across the equals sign. Be precise with your calculations and when plotting points. And remember, a linear equation's graph is always a straight line, so use a ruler!
