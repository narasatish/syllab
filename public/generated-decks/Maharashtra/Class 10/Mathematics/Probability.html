What is Probability?

  • It's a measure of how likely an event is to occur.
  • Expressed as a number between 0 and 1.
  • 0 means impossible, 1 means certain.

🎙️ Probability helps us quantify uncertainty. It tells us how often we can expect an event to happen if we repeat an experiment many times, giving us a numerical value for its likelihood.

Key Terms: Experiment & Outcome

  • Experiment: An action with well-defined results.
  • Outcome: A possible result of an experiment.
  • Example: Tossing a coin is an experiment. Getting Heads is an outcome.

🎙️ To understand probability, we first need to define what we are observing. An experiment is any activity where we can clearly list all possible results, and each result is called an outcome.

Key Terms: Sample Space (S)

  • The set of all possible outcomes of an experiment.
  • Represented by 'S' or 'Ω' (Omega).
  • Example: Tossing a coin: S = {Heads, Tails}.

🎙️ When you perform an experiment, there's a list of every single thing that could happen. This complete list of all possible outcomes is called the sample space, and it's crucial for calculating probability.

Key Terms: Event (E)

  • A subset of the sample space.
  • A collection of one or more outcomes.
  • Example: Getting a 'Head' when tossing a coin is an event.

🎙️ An event is simply what we are interested in observing. It's a specific outcome or a group of outcomes from our sample space, forming a part of the total possibilities.

Types of Events: Certain Event

  • An event that is sure to happen.
  • Its probability is 1 (or 100%).
  • Example: The sun will rise tomorrow.

🎙️ A certain event is one that will always occur. There's no doubt about it, and its probability is the highest possible value, which is 1, indicating absolute certainty.

Types of Events: Impossible Event

  • An event that cannot happen.
  • Its probability is 0.
  • Example: Rolling a 7 on a standard six-sided die.

🎙️ An impossible event is the opposite of a certain event. It's something that can never occur in a given experiment, and its probability is 0, meaning there's no chance of it happening.

Types of Events: Elementary Event

  • An event with only one outcome.
  • Also called a simple event.
  • Example: Getting a '3' when rolling a single die.

🎙️ An elementary event is the most basic kind of event. It consists of just one specific result from the experiment, making it a single point in the sample space.

Types of Events: Complementary Event (E')

  • The event that 'E does not happen'.
  • P(E) + P(E') = 1.
  • Example: If E is getting Heads, E' is getting Tails.

🎙️ A complementary event includes all the outcomes that are not in the original event. The probabilities of an event and its complement always add up to 1, representing all possible outcomes.

The Probability Formula

  • P(E) = (Number of favourable outcomes) / (Total number of outcomes in S)
  • Remember: Favourable means what we want to happen!

🎙️ This is the core formula for calculating probability. We simply divide the number of ways our desired event can happen by the total number of possible outcomes in the sample space.

➗
Ratio for Probability

Probability Range: 0 to 1

  • The probability of any event E is always between 0 and 1.
  • 0 ≤ P(E) ≤ 1.
  • A probability cannot be negative or greater than 1.

🎙️ It's very important to remember that all probabilities must fall within this range. If you calculate a probability outside of 0 and 1, you know you've made a mistake in your calculation.

Worked Example: Coin Toss

  • Experiment: Tossing a fair coin.
  • Sample Space (S) = {Heads, Tails}, n(S) = 2.
  • Event (E): Getting a Head. Favourable outcomes = {Heads}, n(E) = 1.
  • P(E) = n(E) / n(S) = 1 / 2.

🎙️ Let's apply our formula. For a coin toss, there are two equally likely outcomes. If we want a Head, there's only one way to get it, so the probability is a clear 1/2.

Worked Example: Dice Roll

  • Experiment: Rolling a standard six-sided die.
  • Sample Space (S) = {1, 2, 3, 4, 5, 6}, n(S) = 6.
  • Event (E): Getting an even number. Favourable outcomes = {2, 4, 6}, n(E) = 3.
  • P(E) = n(E) / n(S) = 3 / 6 = 1 / 2.

🎙️ With a die, we have six possible outcomes. If we're looking for an even number, we can count how many of those outcomes fit our criteria, leading to a probability of 1/2.

Worked Example: Deck of Cards

  • Experiment: Drawing one card from a well-shuffled deck of 52 cards.
  • Sample Space (S): 52 cards, n(S) = 52.
  • Event (E): Drawing a King. Favourable outcomes = {4 Kings}, n(E) = 4.
  • P(E) = n(E) / n(S) = 4 / 52 = 1 / 13.

🎙️ A standard deck has 52 cards. There are 4 suits, and each suit has one King. So, there are 4 Kings in total, making the probability of drawing one 4/52.

Worked Example: Marbles in a Bag

  • A bag contains 3 red, 2 blue, and 5 green marbles.
  • Total marbles (S) = 3 + 2 + 5 = 10, n(S) = 10.
  • Event (E1): Picking a red marble. n(E1) = 3. P(E1) = 3/10.
  • Event (E2): Picking a green marble. n(E2) = 5. P(E2) = 5/10 = 1/2.

🎙️ Here, we first find the total number of marbles. Then, for each event, we count the number of marbles that satisfy the condition and apply our probability formula.

Worked Example: Days of the Week

  • Experiment: Randomly choosing a day of the week.
  • Sample Space (S) = {Mon, Tue, Wed, Thu, Fri, Sat, Sun}, n(S) = 7.
  • Event (E): Choosing a day starting with 'S'. Favourable outcomes = {Saturday, Sunday}, n(E) = 2.
  • P(E) = n(E) / n(S) = 2 / 7.

🎙️ When considering days of the week, remember there are 7 distinct days. We then count how many of them fit our criteria, like starting with the letter 'S', to find the probability.

Common Misconceptions

  • "Gambler's Fallacy": Believing past events affect future independent ones.
  • Small Sample Size: Assuming probability holds true in very few trials.

🎙️ It's easy to fall into traps when thinking about probability. Remember that independent events don't 'remember' what happened before, and probability describes long-term trends, not necessarily short bursts.
