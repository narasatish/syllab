What is an Equation?

  • A mathematical statement showing two expressions are equal.
  • Contains variables, constants, and an equality sign (=).
  • Example: 2x + 5 = 11

🎙️ Think of an equation like a balanced scale. Whatever is on one side must be equal to what's on the other. It's a statement of equality between two mathematical expressions.

Variables and Constants

  • Variables: Letters representing unknown values (e.g., x, y, a).
  • Constants: Fixed numerical values (e.g., 2, 5, -10).

🎙️ Variables are like placeholders for numbers that can change or are unknown, while constants are numbers that always stay the same. In '2x + 5', 'x' is the variable and '2' and '5' are constants.

Recap: Linear Equation in One Variable

  • An equation with only one variable.
  • The highest power (degree) of the variable is 1.
  • Standard form: ax + b = 0 (where a ≠ 0).
  • Example: 3x - 7 = 8

🎙️ You've already solved linear equations with one variable, like '3x - 7 = 8'. Here, 'x' is the only variable, and its highest power is 1. We find a single value for x that makes the equation true.

Why Do We Need Two Variables?

  • Many real-life situations involve two unknown quantities.
  • One variable isn't enough to represent these situations.
  • Example: Cost of two different items, speeds of two vehicles.

🎙️ Imagine you go to a shop and buy both pens and notebooks. If you only know the total cost, how would you find the individual cost of each? You need to consider two different items, hence two variables.

Definition: Linear Equation in Two Variables

  • An equation involving two variables.
  • The highest power (degree) of each variable is 1.
  • Variables are not multiplied together (e.g., no 'xy').
  • Standard form: ax + by + c = 0

🎙️ A linear equation in two variables is an equation where we have two different letters, say 'x' and 'y'. The most important thing is that the highest power of both 'x' and 'y' is always 1, and they don't multiply each other.

Key Characteristics

  • Two variables (e.g., x and y).
  • Degree of each variable is 1.
  • Coefficients a, b, c are real numbers.
  • Coefficients 'a' and 'b' cannot both be zero.

🎙️ Remember these four key points. If any of these conditions are not met, it's not a linear equation in two variables. For example, x² + y = 5 is not linear because x has a degree of 2.

Real-Life Example 1: Cost of Fruits

  • You buy apples and bananas.
  • Cost of 1 apple = ₹x, Cost of 1 banana = ₹y.
  • Total cost of 3 apples and 2 bananas is ₹70.

🎙️ Let's say you bought 3 apples and 2 bananas. If an apple costs 'x' rupees and a banana costs 'y' rupees, the total cost can be written as 3x + 2y = 70. This is a perfect example of a linear equation in two variables.

Real-Life Example 2: Distance and Time

Solutions to a Linear Equation in Two Variables

  • A pair of values (x, y) that satisfies the equation.
  • When substituted into the equation, it makes the statement true.
  • Example: For x + y = 5, (2, 3) is a solution because 2 + 3 = 5.

🎙️ Unlike one-variable equations which have a single solution, an equation in two variables has a pair of values (x, y) that works. This pair, when substituted back into the equation, will make both sides equal.

Finding Solutions (Trial & Error)

  • Choose a value for one variable (e.g., x).
  • Substitute it into the equation.
  • Solve for the other variable (e.g., y).
  • Repeat to find multiple solution pairs.

🎙️ Let's find solutions for x + y = 7. If x = 1, then 1 + y = 7, so y = 6. The pair is (1, 6). If x = 3, then 3 + y = 7, so y = 4. The pair is (3, 4). We can keep doing this.

Infinitely Many Solutions

  • A single linear equation in two variables has countless solutions.
  • For every chosen 'x' value, there's a corresponding 'y' value.
  • These solutions form a line when plotted on a graph.

🎙️ This is a key difference from one-variable equations. For any linear equation in two variables, there are infinitely many pairs of (x, y) that will satisfy it. This is why we often need more information or another equation.

Graphing Linear Equations

  • All solutions of a linear equation in two variables lie on a straight line.
  • The graph visually represents all possible solutions.
  • Helps to understand the relationship between variables.

🎙️ Plotting these (x, y) solution pairs on a coordinate plane will always result in a straight line. This line is the graphical representation of the equation, showing all its infinite solutions.

Steps to Graph a Linear Equation

  • 1. Find at least two (preferably three) solutions (x, y) for the equation.
  • 2. Plot these ordered pairs on a Cartesian coordinate system.
  • 3. Draw a straight line passing through these points.
  • 4. Extend the line with arrows on both ends.

🎙️ To draw the graph, we need at least two points. A third point is good for checking accuracy. Once plotted, use a ruler to connect them and extend the line, indicating it goes on infinitely.

Simultaneous Linear Equations

  • A pair of two linear equations in two variables.
  • We seek a single pair of (x, y) values that satisfies BOTH equations.
  • This unique solution is the point where their graphs intersect.

🎙️ When we have two linear equations involving the same two variables, we call them simultaneous equations. Our goal is to find one specific (x, y) pair that works for both equations at the same time.

🎙️ There are several algebraic ways to solve simultaneous equations. Today, we'll focus on two main methods: substitution and equating coefficients. Both aim to reduce the problem to a single variable.

Method 1: Elimination by Substitution

  • 1. Express one variable in terms of the other from one equation.
  • 2. Substitute this expression into the second equation.
  • 3. Solve the resulting linear equation in one variable.
  • 4. Substitute the found value back to find the other variable.

🎙️ In the substitution method, we isolate one variable in one equation and then 'plug' that expression into the other equation. This eliminates one variable, leaving us with a simpler equation to solve.

2Substitute
3Solve for 1 Variable
4Find 2nd Variable

Worked Example: Substitution Method

  • Equations: (1) x + y = 7, (2) x - y = 1
  • From (1), x = 7 - y. Substitute into (2): (7 - y) - y = 1
  • 7 - 2y = 1 => -2y = -6 => y = 3
  • Substitute y = 3 into x = 7 - y => x = 7 - 3 => x = 4. Solution: (4, 3)

🎙️ Let's solve x + y = 7 and x - y = 1. From the first equation, we can write x = 7 - y. Now, replace 'x' in the second equation with '7 - y'. This gives us 7 - y - y = 1, which simplifies to 7 - 2y = 1. Solving this, we get y = 3. Finally, substitute y=3 back into x = 7 - y to find x=4. So, the solution is (4, 3).

Method 2: Elimination by Equating Coefficients

  • 1. Multiply equations to make coefficients of one variable equal.
  • 2. Add or subtract the equations to eliminate that variable.
  • 3. Solve the resulting linear equation in one variable.
  • 4. Substitute the found value back into original equation to find the other.

🎙️ In this method, we strategically multiply one or both equations by a number so that one of the variables has the same coefficient in both equations. Then, we either add or subtract the equations to eliminate that variable.

Worked Example: Equating Coefficients Method

  • Equations: (1) 2x + 3y = 13, (2) 5x - 2y = 4
  • Multiply (1) by 2, (2) by 3: (1') 4x + 6y = 26, (2') 15x - 6y = 12
  • Add (1') and (2'): (4x + 6y) + (15x - 6y) = 26 + 12 => 19x = 38 => x = 2
  • Substitute x = 2 into (1): 2(2) + 3y = 13 => 4 + 3y = 13 => 3y = 9 => y = 3. Solution: (2, 3)

🎙️ For 2x + 3y = 13 and 5x - 2y = 4, let's eliminate 'y'. Multiply the first by 2 and the second by 3. This gives 4x + 6y = 26 and 15x - 6y = 12. Adding these new equations eliminates 'y', giving 19x = 38, so x = 2. Substitute x=2 into the first original equation to find y=3. The solution is (2, 3).

Quick Question 2

  • Is (1, 2) a solution to the equation 3x + 2y = 7?
  • A) Yes
  • B) No
  • C) Cannot be determined

🎙️ To check if (1, 2) is a solution, substitute x=1 and y=2 into the equation. If both sides are equal, then it's a solution. 3(1) + 2(2) = 3 + 4 = 7. So, the answer is A, Yes.
