Arithmetic Progression (AP): The Staircase Rule

  • Imagine climbing a staircase where each step has the exact same height.
  • You add the same 'height' (distance) with each step.
  • This constant addition is key to an AP!

🎙️ Just like a perfectly built staircase, an Arithmetic Progression is a sequence where the difference between any two consecutive terms is always the same. This 'same height' or 'same distance' is super important.

🪜
Equal Steps

Defining Arithmetic Progression (AP)

  • An Arithmetic Progression (AP) is a sequence where the difference between any term and its preceding term is constant.
  • This constant difference is called the 'common difference', denoted by 'd'.
  • d = a(n+1) - an (for any n).

🎙️ The common difference 'd' can be positive, negative, or even zero. If 'd' is positive, the terms increase. If 'd' is negative, the terms decrease. If 'd' is zero, all terms are the same.

a2 - a1
a3 - a2
a4 - a3
10 / 30

Example: Identifying an AP

  • Is the sequence 7, 10, 13, 16, ... an AP?
  • Calculate the difference between consecutive terms:
  • 10 - 7 = 3
  • 13 - 10 = 3
  • 16 - 13 = 3
  • Since the difference is constant (d=3), YES, it's an AP!

🎙️ To check if a sequence is an AP, always calculate the difference between at least two pairs of consecutive terms. If they are all the same, then you've found an AP!

General Form of an AP: The Blueprint

  • If 'a' is the first term and 'd' is the common difference, an AP can be written as:
  • a, a + d, a + 2d, a + 3d, ...
  • Each term is found by adding 'd' to the previous term.

🎙️ This general form is like a blueprint for any AP. If you know the first term 'a' and the common difference 'd', you can write out the entire progression, no matter how long it is.

1a (1st term)
2a+d (2nd term)
3a+2d (3rd term)
4a+3d (4th term)
13 / 30

Example: Writing an AP

  • Write the first 4 terms of an AP where a = 5 and d = 2.
  • 1st term (a1) = a = 5
  • 2nd term (a2) = a + d = 5 + 2 = 7
  • 3rd term (a3) = a + 2d = 5 + 2(2) = 9
  • 4th term (a4) = a + 3d = 5 + 3(2) = 11
  • The AP is: 5, 7, 9, 11, ...

🎙️ This example shows how straightforward it is to construct an AP once you have its fundamental building blocks: the first term and the common difference. Practice writing a few more!

The Formula for the nth Term (tn)

  • We know: a1 = a
  • a2 = a + d
  • a3 = a + 2d
  • a4 = a + 3d
  • Notice the pattern: the coefficient of 'd' is always one less than the term number.
  • So, the nth term: tn = a + (n-1)d

🎙️ This formula, tn = a + (n-1)d, is one of the most important in this chapter. It connects the first term (a), the common difference (d), and the position of the term (n) to give you the value of that term (tn).

1a
2a + d
3a + 2d
4a + (n-1)d
16 / 30

Example: Finding a Specific Term

  • Find the 10th term of the AP: 2, 7, 12, ...
  • Here, a = 2, d = 7 - 2 = 5, n = 10.
  • Using tn = a + (n-1)d
  • t10 = 2 + (10 - 1) * 5
  • t10 = 2 + 9 * 5 = 2 + 45 = 47.
  • The 10th term is 47.

🎙️ Always identify 'a', 'd', and 'n' first before plugging them into the formula. This systematic approach helps avoid errors and ensures you get the correct answer.

Example: Finding 'n' or 'd'

  • Which term of the AP: 21, 18, 15, ... is -81?
  • Here, a = 21, d = 18 - 21 = -3, tn = -81.
  • Using tn = a + (n-1)d
  • -81 = 21 + (n-1)(-3)
  • -81 - 21 = -3(n-1)
  • -102 = -3(n-1)
  • 34 = n-1 => n = 35.
  • The 35th term is -81.

🎙️ The nth term formula is versatile! You can use it to find any of the four variables (tn, a, n, d) if the other three are known. It's like a puzzle where you fill in the missing piece.

Sum of n Terms: The Story of Young Gauss

  • When Gauss was a child, his teacher asked the class to sum numbers from 1 to 100.
  • Gauss quickly found the answer without adding them one by one.
  • He noticed a clever pattern: (1+100) + (2+99) + ...
  • We'll learn his trick!

🎙️ Adding many numbers can be very time-consuming. But for an AP, there's a brilliant shortcut, just like Gauss discovered. This formula will save you a lot of time and effort!

🧠
Gauss's Trick

The Formula for Sum of n Terms (Sn)

  • Sn = a + (a+d) + (a+2d) + ... + [a + (n-1)d]
  • Also, Sn = [a + (n-1)d] + [a + (n-2)d] + ... + a
  • Adding these two equations gives: 2Sn = n * [2a + (n-1)d]
  • Therefore, Sn = n/2 [2a + (n-1)d]

🎙️ This formula helps us sum up a large number of terms in an AP very efficiently. It's derived by pairing the first term with the last, the second with the second-to-last, and so on.

1S_n = a + ... + t_n
2S_n = t_n + ... + a
32S_n = n * (a + t_n)
4S_n = n/2 [2a + (n-1)d]
21 / 30

Alternative Sum Formula (When Last Term is Known)

  • We know that tn = a + (n-1)d. Let tn be the last term, 'l'.
  • So, Sn = n/2 [a + {a + (n-1)d}] can be written as:
  • Sn = n/2 [a + l]
  • This formula is very handy if you already know the first term 'a' and the last term 'l'.

🎙️ Both formulas are essentially the same, just expressed differently. Choose the one that best suits the information given in the problem. If 'l' is given, the second form is quicker!

Example: Finding the Sum (Using 2a + (n-1)d)

  • Find the sum of the first 20 terms of the AP: 1, 4, 7, 10, ...
  • Here, a = 1, d = 3, n = 20.
  • Using Sn = n/2 [2a + (n-1)d]
  • S20 = 20/2 [2(1) + (20-1)3]
  • S20 = 10 [2 + 19 * 3]
  • S20 = 10 [2 + 57] = 10 * 59 = 590.
  • The sum is 590.

🎙️ Again, carefully identify 'a', 'd', and 'n'. Substitute them into the formula and perform the calculations step-by-step to avoid any arithmetic errors.

Example: Finding the Sum (Using a + l)

Interesting Properties of an AP

  • If a constant is added to or subtracted from each term of an AP, the resulting sequence is also an AP with the same common difference.
  • If each term of an AP is multiplied or divided by a non-zero constant, the resulting sequence is also an AP.
  • The sum of terms equidistant from the beginning and end of an AP is constant.

🎙️ These properties can sometimes simplify problems or help you understand the nature of APs better. For instance, if you shift all values by a constant, the 'gap' between them remains the same!

Beware of Common Mistakes!

  • Confusing 'n' with 'tn': 'n' is the position, 'tn' is the value at that position.
  • Sign errors: Especially when 'd' is negative, be careful with (n-1)d.
  • Using the wrong formula: For sum vs. nth term, or mixing up '2a' with 'a+l'.
  • Calculation errors: Double-check your arithmetic, especially with fractions or large numbers.

🎙️ Many errors happen due to rushing or not reading the question carefully. Always write down what you know (a, d, n, tn, Sn) before attempting to solve. Practice makes perfect!
