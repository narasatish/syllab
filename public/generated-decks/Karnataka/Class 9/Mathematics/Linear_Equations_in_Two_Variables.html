Variables and Constants: Formal Terms

  • Variable: A symbol (usually a letter) that represents a value that can change.
  • Constant: A value that remains fixed and does not change.
  • Examples: x, y (variables); 2, 5, -7 (constants).

🎙️ In mathematics, variables are symbols, often letters like x or y, that stand for quantities that can take on different values. Constants, on the other hand, are fixed numerical values that do not change. This distinction is crucial for equations.

🎙️ A linear equation in two variables is an equation that can be written in a specific form, where there are two distinct variables, and the highest power of each variable is one. These equations describe a linear relationship between two quantities.

Standard Form of Linear Equations in Two Variables

  • The general form is ax + by + c = 0.
  • a, b, c are real numbers.
  • Crucially, 'a' and 'b' cannot both be zero.
  • Example: 3x + 4y - 12 = 0.

🎙️ The standard form is like the blueprint for these equations. It's ax + by + c = 0, where a, b, and c are real numbers. The important condition is that 'a' and 'b' cannot both be zero, otherwise, it wouldn't be a two-variable equation anymore.

Solutions of a Linear Equation in Two Variables

  • A solution is a pair of values (x, y).
  • When substituted into the equation, it makes the equation true.
  • Example: For x + y = 5, (2, 3) is a solution because 2 + 3 = 5.

🎙️ What does 'solving' mean for these equations? A solution is not just one number, but a pair of numbers, one for 'x' and one for 'y'. When you plug these values into the equation, the left side must equal the right side, making the statement true.

How Many Solutions Can There Be? (Infinite Possibilities!)

  • Unlike one-variable equations, two-variable equations have infinite solutions.
  • For any 'x' value you choose, you can find a corresponding 'y' value.
  • Example: y = 2x + 1. If x=0, y=1; if x=1, y=3; if x=2, y=5...

🎙️ This is a key difference! A linear equation in one variable has exactly one solution. But for an equation in two variables, there are infinitely many solutions! You can pick any value for 'x', and you'll always find a 'y' that satisfies the equation.

Worked Example 2: Finding Solutions

  • Equation: x + y = 7.
  • Let x = 0: 0 + y = 7 => y = 7. Solution: (0, 7).
  • Let x = 3: 3 + y = 7 => y = 4. Solution: (3, 4).
  • Let y = 1: x + 1 = 7 => x = 6. Solution: (6, 1).

🎙️ Let's find some solutions for the equation x + y = 7. We can choose any value for x or y, substitute it into the equation, and then solve for the other variable. Remember to write your solution as an ordered pair (x, y).

Equations of Lines Parallel to Axes

  • Equation x = k: Represents a vertical line, parallel to the y-axis.
  • Equation y = k: Represents a horizontal line, parallel to the x-axis.
  • 'k' is any real number (a constant).

🎙️ Sometimes, linear equations can look simpler, like x = k or y = k. When you see x = k (e.g., x=3), it means all points on that line have an x-coordinate of 3, forming a vertical line. Similarly, y = k forms a horizontal line.

  • Problem: Auto fare is ₹10 for the first km, and ₹6 for every subsequent km.
