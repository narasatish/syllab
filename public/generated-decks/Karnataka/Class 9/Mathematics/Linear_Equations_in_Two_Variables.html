Defining Linear Equations in Two Variables

  • An equation with two variables (usually x and y).
  • The highest power of each variable is 1.
  • No product of variables (like xy) exists.

🎙️ A linear equation in two variables is an equation that can be written in a specific form, where we have two unknowns, typically 'x' and 'y'. The key is that neither variable is raised to a power higher than one, and they are not multiplied together.

The Standard Form: ax + by + c = 0

  • Any linear equation in two variables can be written in this form.
  • a, b, and c are real numbers.
  • a and b cannot both be zero simultaneously.

🎙️ This is the general or standard form for a linear equation in two variables. 'a', 'b', and 'c' are constants, and 'x' and 'y' are our variables. Remember, if both 'a' and 'b' were zero, it wouldn't be an equation with variables anymore.

What are the Solutions?

  • A solution is a pair of values (x, y) that satisfies the equation.
  • When substituted, the left-hand side equals the right-hand side.
  • Example: For x + y = 5, (2, 3) is a solution.

🎙️ Unlike linear equations in one variable which have a single solution, linear equations in two variables have pairs of solutions. Each pair of values for x and y makes the equation true. Let's see how to find them.

Finding Solutions: Guess & Check Method

  • Choose an arbitrary value for one variable (e.g., x).
  • Substitute this value into the equation.
  • Solve the resulting linear equation for the other variable (y).

🎙️ One simple way to find solutions is by picking a value for one variable, say 'x'. Then, substitute it into the equation and solve for 'y'. This gives you an ordered pair (x, y) that is a solution.

1Pick a value for x
2Substitute into equation
3Solve for y
4Write as (x, y) pair

Worked Example: Find 3 Solutions for 2x + y = 6

  • If x = 0, then 2(0) + y = 6 => y = 6. Solution: (0, 6).
  • If x = 1, then 2(1) + y = 6 => y = 4. Solution: (1, 4).
  • If y = 0, then 2x + 0 = 6 => x = 3. Solution: (3, 0).

🎙️ Let's work through this example together. By choosing different values for x or y, we can systematically find multiple solution pairs. Notice how each pair satisfies the equation 2x + y = 6.

Infinite Solutions: Many Possibilities!

  • A linear equation in two variables has infinitely many solutions.
  • You can always find another pair of (x, y) that satisfies it.
  • This is why we can't list all solutions.

🎙️ This is a crucial point: unlike single-variable equations, linear equations in two variables don't have just one answer. They have an infinite number of solutions, each represented by an (x, y) pair. This concept becomes clear when we graph them.

Visualizing Solutions: The Graph

  • The graph of every linear equation in two variables is a straight line.
  • Every point on this line represents a solution to the equation.
  • Conversely, every solution lies on this line.

🎙️ When we plot all the possible solutions of a linear equation in two variables on a coordinate plane, they form a straight line. This line is a powerful visual representation of all the solutions to the equation.

How to Plot the Graph?

  • Find at least two solutions (x, y) for the equation.
  • Plot these ordered pairs on a Cartesian plane.
  • Draw a straight line passing through these points.

🎙️ To draw the graph, we need at least two distinct points. Finding three points is a good practice to ensure accuracy and catch any calculation errors. Once plotted, simply connect them with a ruler to form the line.

1Find 2-3 solutions
2Plot points on graph
3Draw a straight line
4Label the line

Worked Example: Graph for x + y = 4

  • Solutions: (0, 4), (4, 0), (2, 2).
  • Plot (0, 4) on the y-axis.
  • Plot (4, 0) on the x-axis.
  • Plot (2, 2) in the first quadrant and draw the line.

🎙️ Let's take the equation x + y = 4. We found solutions like (0, 4), (4, 0), and (2, 2). When you plot these points on graph paper and connect them, you will see a perfectly straight line. Remember to label your axes and the line itself.

Special Cases: Equations of Lines Parallel to Axes

  • Equations like x = k represent vertical lines.
  • Equations like y = k represent horizontal lines.
  • These are also linear equations in two variables.

🎙️ Sometimes, one of the coefficients 'a' or 'b' in the standard form ax + by + c = 0 might be zero. This leads to special lines. For example, if a = 0, we get by + c = 0, which simplifies to y = -c/b, a horizontal line.

Equation of the X-axis and Y-axis

  • The equation of the X-axis is y = 0.
  • Every point on the X-axis has a y-coordinate of 0.
  • The equation of the Y-axis is x = 0.
  • Every point on the Y-axis has an x-coordinate of 0.

🎙️ The coordinate axes themselves are examples of these special lines. The x-axis is a horizontal line where all y-coordinates are zero, so its equation is y=0. Similarly, the y-axis is a vertical line where all x-coordinates are zero, so its equation is x=0.

Key Takeaways from Our Lesson

  • A linear equation in two variables has the form ax + by + c = 0.
  • It has infinitely many solutions (x, y) pairs.
  • Its graph is always a straight line.
  • It models many real-world relationships.

🎙️ To summarize, we've learned the definition, standard form, and how to find solutions for linear equations in two variables. Remember that these equations are powerful tools for representing and understanding relationships between two quantities, and their graph is always a straight line.
