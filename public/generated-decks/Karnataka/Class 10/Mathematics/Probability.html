What is Probability?

  • Measures the likelihood of an event
  • Expressed as a number between 0 and 1
  • Helps predict future outcomes

🎙️ Probability is simply a way to quantify how likely something is to happen. Think of it as a numerical value that tells us the chance of an event occurring. It's always a value between zero and one, where zero means impossible and one means certain.

Key Terms: Experiment & Outcome

  • Experiment: An action with well-defined results
  • Outcome: A possible result of an experiment
  • Example: Tossing a coin is an experiment

🎙️ Before we dive deeper, let's understand some basic terms. An experiment is any action that produces a set of results, like flipping a coin or rolling a die. Each possible result from that experiment is called an outcome. So, for a coin toss, 'Heads' is an outcome, and 'Tails' is another.

Key Terms: Sample Space

  • Set of ALL possible outcomes of an experiment
  • Represented by 'S'
  • Example: Coin toss S = {Head, Tail}

🎙️ The collection of all possible outcomes for an experiment is called the Sample Space. It's like a complete list of everything that could happen. For example, if you roll a standard six-sided die, your sample space would be {1, 2, 3, 4, 5, 6}.

Key Terms: Event

  • One or more outcomes from an experiment
  • A subset of the sample space
  • Example: Getting a 'Head' when tossing a coin

🎙️ An event is simply one or more specific outcomes that we are interested in. It's a subset of the sample space. For instance, in rolling a die, getting an 'even number' is an event, which includes the outcomes {2, 4, 6}.

The Probability Formula

  • P(E) = (Number of Favorable Outcomes) / (Total Number of Outcomes)
  • P(E) is the probability of Event E
  • Favorable: Outcomes we are interested in

🎙️ This is the core formula! To find the probability of any event 'E', you divide the number of outcomes that satisfy your event (favorable outcomes) by the total number of possible outcomes in the sample space. Remember, this ratio will always be between 0 and 1.

Example 1: Coin Toss

  • Experiment: Toss a coin
  • Sample Space (S) = {Head, Tail}
  • Total Outcomes = 2
  • Event (E): Getting a Head
  • Favorable Outcomes = 1 (Head)

🎙️ Let's apply the formula. When you toss a coin, there are two total possible outcomes: Head or Tail. If our event is 'getting a Head', then there's only one favorable outcome. So, P(Head) = 1/2.

Example 2: Dice Roll

  • Experiment: Roll a standard die
  • Sample Space (S) = {1, 2, 3, 4, 5, 6}
  • Total Outcomes = 6
  • Event (E): Getting an Even Number
  • Favorable Outcomes = {2, 4, 6}

🎙️ Consider rolling a standard six-sided die. The total possible outcomes are 1, 2, 3, 4, 5, or 6. If we want to find the probability of getting an even number, our favorable outcomes are 2, 4, and 6. That's 3 favorable outcomes out of 6 total, so P(Even) = 3/6 = 1/2.

  • Probability values range from 0 to 1
  • 0 means impossible

🎙️ Probability values always fall between 0 and 1. A probability of 0 means an event will definitely not happen, while a probability of 1 means it will definitely happen. A probability of 0.5 indicates an event has an even chance of occurring, like flipping a coin.

Complementary Events

  • Two events where one happens if and only if the other doesn't
  • P(E) + P(not E) = 1
  • P(not E) is also written as P(E') or P(Eᶜ)

🎙️ Complementary events are two events that cover all possibilities and cannot both happen at the same time. If one occurs, the other doesn't. The sum of their probabilities is always 1. This means if you know the probability of an event, you can easily find the probability of it not happening.

Example 3: Complementary Event

  • Event E: Getting a 6 on a die
  • P(E) = 1/6
  • Event 'not E': Not getting a 6
  • P(not E) = 1 - P(E) = 1 - 1/6 = 5/6

🎙️ Let's use our die example again. The probability of getting a 6 is 1/6. The complementary event is 'not getting a 6'. Using the formula, P(not 6) = 1 - P(6) = 1 - 1/6 = 5/6. This makes sense, as there are 5 outcomes (1, 2, 3, 4, 5) that are not 6.

Types of Events: Elementary Event

  • An event with only ONE outcome
  • Example: Getting a 'Head' when tossing a coin
  • Each outcome in a sample space is an elementary event

🎙️ An elementary event is the simplest type of event, consisting of just one single outcome from the experiment. When you flip a coin, 'getting a Head' is an elementary event, and 'getting a Tail' is another elementary event.

Types of Events: Compound Event

  • An event with MORE THAN ONE outcome
  • Example: Getting an 'Even Number' when rolling a die ({2, 4, 6})
  • Formed by combining elementary events

🎙️ In contrast, a compound event consists of two or more outcomes. For example, when you roll a die, the event 'getting an even number' is a compound event because it includes the outcomes 2, 4, and 6. It's a combination of several elementary events.

  • Event (E): Drawing a King
  • Number of Kings = 4 (one for each suit)

Example 5: Drawing a Card (Red)

  • Total cards = 52
  • Event (E): Drawing a Red Card
  • Number of Red Cards = 26 (Hearts + Diamonds)
  • P(Red Card) = 26/52

🎙️ Now, what about drawing a red card? We know there are 26 red cards (Hearts and Diamonds) in a standard 52-card deck. Therefore, the probability of drawing a red card is 26/52, which simplifies to 1/2. This means you have an even chance!

Common Pitfalls

  • Misconception: 'Gambler's Fallacy'
  • Thinking past events influence future independent events
  • Example: If a coin lands on Heads 5 times, Tails is 'due' next (Incorrect!)

🎙️ One common mistake is the 'Gambler's Fallacy'. People often think that if an event has happened many times in a row, the opposite event is 'due' to happen. For example, if you flip a coin and get 5 heads, the probability of getting tails on the next flip is still 1/2, because each flip is an independent event.
