Standard Form: The Blueprint

  • ax + by + c = 0
  • a, b, c are real numbers.
  • a and b are not both zero.

General Form of a Pair

  • a₁x + b₁y + c₁ = 0
  • a₂x + b₂y + c₂ = 0
  • a₁, b₁, c₁, a₂, b₂, c₂ are real numbers.

🎙️ Just like a single equation has a standard form, a pair of equations also has a general representation. We use subscripts (1 and 2) to distinguish the coefficients of the first equation from the second. This helps us compare and analyze them easily.

Solving Graphically: Visualising Solutions

  • Each equation represents a line.
  • Solution is where the lines meet.
  • Three possible cases for two lines.

🎙️ One powerful way to solve a pair of linear equations is by graphing them. Each equation will give you a straight line. The solution to the pair is simply the point where these two lines intersect. Let's explore the three possibilities.

Case 1: Intersecting Lines

  • Lines cross at exactly one point.
  • Unique solution (one solution).
  • Condition: a₁/a₂ ≠ b₁/b₂.

🎙️ When two lines intersect, they cross each other at only one specific point. This means there is exactly one unique solution (x, y) that satisfies both equations. We call such a system 'consistent' and 'independent'.

✖️
Lines crossing
16 / 30

Case 2: Parallel Lines

  • Lines never meet, they run side-by-side.
  • No solution.
  • Condition: a₁/a₂ = b₁/b₂ ≠ c₁/c₂.

🎙️ Imagine two railway tracks that never meet. That's what parallel lines are! If the graphs of your two equations are parallel, they will never intersect, meaning there is no point (x, y) that satisfies both equations. This system is called 'inconsistent'.

⏸️
Parallel tracks

Case 3: Coincident Lines

  • One line lies exactly on top of the other.
  • Infinitely many solutions.
  • Condition: a₁/a₂ = b₁/b₂ = c₁/c₂.

🎙️ Sometimes, if you simplify two equations, they might turn out to be the exact same line! When one line lies completely over the other, every point on that line is a common solution. This means there are infinitely many solutions, and the system is 'consistent' and 'dependent'.

Substitution Method: Swapping Values

  • Express one variable from one equation.
  • Substitute this expression into the second equation.
  • Solve the resulting single-variable equation.
  • Find the value of the other variable.

🎙️ Think of substitution like replacing a player in a game. You express one variable in terms of the other from one equation, then 'substitute' that entire expression into the second equation. This leaves you with a simpler equation with just one variable to solve.

1Isolate variable
2Substitute
3Solve for 1st
4Solve for 2nd
21 / 30

Example: Substitution Method

  • Solve: x + y = 10 (1), x - y = 2 (2)
  • From (2), x = 2 + y
  • Substitute x in (1): (2 + y) + y = 10
  • 2 + 2y = 10 => 2y = 8 => y = 4
  • Substitute y = 4 in x = 2 + y => x = 2 + 4 => x = 6
  • Solution: (x, y) = (6, 4)

🎙️ Let's walk through an example. We take x - y = 2 and find x = 2 + y. Then, we replace 'x' in the first equation with '2 + y'. This gives us an equation only in 'y', which we can solve. Once 'y' is found, we easily find 'x'.

22 / 30

Elimination Method: Making Variables Disappear!

  • Make coefficients of one variable equal.
  • Add or subtract equations to 'eliminate' that variable.
  • Solve for the remaining variable.
  • Substitute back to find the eliminated variable.

🎙️ Elimination is like removing one item from a list. We strategically multiply equations so that the coefficients of one variable become the same. Then, by adding or subtracting the equations, that variable 'disappears', leaving us with a single-variable equation.

1Match coefficients
2Add/Subtract
3Solve for 1st
4Solve for 2nd
23 / 30

Example: Elimination Method

  • Solve: 2x + 3y = 11 (1), 2x - 2y = 6 (2)
  • Subtract (2) from (1): (2x + 3y) - (2x - 2y) = 11 - 6
  • 5y = 5 => y = 1
  • Substitute y = 1 in (1): 2x + 3(1) = 11
  • 2x + 3 = 11 => 2x = 8 => x = 4
  • Solution: (x, y) = (4, 1)

🎙️ Here, notice that the 'x' coefficients are already the same. So, we can directly subtract the second equation from the first. This eliminates 'x', leaving us with an equation for 'y'. Once 'y' is found, we substitute it back into either original equation to find 'x'.

Cross-Multiplication Method: The 'Butterfly' Way!

  • Works directly with coefficients.
  • Uses a specific formula derived from elimination.
  • Quick for competitive exams once mastered.

🎙️ The cross-multiplication method is a formula-based approach that can be very fast if you remember the pattern. It's often visualized as a 'butterfly' pattern when writing down the coefficients. Ensure your equations are in the standard form (ax + by + c = 0) before applying this method.

🦋
Cross-multiplication pattern
25 / 30

Example: Cross-Multiplication Method

  • Equations: x + 2y - 4 = 0, 2x + y - 5 = 0
  • Coefficients: a₁=1, b₁=2, c₁=-4; a₂=2, b₂=1, c₂=-5
  • x / (b₁c₂ - b₂c₁) = y / (c₁a₂ - c₂a₁) = 1 / (a₁b₂ - a₂b₁)
  • x / (2(-5) - 1(-4)) = y / ((-4)(2) - (-5)(1)) = 1 / (1(1) - 2(2))
  • x / (-10 + 4) = y / (-8 + 5) = 1 / (1 - 4)
  • x / -6 = y / -3 = 1 / -3
  • x = (-6)/(-3) = 2, y = (-3)/(-3) = 1
  • Solution: (x, y) = (2, 1)

🎙️ This method requires careful handling of coefficients and signs. Write down the coefficients in order, then apply the cross-multiplication formula. Practice helps in remembering the sequence and avoiding errors.
