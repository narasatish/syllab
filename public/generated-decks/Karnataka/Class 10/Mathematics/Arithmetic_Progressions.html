Introduction to Arithmetic Progression (AP)

  • A sequence where the difference between consecutive terms is constant.
  • This constant difference is called the 'common difference'.
  • Example: 2, 4, 6, 8, ... (difference is 2)

🎙️ An Arithmetic Progression, or AP, is a very special type of sequence. It's one where the jump from one term to the next is always the same. This consistent jump is key to understanding APs.

The Common Difference (d)

  • The fixed number added to get the next term.
  • Found by subtracting any term from its succeeding term (a₂ - a₁).
  • Can be positive, negative, or zero.

🎙️ The 'common difference', denoted by 'd', is the heart of an AP. It's the constant value that you add to any term to get the next term in the sequence. Remember, 'd' can be a positive number, a negative number, or even zero.

General Form of an AP

  • An AP can be represented as: a, a+d, a+2d, a+3d, ...
  • 'a' is the first term.
  • 'd' is the common difference.

🎙️ The general form helps us understand any AP by just knowing its first term 'a' and its common difference 'd'. Every term in the sequence can be expressed using these two values. This pattern is fundamental to solving problems related to APs.

1First term: a
2Second term: a+d
3Third term: a+2d
4Fourth term: a+3d

The nth Term of an AP (a_n)

  • The formula to find any term in an AP.
  • a_n = a + (n-1)d
  • Where a_n is the nth term, a is the first term, n is the term number, and d is the common difference.

🎙️ This formula is incredibly powerful as it allows us to find any term in an AP without having to list all the preceding terms. If you know the first term, the common difference, and which term you want, you can find it directly.

Finding any term

Understanding the nth Term Formula

  • First term (n=1): a + (1-1)d = a
  • Second term (n=2): a + (2-1)d = a+d
  • Third term (n=3): a + (3-1)d = a+2d
  • The common difference 'd' is added (n-1) times.

🎙️ Let's break down why the formula a_n = a + (n-1)d works. To get to the nth term, you start with the first term 'a' and then you add the common difference 'd' a total of 'n-1' times. This makes perfect sense when you look at how each term is formed.

Worked Example: Finding a Specific Term

  • Find the 10th term of the AP: 2, 7, 12, ...
  • Here, a = 2, d = 7-2 = 5, n = 10.
  • a₁₀ = a + (10-1)d = 2 + (9)5 = 2 + 45 = 47.

🎙️ Let's apply the formula to find the 10th term of the AP 2, 7, 12, ... . First, identify 'a', 'd', and 'n'. Then, substitute these values into the formula and perform the calculation to find the desired term.

Worked Example: Finding 'n' (Number of Terms)

  • Which term of the AP: 21, 18, 15, ... is -81?
  • a = 21, d = 18-21 = -3, a_n = -81.
  • -81 = 21 + (n-1)(-3) => -102 = (n-1)(-3)
  • 34 = n-1 => n = 35. So, -81 is the 35th term.

🎙️ Sometimes, we know the value of a term but need to find its position in the AP. In this example, we use the same nth term formula, but this time we solve for 'n' after plugging in the known values. This helps us find which term in the sequence equals -81.

Worked Example: Finding 'a' or 'd'

  • If the 3rd term of an AP is 7 and the 7th term is 15.
  • a₃ = a + 2d = 7 (Eq 1)
  • a₇ = a + 6d = 15 (Eq 2)
  • Subtracting (1) from (2): 4d = 8 => d = 2. Substitute d=2 in (1): a + 2(2) = 7 => a = 3.

🎙️ When given two terms of an AP, we can form a system of linear equations using the nth term formula. By solving these simultaneous equations, we can find both the first term 'a' and the common difference 'd' of the AP. This is a common problem type.

Sum of First 'n' Terms of an AP (S_n)

  • Sometimes we need to add up the terms of an AP.
  • For example, total salary earned over 'n' years.
  • This sum is denoted by S_n.

🎙️ Beyond finding individual terms, we often need to calculate the total sum of a certain number of terms in an AP. This is useful in many practical scenarios, such as calculating total interest or total distance covered.

Formula for Sum of 'n' Terms

  • S_n = n/2 [2a + (n-1)d]
  • Alternatively, if the last term (l or a_n) is known: S_n = n/2 [a + l]
  • Where 'l' is the last term.

🎙️ We have two main formulas for the sum of 'n' terms. The first uses 'a' and 'd', which you already know. The second is a simpler version if you happen to know the first term 'a' and the last term 'l' of the AP.

How the Sum Formula Works (Briefly)

  • Imagine writing the sum forwards and backwards.
  • Adding corresponding terms gives a constant sum.
  • This helps derive the formula easily.

🎙️ The sum formula has an interesting origin, often attributed to young Gauss. By writing the sum of an AP both forwards and backwards, and then adding them vertically, you'll notice a clever pattern that simplifies the calculation significantly. This trick makes the formula intuitive.

Worked Example: Calculating S_n

  • Find the sum of the first 20 terms of the AP: 1, 3, 5, 7, ...
  • a = 1, d = 2, n = 20.
  • S₂₀ = 20/2 [2(1) + (20-1)2] = 10 [2 + 19(2)]
  • S₂₀ = 10 [2 + 38] = 10 [40] = 400.

🎙️ Let's find the sum of the first 20 terms of this AP. First, identify the first term 'a', the common difference 'd', and the number of terms 'n'. Then, substitute these values into the sum formula and carefully calculate the result.

1Identify a, d, n
2Apply formula S_n = n/2 [2a + (n-1)d]
3Calculate the sum

Worked Example: S_n with Last Term

  • Find the sum of the AP: 2, 5, 8, ..., 32.
  • Here a = 2, l = 32. First find n: 32 = 2 + (n-1)3 => 30 = (n-1)3 => 10 = n-1 => n = 11.
  • S₁₁ = 11/2 [2 + 32] = 11/2 [34] = 11 * 17 = 187.

🎙️ When the last term 'l' is given, it's often easier to use the second sum formula. However, you might first need to find the number of terms 'n' using the nth term formula before you can apply the sum formula. This example demonstrates that process.

1Identify a, l. Find n.
2Apply formula S_n = n/2 [a + l]
3Calculate the sum

Recap: Arithmetic Progressions

  • AP: sequence with constant common difference 'd'.
  • General form: a, a+d, a+2d, ...
  • nth term: a_n = a + (n-1)d
  • Sum of n terms: S_n = n/2 [2a + (n-1)d] or S_n = n/2 [a + l]

🎙️ We've covered a lot today! Remember that an AP is defined by its constant common difference. We learned how to find any specific term and how to calculate the sum of a given number of terms using powerful formulas. These are the core concepts of Arithmetic Progressions.
