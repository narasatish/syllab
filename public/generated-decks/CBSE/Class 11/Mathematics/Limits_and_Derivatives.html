Intuitive Understanding of a Limit

  • Value a function approaches
  • As input approaches a specific number
  • Not necessarily the function's value AT that point

🎙️ Think of a limit as a target. As our input 'x' gets closer and closer to a certain number, the function's output 'f(x)' gets closer and closer to a specific value. This target value is the limit.

Left-Hand and Right-Hand Limits

  • Approach from values less than 'a'
  • Approach from values greater than 'a'
  • Both must lead to the same value

🎙️ To truly understand how a function behaves near a point, we must consider approaching it from both sides: from values smaller than 'a' (left-hand limit) and from values larger than 'a' (right-hand limit).

1LHL: x → a⁻
2RHL: x → a⁺

When Does a Limit Exist?

  • LHL must be equal to RHL
  • Both must be finite values
  • Then the limit exists and equals that value

🎙️ For the limit of a function to exist at a point 'a', the value the function approaches from the left side must be exactly the same as the value it approaches from the right side. This is the fundamental condition.

Worked Example: Direct Substitution (Polynomial)

  • Evaluate: lim (x→2) (x² + 3x + 1)
  • Substitute x=2 directly
  • Result: 2² + 3(2) + 1 = 4 + 6 + 1 = 11

🎙️ For polynomial functions and many other well-behaved functions, if direct substitution does not lead to an indeterminate form, it is the simplest way to evaluate the limit. Always try this first!

8 / 25

Worked Example: Rational Function (Direct Substitution)

  • Evaluate: lim (x→1) (x + 2) / (x + 1)
  • Substitute x=1 directly
  • Result: (1 + 2) / (1 + 1) = 3 / 2

🎙️ Again, in this case, direct substitution works perfectly fine because the denominator does not become zero. This indicates that the function is continuous at x=1, and the limit is simply the function's value.

What are Indeterminate Forms?

  • Expressions like 0/0, ∞/∞, ∞-∞
  • Cannot be determined directly
  • Require algebraic manipulation

🎙️ When direct substitution results in forms like 0/0, it doesn't mean the limit doesn't exist. It means we need to do more work. These are 'indeterminate' because their actual value depends on how the numerator and denominator approach zero.

Technique 1: Factorisation Method

  • Factorize numerator and denominator
  • Cancel common factors
  • Then substitute the limit value

🎙️ The factorisation method is very effective when you have polynomial expressions that result in 0/0. By cancelling the common factor (x-a), you eliminate the problematic term causing the zero in the denominator.

1Factorize Expressions
2Cancel Common Factors
3Substitute Limit Value
11 / 25

Example: Factorisation Method

  • Evaluate: lim (x→2) (x² - 4) / (x - 2)
  • Factorize x² - 4 to (x - 2)(x + 2)
  • Cancel (x - 2), then substitute x=2: 2 + 2 = 4

🎙️ Here, direct substitution gives 0/0. By factoring the numerator into (x-2)(x+2), we can cancel the (x-2) term, which was causing the denominator to be zero. After cancellation, direct substitution yields the limit.

12 / 25

Technique 2: Rationalisation Method

  • Used for expressions with square roots
  • Multiply by conjugate of root term
  • Simplify and then substitute

🎙️ When you see square roots in a limit problem that gives 0/0, rationalisation is often the way to go. Multiplying by the conjugate helps eliminate the square root and usually creates a factor that can be cancelled.

1Identify Roots
2Multiply by Conjugate
3Simplify & Substitute
13 / 25

Example: Rationalisation Method

  • Evaluate: lim (x→0) (√(1+x) - 1) / x
  • Multiply numerator & denominator by (√(1+x) + 1)
  • Simplify to 1 / (√(1+x) + 1), then substitute x=0: 1 / (1+1) = 1/2

🎙️ This is a classic example where rationalisation helps. Notice how the (a-b)(a+b) = a²-b² identity simplifies the numerator, allowing us to cancel the 'x' term in the denominator that was causing the 0/0 form.

Properties of Limits (Algebra of Limits)

  • Sum Rule: lim(f+g) = lim f + lim g
  • Product Rule: lim(f*g) = lim f * lim g
  • Quotient Rule: lim(f/g) = lim f / lim g (if lim g ≠ 0)
  • Constant Multiple Rule: lim(c*f) = c * lim f

🎙️ Limits behave very nicely with basic arithmetic operations. These properties allow us to break down complex limit problems into simpler ones, evaluating each part separately and then combining the results.

What are Derivatives? (Rate of Change)

  • Measure of how a function changes
  • Instantaneous rate of change
  • Slope of the tangent line

🎙️ While limits help us understand behavior near a point, derivatives tell us exactly how fast a function is changing at a specific point. Think of it like the instantaneous speed of a moving object.

🚀
Instantaneous speed
17 / 25

Defining Derivative: First Principles

  • f'(x) = lim (h→0) [f(x+h) - f(x)] / h
  • Also known as the delta method
  • Fundamental definition of the derivative

🎙️ This formula is the very heart of derivatives. It represents the limit of the average rate of change over an infinitesimally small interval 'h', giving us the instantaneous rate of change.

1Find f(x+h)
2Calculate Difference
3Divide by h
4Apply Limit (h→0)

Derivative as Slope of Tangent

  • Derivative at 'x' is slope of tangent
  • Tangent touches curve at one point
  • Reveals direction & steepness of curve

🎙️ Geometrically, the derivative of a function at a point 'x' is the slope of the tangent line to the curve at that point. This visual connection helps us understand what the numerical value of a derivative actually represents.

Worked Example: Derivative of x² from First Principles

  • Function: f(x) = x²
  • f(x+h) = (x+h)² = x² + 2xh + h²
  • f'(x) = lim (h→0) [(x² + 2xh + h²) - x²] / h
  • Simplify: lim (h→0) [2xh + h²] / h = lim (h→0) [2x + h] = 2x

🎙️ Let's apply the first principles definition to find the derivative of x². Notice how the 'h' in the denominator cancels out after simplification, allowing us to substitute h=0 and find the derivative, which is 2x.

Avoid These Common Mistakes!

  • Assuming limit exists if f(a) is defined
  • Incorrectly cancelling terms (e.g., x/x = 1 when x=0)
  • Forgetting to apply the limit operator
  • Confusing average vs. instantaneous rate

🎙️ Students often make crucial errors. Remember, a function being defined at 'a' doesn't guarantee the limit exists. Also, be careful with algebraic manipulations, especially when dealing with variables that approach zero.

Rules for Differentiation

  • Power Rule: d/dx (xⁿ) = nxⁿ⁻¹
  • Sum/Difference Rule: d/dx (f±g) = f'±g'
  • Product Rule: d/dx (fg) = f'g + fg'
  • Quotient Rule: d/dx (f/g) = (f'g - fg') / g²

🎙️ Just like limits, derivatives also have rules for arithmetic operations. These rules simplify the process of finding derivatives immensely, especially for complex functions, without having to use first principles every time.
