The Concept of a Limit: A Formal Look

  • The value a function 'approaches' as input approaches a point.
  • Not necessarily the function's value at that point.
  • Involves the idea of a 'neighbourhood' around the point.

🎙️ Formally, a limit exists if, as x gets arbitrarily close to a certain value 'a', the function f(x) gets arbitrarily close to a specific value 'L'. It's like zooming in on a graph to see where the function is heading.

🔍
Zooming In

Left Hand Limit (LHL) and Right Hand Limit (RHL)

  • LHL: Approaching the point from values smaller than it.
  • RHL: Approaching the point from values larger than it.
  • Both approaches must lead to the same value for the limit to exist.

🎙️ To properly define a limit, we must consider how the function behaves as we approach the point from two directions: the left (smaller values) and the right (larger values). These are the Left Hand Limit and Right Hand Limit, respectively.

Existence of a Limit: The Balance

  • A limit exists if and only if LHL = RHL.
  • If LHL ≠ RHL, the limit does not exist.
  • Crucial for evaluating function behavior.

🎙️ Think of it like a balance scale. For the limit to exist, the 'weight' (the value the function approaches) from the left side must exactly match the 'weight' from the right side. If they don't balance, there's no single limit.

Algebra of Limits: Rules for Operations

  • Limits can be applied to sums, differences, products, and quotients.
  • lim (f ± g) = lim f ± lim g
  • lim (f ⋅ g) = lim f ⋅ lim g
  • lim (f / g) = lim f / lim g (if lim g ≠ 0)

🎙️ Just like regular algebra, limits have rules that allow us to combine them. These rules simplify the process of finding limits of complex functions by breaking them down into simpler parts. Remember the condition for division!

Worked Example 1: Evaluating a Polynomial Limit

  • Evaluate: lim (x→2) (3x² + 5x - 7)
  • Direct substitution is possible for polynomials.
  • Result: 3(2)² + 5(2) - 7 = 12 + 10 - 7 = 15.

🎙️ For polynomial functions, limits are straightforward. You can often find the limit by simply substituting the value that x approaches into the function. This is because polynomials are continuous everywhere.

Indeterminate Forms: When Direct Substitution Fails

  • Forms like 0/0, ∞/∞ are indeterminate.
  • They don't directly tell us the limit's value.
  • Require further algebraic manipulation.

🎙️ Sometimes, direct substitution leads to expressions like 0/0 or infinity/infinity. These are called indeterminate forms because they don't give a clear answer. We need special techniques to resolve them and find the actual limit.

Methods to Evaluate Limits: Factorisation

  • Used when direct substitution yields 0/0.
  • Factorize numerator and denominator.
  • Cancel out the common factor (x-a).

🎙️ Factorisation is a powerful technique for indeterminate forms. By factoring, we can often identify and cancel the term that causes the zero in both the numerator and denominator, allowing us to then substitute the value.

1Substitute and check 0/0
2Factorize numerator & denominator
3Cancel common factors
4Substitute again
10 / 25

Worked Example 2: Limit by Factorisation

  • Evaluate: lim (x→3) (x² - 9) / (x - 3)
  • Direct substitution gives 0/0.
  • Factorize: (x - 3)(x + 3) / (x - 3) = x + 3.
  • Substitute: lim (x→3) (x + 3) = 6.

🎙️ Here, (x-3) is the common factor causing the indeterminate form. Once cancelled, the function simplifies to x+3, which is a continuous polynomial. Now, direct substitution gives us the limit.

11 / 25

Methods to Evaluate Limits: Rationalisation

  • Used when expressions involve square roots and yield 0/0.
  • Multiply numerator and denominator by the conjugate.
  • Simplifies the expression to remove the indeterminate form.

🎙️ Rationalisation is particularly useful when you encounter square roots. By multiplying by the conjugate, we eliminate the root in one part of the fraction, often revealing a common factor that can be cancelled out.

1Substitute and check 0/0
2Multiply by conjugate
3Simplify using (a-b)(a+b)=a²-b²
4Cancel common factors & substitute
12 / 25

Worked Example 3: Limit by Rationalisation

  • Evaluate: lim (x→0) (√(1+x) - 1) / x
  • Direct substitution gives 0/0.
  • Multiply by (√(1+x) + 1) / (√(1+x) + 1).
  • Result: lim (x→0) (1+x - 1) / (x(√(1+x) + 1)) = lim (x→0) 1 / (√(1+x) + 1) = 1/2.

🎙️ Notice how multiplying by the conjugate helped transform the numerator into a simpler form, allowing us to cancel 'x' and resolve the 0/0 indeterminate form. This is a common pattern to look for.

Limits of Trigonometric Functions: Key Formulas

  • lim (x→0) (sin x / x) = 1
  • lim (x→0) (tan x / x) = 1
  • lim (x→0) (1 - cos x) / x = 0
  • These are fundamental and must be memorized.

🎙️ Trigonometric limits have specific formulas that are incredibly useful. The first two, involving sin x / x and tan x / x, are particularly important and frequently appear in exams. Make sure you know them well!

Worked Example 4: Trigonometric Limit

  • Evaluate: lim (x→0) (sin 4x / x)
  • We need the form (sin θ / θ).
  • Multiply and divide by 4: lim (x→0) (sin 4x / 4x) * 4.
  • Result: 1 * 4 = 4.

🎙️ The trick here is to manipulate the expression to match the standard form (sin θ / θ). Whatever is inside the 'sin' function must also be in the denominator. This often involves multiplying and dividing by a constant.

Limits of Exponential and Logarithmic Functions

  • lim (x→0) (e^x - 1) / x = 1
  • lim (x→0) (log(1+x)) / x = 1
  • lim (x→0) (a^x - 1) / x = log a (base e)
  • These are also standard formulas.

🎙️ Beyond algebraic and trigonometric functions, exponential and logarithmic functions also have specific limit formulas. These are essential for understanding continuous growth and decay models. Remember 'log' here implies natural logarithm (base e).

Worked Example 5: Exponential Limit

  • Evaluate: lim (x→0) (e^(3x) - 1) / x
  • We need the form (e^θ - 1) / θ.
  • Multiply and divide by 3: lim (x→0) (e^(3x) - 1) / (3x) * 3.
  • Result: 1 * 3 = 3.

🎙️ Similar to trigonometric limits, we adjust the expression to fit the standard formula. Ensure that the exponent of 'e' matches the denominator. This pattern of adjustment is very common in limit problems.

Introduction to Derivatives: Rate of Change

  • Measures the instantaneous rate of change of a function.
  • How fast is a quantity changing at a specific moment?
  • Connects to velocity, acceleration, marginal cost, etc.

🎙️ Now we move to derivatives, which are essentially limits applied to rates of change. Think of a car's speedometer; it shows the instantaneous speed, which is a derivative. Derivatives tell us how sensitive a function is to changes in its input.

Derivative as a Limit: The First Principle

  • The derivative f'(x) = lim (h→0) [f(x+h) - f(x)] / h.
  • This is the formal definition, also called 'differentiation from first principles'.
  • Represents the slope of the tangent to the curve at x.

🎙️ This formula is the heart of derivatives. It calculates the slope of a secant line between two very close points on a curve, and as the distance between these points (h) approaches zero, the secant line becomes the tangent line, giving us the instantaneous rate of change.

🔬
Precise Definition

Geometric Interpretation of Derivative: Tangent Slope

  • The derivative f'(x) gives the slope of the tangent line to the curve y = f(x) at point (x, f(x)).
  • A positive derivative means the function is increasing.
  • A negative derivative means the function is decreasing.

🎙️ Geometrically, the derivative has a beautiful meaning. It's the slope of the line that just touches the curve at a single point. This slope tells us the steepness and direction of the curve at that exact point.

Derivatives of Common Functions: Basic Rules

  • d/dx (c) = 0 (Derivative of a constant is zero).
  • d/dx (x^n) = n * x^(n-1) (Power Rule).
  • d/dx (cx^n) = c * n * x^(n-1) (Constant Multiple Rule).
  • These are the building blocks.

🎙️ Thankfully, we don't always need to use the first principle. There are standard rules for differentiating common functions. The power rule is perhaps the most fundamental and widely used, so commit it to memory!

⚙️
Function Mechanisms

Algebra of Derivatives: Sum, Difference, Product, Quotient Rules

  • d/dx (u ± v) = du/dx ± dv/dx
  • d/dx (uv) = u(dv/dx) + v(du/dx) (Product Rule)
  • d/dx (u/v) = [v(du/dx) - u(dv/dx)] / v² (Quotient Rule)
  • These rules help differentiate complex functions.

🎙️ Just like limits, derivatives also have rules for combining functions. The product rule and quotient rule are particularly important for differentiating functions that are multiplied or divided. Practice these thoroughly!

🔗
Connecting Functions

Worked Example 6: Using Derivative Rules

  • Find the derivative of f(x) = 5x³ - 2x + 7.
  • Apply power rule and constant rule term by term.
  • d/dx (5x³) = 15x².
  • d/dx (-2x) = -2.
  • d/dx (7) = 0.
  • Result: f'(x) = 15x² - 2.

🎙️ This example demonstrates how to apply the basic rules of differentiation to a polynomial. Remember to differentiate each term separately and handle constants correctly. This forms the basis for more complex problems.
