Recall: Equations vs. Inequalities

  • Equations use '=' for exact solutions
  • Inequalities use '<, >, ≤, ≥'
  • Inequalities represent a range of solutions

🎙️ Before we jump into inequalities, let's quickly remember the difference between equations and inequalities. Equations give us a specific value, while inequalities give us a set of values. Think of it like a single point versus a whole region on a map.

What are Linear Inequalities?

  • Mathematical statements comparing two expressions
  • Involve variables raised to power one
  • Represented by inequality symbols

🎙️ A linear inequality is simply a mathematical statement that shows a relationship of inequality between two expressions, where the highest power of the variable is one. It's like comparing two quantities, rather than stating they are exactly equal.

Types of Linear Inequalities

  • Strict Inequalities: < (less than), > (greater than)
  • Slack Inequalities: ≤ (less than or equal to), ≥ (greater than or equal to)

🎙️ We classify inequalities into two main types: strict and slack. Strict inequalities mean 'definitely less than' or 'definitely greater than'. Slack inequalities include the possibility of equality, which is crucial for graphing later on.

Rules for Solving Inequalities (Part 1)

  • Adding the same number to both sides
  • Subtracting the same number from both sides
  • The inequality sign remains unchanged

🎙️ The first two rules are quite similar to solving equations. If you add or subtract the same number from both sides of an inequality, the direction of the inequality sign does not change. It's like shifting the entire number line.

Representing Solutions on a Number Line

  • Open circle for strict inequalities (<, >)
  • Closed circle for slack inequalities (≤, ≥)
  • Shade the region representing the solution set

🎙️ Representing solutions on a number line is essential. An open circle indicates that the endpoint is not included in the solution, while a closed circle means it is. This visual representation clearly shows the range of values that satisfy the inequality.

Rules for Solving Inequalities (Part 2)

  • Multiplying both sides by a positive number
  • Dividing both sides by a positive number
  • The inequality sign remains unchanged

🎙️ Similar to addition and subtraction, multiplying or dividing both sides of an inequality by a positive number also keeps the inequality sign in the same direction. This is a straightforward operation.

Crucial Rule: Multiplying/Dividing by a Negative Number

  • Multiplying both sides by a negative number
  • Dividing both sides by a negative number
  • The inequality sign MUST REVERSE

🎙️ This is perhaps the most critical rule and a common source of error! When you multiply or divide both sides of an inequality by a negative number, you MUST reverse the direction of the inequality sign. Remember this golden rule!

Common Mistake: Forgetting to Flip the Sign

  • Incorrect: -2x > 6 -> x > -3
  • Correct: -2x > 6 -> x < -3
  • Always remember to reverse the sign when multiplying/dividing by a negative

🎙️ This is a very common mistake in exams! Students often forget to flip the inequality sign when dividing or multiplying by a negative number. Always double-check this step to avoid losing marks.

Solving Linear Inequalities Graphically (Two Variables)

  • Used for inequalities with two variables (e.g., x and y)
  • Solution is a region in the Cartesian plane
  • Not a single point or line

🎙️ Now, let's extend our understanding to inequalities involving two variables, like 'x' and 'y'. The solution to such an inequality isn't a single point or a line, but an entire region in the coordinate plane. This is where graphing becomes crucial.

Steps for Graphical Solution (Single Inequality)

  • 1. Replace inequality sign with '=' to get boundary line
  • 2. Plot the boundary line (dotted for strict, solid for slack)
  • 3. Choose a test point (e.g., (0,0))
  • 4. Shade the region that satisfies the original inequality

🎙️ Here are the four key steps to graphically solve a linear inequality in two variables. Remember to distinguish between a dotted line for strict inequalities and a solid line for slack ones. The test point helps us decide which side to shade.

2Test Point

Worked Example 2: Graphing a Single Inequality

  • Graph: x + y < 4
  • Boundary line: x + y = 4 (dotted line)
  • Test point (0,0): 0 + 0 < 4 (True)
  • Shade the region containing (0,0)

🎙️ Let's graph x + y < 4. First, draw the line x + y = 4, but make it dotted because it's a strict inequality. Then, pick a test point, say (0,0). Since (0,0) satisfies the inequality, we shade the region that includes the origin.

The Test Point Method for Shading

  • Pick a point NOT on the boundary line (e.g., (0,0))
  • Substitute its coordinates into the original inequality
  • If True, shade the region containing the test point
  • If False, shade the opposite region

🎙️ The test point method is your best friend for determining which side of the boundary line to shade. (0,0) is often the easiest point to use, unless the boundary line passes through it. Simply plug in the coordinates and check for truthfulness.

📍

Worked Example 3: Graphing with a Solid Line

  • Graph: 2x - y ≥ 2
  • Boundary line: 2x - y = 2 (solid line)
  • Test point (0,0): 0 - 0 ≥ 2 (False)
  • Shade the region NOT containing (0,0)

🎙️ In this example, 2x - y ≥ 2, the boundary line 2x - y = 2 will be solid because of the 'greater than or equal to' sign. When we test (0,0), it gives a false statement, so we shade the region that does not include the origin.

System of Linear Inequalities

  • Two or more linear inequalities considered together
  • Solution is the common region satisfying ALL inequalities
  • Called the feasible region

🎙️ Often, we need to satisfy multiple conditions simultaneously. This leads to a system of linear inequalities. The solution to such a system is the region on the graph where all individual inequalities overlap, known as the feasible region.

🤝🤝
Common Ground
19 / 25

Steps for Solving a System Graphically

  • 1. Graph each inequality separately (boundary lines, shading)
  • 2. Identify the common shaded region
  • 3. The common region is the solution set

🎙️ To solve a system, simply graph each inequality individually on the same coordinate plane. The area where all the shaded regions overlap is your final solution. This common region represents all points that satisfy every inequality in the system.

2Find Intersection

Worked Example 4: Solving a System

  • Solve: x + y ≤ 5 and x ≥ 1
  • Graph x + y = 5 (solid, shade below)
  • Graph x = 1 (solid, shade right)
  • Identify the overlapping region

🎙️ Let's solve a system. We'll graph x + y ≤ 5 and x ≥ 1. For x + y ≤ 5, we shade below the line. For x ≥ 1, we shade to the right of the vertical line x=1. The region where these two shadings intersect is our solution.

Common Mistake: Incorrect Shading of Regions

  • Incorrectly identifying the common region for a system

🎙️ Incorrectly shading is another frequent mistake. Always use a test point to confirm which side to shade. For systems, be very careful in identifying the exact overlapping region; a different color for each inequality's shading can sometimes help.
