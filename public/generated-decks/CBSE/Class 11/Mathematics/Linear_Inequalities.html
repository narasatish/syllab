Equations vs. Inequalities: The Difference

  • Equations show exact equality (e.g., x = 5).
  • Inequalities show a range of possibilities (e.g., x < 5).
  • They use different symbols to express relationships.

🎙️ Think of an equation as a single, precise point on a number line, like saying 'your age is exactly 16'. An inequality, however, is like saying 'your age is less than 18', which opens up many possibilities. This distinction is crucial.

Unpacking the Symbols: Types of Inequalities

  • Less than (<): x < 5 (x is strictly less than 5).
  • Greater than (>): y > 10 (y is strictly greater than 10).
  • Less than or equal to (≤): z ≤ 7 (z can be 7 or less).
  • Greater than or equal to (≥): w ≥ 2 (w can be 2 or more).

🎙️ These four symbols are the building blocks of inequalities. Understanding what each symbol represents is key to correctly interpreting and solving problems. Pay close attention to the difference between strict inequalities (<, >) and non-strict ones (≤, ≥).

What is a Linear Inequality in One Variable?

  • An algebraic expression with one variable.
  • Involves inequality symbols (<, >, ≤, ≥).
  • The highest power of the variable is 1.
  • Examples: 2x + 3 < 7, 5y - 1 ≥ 9.

🎙️ Just like linear equations, a linear inequality in one variable means the variable appears with a power of one, and we use one of our four inequality symbols. The solution will be a range of values, not a single value.

The Golden Rules for Solving Inequalities

  • Rule 1: Add/subtract same number on both sides (sign unchanged).
  • Rule 2: Multiply/divide by a positive number (sign unchanged).
  • Rule 3: Multiply/divide by a negative number (SIGN REVERSES!).

🎙️ These rules are similar to solving equations, but Rule 3 is crucial and often a source of error. Always remember to flip the inequality sign when multiplying or dividing by a negative number. This is a common mistake to avoid!

1Add/Subtract
2Positive Multiply/Divide
3Negative Multiply/Divide (Reverse Sign!)

Example 1: Solving a Simple Linear Inequality

  • Solve: 3x - 5 < 10
  • Add 5 to both sides: 3x < 15
  • Divide by 3: x < 5
  • Solution: All real numbers less than 5.

🎙️ Let's walk through this step-by-step. First, isolate the term with 'x' by adding 5 to both sides. Then, divide by the coefficient of 'x'. Since we divided by a positive number (3), the inequality sign remains the same. So, x is any number strictly less than 5.

Visualising Solutions: The Number Line

  • Represents the solution set graphically.
  • Open circle (○) for < or > (value not included).
  • Closed circle (●) for ≤ or ≥ (value included).
  • Shade the region indicating the solution.

🎙️ A number line is an excellent way to visually understand the range of solutions. Remember the difference between open and closed circles; it tells us whether the boundary value itself is part of the solution or not. Shading indicates all the numbers that satisfy the inequality.

Example 2: Solving and Graphing on a Number Line

  • Solve: -2x + 1 ≥ 5
  • Subtract 1: -2x ≥ 4
  • Divide by -2 (REVERSE SIGN!): x ≤ -2
  • Graph: Closed circle at -2, shade to the left.

🎙️ Here's an example where Rule 3 comes into play. After subtracting 1, we get -2x ≥ 4. When we divide by -2, we must reverse the inequality sign from 'greater than or equal to' to 'less than or equal to'. The solution is x ≤ -2, which means we put a closed circle at -2 and shade everything to its left.

Stepping Up: Linear Inequalities in Two Variables

  • Involve two variables (e.g., x and y).
  • General form: Ax + By + C < 0 (or >, ≤, ≥).
  • Solutions are regions on a coordinate plane, not just points.
  • Example: 2x + 3y ≤ 6.

🎙️ Now, let's extend our understanding to two variables. Instead of a single number line, our solutions will now occupy an entire region on the Cartesian coordinate plane. This is where graphing becomes essential to visualize the solution set.

Graphing Solutions: A Step-by-Step Approach

  • Step 1: Replace inequality sign with '=' to get the boundary line equation.
  • Step 2: Draw the boundary line (dashed for <, > ; solid for ≤, ≥).
  • Step 3: Choose a 'test point' not on the line (e.g., (0,0)).
  • Step 4: Substitute the test point into the original inequality. If true, shade that side; if false, shade the other side.

🎙️ These four steps are your roadmap to accurately graphing linear inequalities in two variables. The test point method is particularly useful to determine which side of the line represents the solution. (0,0) is often the easiest test point unless it lies on the boundary line itself.

1Boundary Line Equation
2Draw Line (Dashed/Solid)
3Choose Test Point
4Shade Correct Region

Example 3: Graphing a Two-Variable Inequality

  • Graph: x + y < 4
  • Boundary line: x + y = 4 (dashed line).
  • Test point (0,0): 0 + 0 < 4 (0 < 4) is TRUE.
  • Shade the region containing (0,0).

🎙️ Let's apply the steps. First, we draw the dashed line x + y = 4 because the inequality is strictly less than. Then, we pick our test point (0,0). Since (0,0) satisfies the inequality, we shade the region that includes the origin.

Dashed or Solid? Understanding Boundary Lines

  • Dashed Line: Used for strict inequalities (< or >).
  • It means points on the line are NOT part of the solution.
  • Solid Line: Used for non-strict inequalities (≤ or ≥).
  • It means points on the line ARE part of the solution.

🎙️ This distinction between dashed and solid lines is crucial for accuracy in your graphs. It indicates whether the boundary values themselves are included in the solution set. A correct line type is essential for full marks in exams.

Dashed (<,>)
Solid (≤,≥)

Example 4: Graphing with an 'Equal To' Sign

  • Graph: 2x - y ≥ 2
  • Boundary line: 2x - y = 2 (solid line).
  • Test point (0,0): 2(0) - 0 ≥ 2 (0 ≥ 2) is FALSE.
  • Shade the region NOT containing (0,0).

🎙️ In this example, since it's 'greater than or equal to', we draw a solid line for 2x - y = 2. Our test point (0,0) makes the inequality false, so we shade the region on the opposite side of the line from the origin.

Combining Forces: Systems of Linear Inequalities

  • A system involves two or more linear inequalities.
  • The solution is the region that satisfies ALL inequalities simultaneously.
  • This common region is called the 'feasible region'.
  • Often used in optimization problems.

🎙️ When we have multiple constraints, we're looking for an area that satisfies all of them. This intersection of shaded regions is known as the feasible region, and it's a very important concept, especially in higher mathematics and real-world applications like linear programming.

Steps to Solve a System of Inequalities

  • Step 1: Graph each inequality separately on the same coordinate plane.
  • Step 2: Shade the solution region for each inequality (use different colours/patterns mentally).
  • Step 3: Identify the region where all shaded areas overlap. This is the feasible region.

🎙️ It's like finding the intersection of multiple sets. Graphing each inequality carefully and then identifying the overlap is key. Using light shading or different colours for each inequality can help you visualize the common region more clearly.

2Graph 2nd Inequality
3Find Common Region

Example 5: Solving a System of Two Inequalities

  • Solve the system: x + y ≤ 5 and x - y ≥ 1.
  • Graph x + y = 5 (solid line, shade below).
  • Graph x - y = 1 (solid line, shade below/right).
  • The feasible region is where these two shaded areas intersect.

🎙️ Let's tackle this system. First, graph x + y ≤ 5. Then, on the same graph, plot x - y ≥ 1. The region where the shading from both inequalities overlaps is your solution. Remember to use solid lines as both inequalities include 'equal to'.

Example 6: A System with Multiple Inequalities

  • Solve: x ≥ 0, y ≥ 0, x + y ≤ 4.
  • x ≥ 0: Region to the right of the y-axis.
  • y ≥ 0: Region above the x-axis.
  • x + y ≤ 4: Region below the line x + y = 4.
  • The common feasible region is a triangle in the first quadrant.

🎙️ This is a common type of system, often found in linear programming. The conditions x ≥ 0 and y ≥ 0 restrict our solution to the first quadrant. Then, we add the third inequality, x + y ≤ 4, to further define the feasible region. The intersection forms a triangular region.

Beware! Common Pitfalls in Inequalities

  • Forgetting to reverse the sign when multiplying/dividing by a negative number.
  • Incorrectly using open/closed circles on the number line.
  • Drawing dashed lines instead of solid, or vice-versa, in 2D graphs.
  • Shading the wrong region after using a test point.
  • Not identifying the correct feasible region in systems.

🎙️ These are the common traps students fall into. Be extra vigilant with the sign reversal rule and the type of boundary line. Double-check your test points and ensure your final feasible region truly satisfies all conditions. Practice helps in avoiding these mistakes.
