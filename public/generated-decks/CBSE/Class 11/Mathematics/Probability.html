Random Experiment: The Starting Point

  • An experiment with well-defined outcomes.
  • The exact outcome cannot be predicted in advance.
  • It can be repeated under identical conditions.

🎙️ Think of rolling a fair die. You know the possible outcomes (1, 2, 3, 4, 5, 6), but you can't say for sure which number will appear on any given roll. This is a classic random experiment.

Example: Identifying Random Experiments

  • Tossing a coin: Random (Heads/Tails, unpredictable).
  • Dropping a stone: Not Random (Always falls down).
  • Drawing a card from a shuffled deck: Random.

🎙️ It's important to distinguish between experiments where outcomes are uncertain and those where they are predetermined. Only the former fall under the domain of probability.

Sample Space: All Possibilities

  • The set of all possible outcomes of a random experiment.
  • Represented by 'S' or 'Ω'.
  • Each outcome is called a 'sample point'.

🎙️ The sample space is like a complete list of everything that could possibly happen in an experiment. It's the universe of outcomes we are working with.

📝
Listing Outcomes

Worked Example: Sample Space - Coin Toss

  • 1 Coin: S = {H, T}
  • 2 Coins: S = {HH, HT, TH, TT}
  • 3 Coins: S = {HHH, HHT, HTH, THH, HTT, THT, TTH, TTT}

🎙️ Notice how the number of outcomes doubles with each additional coin. This systematic listing helps ensure we don't miss any possibilities.

Event: A Specific Outcome of Interest

  • An event is a subset of the sample space (S).
  • It's a collection of one or more sample points.
  • Often denoted by capital letters like A, B, E.

🎙️ While the sample space lists everything, an event focuses on particular outcomes we are interested in. For example, 'getting an even number' when rolling a die is an event.

Types of Events: Impossible & Sure Events

  • Impossible Event (Ø): An event that cannot occur. P(Ø) = 0.
  • Sure Event (S): An event that is certain to occur. P(S) = 1.
  • Example: Rolling a 7 on a 6-sided die (Impossible).

🎙️ These are the two extremes of probability. An impossible event has zero chance, while a sure event is guaranteed to happen. All other probabilities lie between 0 and 1.

Types of Events: Simple & Compound Events

  • Simple Event: Contains only one sample point.
  • Example: Getting a '3' when rolling a single die.
  • Compound Event: Contains more than one sample point.
  • Example: Getting an 'even number' (2, 4, 6) when rolling a die.

🎙️ The distinction helps in understanding the complexity of events. Simple events are the basic building blocks, while compound events combine several simple events.

Types of Events: Mutually Exclusive Events

  • Events that cannot occur simultaneously.
  • Their intersection is empty (A ∩ B = Ø).
  • Example: Getting a 'Head' and a 'Tail' on a single coin toss.

🎙️ If two events are mutually exclusive, the occurrence of one completely prevents the occurrence of the other. They are disjoint sets in terms of sample points.

🚫🚫
No Overlap

Types of Events: Exhaustive Events

  • A set of events whose union is the entire sample space (S).
  • At least one of them must occur in any trial.
  • Example: Getting an 'even number' or an 'odd number' on a die roll.

🎙️ Exhaustive events collectively cover all possible outcomes of an experiment. They ensure that no outcome is left out when considering a set of events.

Worked Example: Identifying Event Types

  • Experiment: Rolling a die. S = {1, 2, 3, 4, 5, 6}
  • Event A: Getting an even number = {2, 4, 6}
  • Event B: Getting an odd number = {1, 3, 5}
  • Event C: Getting a number greater than 4 = {5, 6}

🎙️ Here, A and B are mutually exclusive and exhaustive. A and C are neither mutually exclusive (as 6 is common) nor exhaustive (as 1,3 are not covered by A U C).

1A = {2,4,6}
2B = {1,3,5}
3C = {5,6}

Probability: The Classical Approach (Brief)

  • Assumes all outcomes are equally likely.
  • P(E) = (Number of Favorable Outcomes) / (Total Number of Outcomes in S).
  • Simple and intuitive for many basic problems.

🎙️ This is often the first way we learn about probability. It's very useful when outcomes have an equal chance of occurring, like a fair coin or a balanced die.

Probability: Axiomatic Approach - The Foundation

  • A more rigorous and general definition of probability.
  • Based on three fundamental axioms (postulates).
  • Applies even when outcomes are not equally likely.

🎙️ While the classical approach is good for simple cases, the axiomatic approach provides a robust mathematical framework that works for all types of random experiments.

Mathematical Rigor

Axioms of Probability

  • Axiom 1: For any event E, 0 ≤ P(E) ≤ 1.
  • Axiom 2: The probability of the sure event S is 1, i.e., P(S) = 1.
  • Axiom 3: For any two mutually exclusive events A and B, P(A ∪ B) = P(A) + P(B).

🎙️ These three axioms are the bedrock of probability theory. All other rules and theorems in probability can be derived from these fundamental statements.

10 ≤ P(E) ≤ 1
2P(S) = 1
3P(A ∪ B) = P(A) + P(B)
21 / 30

Derived Results from Axioms

  • Probability of Impossible Event: P(Ø) = 0.
  • Complement Rule: P(A') = 1 - P(A) (where A' is 'not A').
  • General Addition Rule: P(A ∪ B) = P(A) + P(B) - P(A ∩ B).

🎙️ These are incredibly useful formulas derived from the axioms. The General Addition Rule is especially important when events are not mutually exclusive.

1P(Ø) = 0
2P(A') = 1 - P(A)
3P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

Worked Example: Basic Probability Calculation

  • Experiment: Tossing a fair coin. S = {H, T}.
  • Event E: Getting a Head. E = {H}.
  • P(E) = Number of favorable outcomes / Total outcomes = 1/2.

🎙️ This simple example demonstrates the application of the classical definition, which is consistent with the axiomatic approach for equally likely outcomes.

Worked Example: Using Addition Rule

  • Experiment: Drawing a card from 52 cards.
  • Event A: Drawing a King. P(A) = 4/52.
  • Event B: Drawing a Spade. P(B) = 13/52.
  • Event A ∩ B: Drawing a King of Spade. P(A ∩ B) = 1/52.

🎙️ P(A ∪ B) = P(A) + P(B) - P(A ∩ B) = 4/52 + 13/52 - 1/52 = 16/52. We subtract the intersection to avoid double-counting the King of Spades.

Worked Example: Complement Rule

  • Experiment: Rolling a fair die. S = {1, 2, 3, 4, 5, 6}.
  • Event E: Getting a 6. P(E) = 1/6.
  • Event E': Not getting a 6. E' = {1, 2, 3, 4, 5}.
  • P(E') = 1 - P(E) = 1 - 1/6 = 5/6.

🎙️ The complement rule is very powerful, especially when it's easier to calculate the probability of an event *not* happening than the event itself.

Common Mistakes in Probability

  • Incorrectly identifying the Sample Space (S).
  • Double-counting outcomes in non-mutually exclusive events.
  • Confusing P(A') with P(A).
  • Assuming outcomes are equally likely when they are not.

🎙️ Pay close attention to these common pitfalls. A small error in defining the sample space or applying the wrong formula can lead to incorrect results.
