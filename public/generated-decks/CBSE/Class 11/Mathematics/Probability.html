Random Experiment: The Foundation

  • An experiment with multiple possible outcomes.
  • Cannot predict the exact outcome beforehand.
  • Can be repeated under identical conditions.

🎙️ A random experiment is the starting point for any probability problem. Think of tossing a coin or rolling a die – you know the possible results, but not which one will occur on a given trial.

Outcome and Sample Space: Defining Possibilities

  • Outcome: A single possible result of a random experiment.
  • Sample Space (S): The set of all possible outcomes.
  • Represented by 'S' and enclosed in curly braces { }.

🎙️ Every time you perform a random experiment, a specific outcome occurs. The collection of all such possible outcomes forms the sample space, which is fundamental to calculating probabilities.

Event: A Subset of the Sample Space

  • An event (E) is a subset of the sample space (S).
  • It's a collection of one or more outcomes.
  • We are interested in the probability of an event occurring.

🎙️ An event is essentially what we are looking for within our experiment. For example, rolling an even number on a die is an event, comprising outcomes {2, 4, 6}.

Classifying Events: Different Types

  • Impossible Event (∅): No outcomes.
  • Sure Event (S): All outcomes.
  • Simple Event: Only one outcome.
  • Compound Event: More than one outcome.

🎙️ Events can be categorized based on the number of outcomes they contain. An impossible event can never happen, while a sure event is guaranteed to happen.

Algebra of Events: Combining Events

  • Union (A U B): A or B or both.
  • Intersection (A ∩ B): A and B both.
  • Complement (A'): Not A (outcomes not in A).
  • These are similar to set operations.

🎙️ Just like with sets, we can combine events using operations like union, intersection, and complement. These are powerful tools for describing complex scenarios.

Mutually Exclusive Events: No Common Outcomes

  • Two events A and B are mutually exclusive if A ∩ B = ∅.
  • They cannot occur simultaneously.
  • Example: Getting a Head AND a Tail on a single coin toss.

🎙️ Mutually exclusive events are crucial. If two events cannot happen at the same time, their intersection is empty. Understanding this helps in applying the addition theorem correctly.

Exhaustive Events: Covering All Possibilities

  • A set of events E1, E2, ..., En is exhaustive if E1 U E2 U ... U En = S.
  • Together, they cover the entire sample space.
  • Example: Getting an even number OR an odd number on a die roll.

🎙️ Exhaustive events ensure that all possible outcomes are accounted for. If events are both mutually exclusive and exhaustive, they form a partition of the sample space.

Classical Definition: The 'Favorable' Approach

  • Assumes all outcomes are equally likely.
  • P(E) = (Number of favorable outcomes) / (Total number of outcomes).
  • Also known as a priori probability.

🎙️ This is the most intuitive definition of probability, often used when dealing with fair coins, dice, or well-shuffled cards. It's the ratio of what we want to what's possible.

Calculating Probability: Step-by-Step

  • Step 1: Identify the random experiment.
  • Step 2: Determine the Sample Space (S) and n(S).
  • Step 3: Identify the Event (E) and n(E).
  • Step 4: Apply the formula P(E) = n(E) / n(S).

🎙️ Following these steps systematically helps avoid errors. Always start by clearly defining your sample space and then the specific event you are interested in.

Worked Example 1: Two Coin Tosses

  • Experiment: Tossing two fair coins.
  • Sample Space (S) = {HH, HT, TH, TT}, so n(S) = 4.
  • Event E: Getting exactly one Head = {HT, TH}, so n(E) = 2.
  • P(E) = n(E)/n(S) = 2/4 = 1/2.

🎙️ When dealing with multiple items, ensure you list all unique outcomes in the sample space. Here, HT is different from TH, as they represent the order of outcomes on the first and second coin.

16 / 25

Worked Example 2: Rolling Two Dice

  • Experiment: Rolling two fair dice simultaneously.
  • n(S) = 6 * 6 = 36 (all pairs (x,y)).
  • Event E: Sum of numbers is 7 = {(1,6), (2,5), (3,4), (4,3), (5,2), (6,1)}, so n(E) = 6.
  • P(E) = n(E)/n(S) = 6/36 = 1/6.

🎙️ Listing the sample space for two dice can be tedious, but understanding n(S) = 6^2 is key. Then carefully identify all pairs that satisfy the event condition.

Axiomatic Approach: A More Formal Definition

  • Based on a set of axioms (postulates).
  • Does not rely on equally likely outcomes.
  • More general and mathematically rigorous.
  • Probability is a real number P(E) assigned to each event E.

🎙️ While the classical definition is intuitive, the axiomatic approach provides a robust mathematical framework. It defines probability as a function satisfying certain fundamental rules.

Key Properties of Probability

  • For any event E, 0 ≤ P(E) ≤ 1.
  • P(S) = 1 (Probability of the sure event is 1).
  • P(∅) = 0 (Probability of the impossible event is 0).
  • If E and F are mutually exclusive, P(E U F) = P(E) + P(F).

🎙️ These are the fundamental axioms and properties derived from them. Remember, probability can never be negative or greater than 1. The sum of probabilities of all possible outcomes is always 1.

Addition Theorem: Probability of 'A or B'

  • For any two events A and B: P(A U B) = P(A) + P(B) - P(A ∩ B).
  • If A and B are mutually exclusive, P(A ∩ B) = 0, so P(A U B) = P(A) + P(B).
  • This formula accounts for overlaps.

🎙️ This theorem is vital when dealing with events that might overlap. We subtract P(A ∩ B) to avoid double-counting the outcomes common to both A and B.

Worked Example 3: Applying Addition Theorem

  • In a class, 30% students passed Math (M), 20% passed Physics (P), and 10% passed both.
  • Find the probability that a randomly chosen student passed Math or Physics.
  • P(M)=0.30, P(P)=0.20, P(M ∩ P)=0.10.
  • P(M U P) = P(M) + P(P) - P(M ∩ P) = 0.30 + 0.20 - 0.10 = 0.40.

🎙️ This example clearly shows why subtracting the intersection is necessary. Without it, students who passed both subjects would be counted twice.

Complementary Event: The 'Not' Probability

  • The complement of an event E, denoted E', includes all outcomes in S that are not in E.
  • P(E') = 1 - P(E).
  • E and E' are mutually exclusive and exhaustive.
  • Example: If P(rain) = 0.6, then P(no rain) = 1 - 0.6 = 0.4.

🎙️ This property is incredibly useful for calculating the probability of an event not happening. Sometimes it's easier to calculate P(E) by finding 1 - P(E').

Common Mistakes in Probability

  • Incorrectly identifying sample space (e.g., HT vs TH).
  • Forgetting to subtract intersection in Addition Theorem.
  • Assuming events are mutually exclusive when they are not.
  • Using P(E) > 1 or P(E) < 0.

🎙️ These errors frequently cost marks in exams. Always double-check your sample space, event definitions, and ensure your probabilities fall within the valid range of 0 to 1.
