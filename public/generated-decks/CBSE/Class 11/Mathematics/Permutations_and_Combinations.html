Fundamental Principle of Multiplication

  • If an event can occur in 'm' different ways.
  • And, following it, a second independent event can occur in 'n' different ways.
  • Then the two events in succession can occur in 'm × n' ways.

🎙️ Let's consider a practical example. If there are 3 routes from City A to City B, and 2 routes from City B to City C, how many total routes are there from A to C? It's simply 3 multiplied by 2, giving 6 routes.

1Event 1 (m ways)
2Event 2 (n ways)
3Both (m x n ways)

Forming Numbers (Repetition Allowed)

  • How many 3-digit numbers can be formed using digits 1, 2, 3, 4, 5 if repetition is allowed?
  • For the hundreds place, we have 5 choices.
  • For the tens place, we still have 5 choices (repetition allowed).
  • For the units place, we again have 5 choices. Total = 5 x 5 x 5 = 125.

🎙️ When repetition is allowed, the number of choices for each position remains constant. This is a common scenario in password or PIN creation, where digits or characters can be reused.

Forming Numbers (No Repetition)

  • How many 3-digit numbers can be formed using digits 1, 2, 3, 4, 5 without repetition?
  • Hundreds place: 5 choices.
  • Tens place: 4 choices (one digit already used).
  • Units place: 3 choices (two digits already used). Total = 5 x 4 x 3 = 60.

🎙️ When repetition is not allowed, the number of available choices decreases with each selection. This is crucial for understanding permutations later on, as each position must be filled with a distinct item.

Fundamental Principle of Addition

  • If an event can occur in 'm' different ways.
  • And another independent event can occur in 'n' different ways.
  • And the two events cannot occur simultaneously.
  • Then one of the events can occur in 'm + n' ways.

🎙️ For instance, if a class has 15 boys and 10 girls, and you need to choose one class monitor, how many choices do you have? You can choose a boy OR a girl, so it's 15 + 10 = 25 choices.

1Event 1 (m ways)
2OR Event 2 (n ways)
3Total (m + n ways)

Understanding n!

  • For any positive integer n, n! = n × (n-1) × (n-2) × ... × 1.
  • Example: 5! = 5 × 4 × 3 × 2 × 1 = 120.
  • By definition, 0! = 1 (this is a crucial convention for formulas to work).

🎙️ It's important to remember that 0! equals 1, not 0. This definition is essential for the permutation and combination formulas we will encounter next, ensuring they remain consistent.

1n! = n x (n-1) x ... x 1
2Example: 4! = 24
3Special Case: 0! = 1

Formula for Permutations

  • The number of permutations of 'n' distinct objects taken 'r' at a time is P(n, r) or nPr.
  • P(n, r) = n! / (n-r)!
  • Here, 'n' is the total number of objects, and 'r' is the number of objects being arranged.

🎙️ This formula directly comes from the multiplication principle where choices decrease with each selection. It calculates all possible ordered arrangements of a subset of items.

Example: Arranging Letters

  • How many different 4-letter words (meaningful or not) can be formed from the letters of the word 'ROSE'?
  • Here, n=4 (R, O, S, E) and r=4 (we are arranging all 4 letters).
  • P(4, 4) = 4! / (4-4)! = 4! / 0! = 24 / 1 = 24.

🎙️ Since we are arranging all the letters, r equals n. This simplifies to n!, as 0! is 1. Each unique arrangement forms a distinct 'word'.

Example: Arranging People

  • In how many ways can 5 people be seated in a row of 3 chairs?
  • Here, n=5 (total people) and r=3 (chairs available).
  • P(5, 3) = 5! / (5-3)! = 5! / 2! = (5 × 4 × 3 × 2 × 1) / (2 × 1) = 60.

🎙️ This illustrates selecting a subset of items and arranging them. The order of seating matters for each chair; swapping two people in different chairs creates a new arrangement.

Permutations with Identical Objects

  • What if some objects are identical? (e.g., letters in 'APPLE').
  • The formula needs adjustment to avoid overcounting identical arrangements.
  • Formula: n! / (p1! * p2! * ... * pk!), where p1, p2... are counts of identical items.

🎙️ If you have two identical red apples, swapping their positions doesn't create a new arrangement. We divide by the factorial of the count of each repeated item to correct for this overcounting.

Example: Arranging 'APPLE'

  • How many different arrangements can be made from the letters of the word 'APPLE'?
  • Total letters (n) = 5.
  • Letter 'P' repeats 2 times (p1 = 2).
  • Arrangements = 5! / 2! = 120 / 2 = 60.

🎙️ Without considering the repetition of 'P', we would get 5! = 120. But since the two 'P's are identical, swapping them doesn't create a new word, so we divide by 2! to get the unique arrangements.

Combinations: Where Order Doesn't Matter!

  • Selection of objects where the order of selection is not important.
  • Think of choosing a team, a committee, or a hand of cards.
  • Selecting A then B is the same as selecting B then A.

🎙️ If you're choosing 3 students for a committee, selecting Ram, then Sita, then Gopal is the same committee as selecting Sita, then Gopal, then Ram. The group itself is what matters, not the sequence of selection.

Formula for Combinations

  • The number of combinations of 'n' distinct objects taken 'r' at a time is C(n, r) or nCr.
  • C(n, r) = n! / (r! * (n-r)!)
  • It's P(n, r) divided by r! because each group of 'r' objects can be arranged in r! ways.

🎙️ This formula is derived directly from the permutation formula. We divide P(n,r) by r! to eliminate the overcounting that occurs when order doesn't matter, as each group of 'r' items can be arranged in r! ways.

Example: Choosing a Committee

  • In how many ways can a committee of 3 members be chosen from a group of 5 people?
  • Here, n=5 (total people) and r=3 (members to choose).
  • C(5, 3) = 5! / (3! * (5-3)!) = 5! / (3! * 2!) = (5 × 4 × 3 × 2 × 1) / ((3 × 2 × 1) × (2 × 1)) = 10.

🎙️ Notice how the number of combinations (10) is much smaller than the number of permutations (60) for the same n and r, because the order of selection for the committee does not matter.

Example: Choosing Cards

  • How many ways can a hand of 5 cards be chosen from a standard deck of 52 cards?
  • Here, n=52 and r=5.
  • C(52, 5) = 52! / (5! * (52-5)!) = 52! / (5! * 47!) = 2,598,960.

🎙️ This is a classic example of combinations, as the order in which you receive the cards in your hand doesn't change the hand itself. It's the collection of cards that matters.

P vs C: The Key Distinction

  • Permutations: Order matters. Arrangements. Keywords: arrange, order, sequence, position.
  • Combinations: Order does not matter. Selections/Groups. Keywords: choose, select, pick, group, committee.
  • Permutations are generally more numerous than combinations for the same n and r.

🎙️ This slide is crucial. Always ask yourself: 'Does the order of selection or arrangement change the outcome?' If yes, it's a permutation. If no, it's a combination. This question will guide your problem-solving.

Avoiding Common Pitfalls

  • Order Confusion: Mixing up P and C when order matters/doesn't matter.
  • Repetition Error: Forgetting to account for identical items in permutations.
  • Calculation Errors: Incorrectly simplifying factorials or arithmetic.
  • Misapplying FPC: Using addition instead of multiplication (or vice-versa).

🎙️ Many students lose marks due to these common errors. Always re-read the question carefully to identify if order matters, if repetition is allowed, or if items are identical, before applying a formula.

Lesson Recap: Key Takeaways

  • FPC: Multiplication (AND) and Addition (OR) principles.
  • Factorials (n!): Product of integers from n down to 1 (0! = 1).
  • Permutations (P(n,r)): Arrangements where order matters. P(n,r) = n!/(n-r)!
  • Combinations (C(n,r)): Selections where order doesn't matter. C(n,r) = n!/(r!(n-r)!).

🎙️ We've covered the fundamental building blocks of counting. Remember these definitions and formulas, as they are your tools for solving any problem in this chapter. Keep them handy!
