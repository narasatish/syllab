Understanding Ordered Pairs

  • A pair of elements (a, b) where the order matters.
  • Unlike sets {a, b}, (a, b) is not the same as (b, a) unless a = b.
  • Used to represent points in a coordinate plane.

🎙️ An ordered pair is simply a pair of objects where the sequence in which they appear is significant. Think of coordinates (x, y); (2, 3) is a different point from (3, 2). This distinction is crucial for Cartesian products.

Introduction to Cartesian Product

  • If A and B are two non-empty sets, A × B is the set of all ordered pairs (a, b).
  • Here, 'a' is an element of set A, and 'b' is an element of set B.
  • A × B = { (a, b) : a ∈ A, b ∈ B }.

🎙️ The Cartesian product is essentially a way to combine elements from two sets into all possible ordered pairs. It's like pairing up every element from the first set with every element from the second set.

Cartesian Product: An Example

  • Let A = {1, 2} and B = {a, b}.
  • A × B = { (1, a), (1, b), (2, a), (2, b) }.
  • Notice the order: first element from A, second from B.

🎙️ Let's take a simple example. If set A has two elements and set B has two elements, their Cartesian product A × B will have 2 multiplied by 2, which is 4 ordered pairs. Each pair takes one element from A and one from B.

Key Properties of Cartesian Product

  • If n(A) = p and n(B) = q, then n(A × B) = pq.
  • A × B ≠ B × A (unless A = B or one is empty).
  • If A or B is the empty set, then A × B is also the empty set.

🎙️ These properties are very important for exams. Remember that the number of elements in a Cartesian product is the product of the number of elements in the individual sets. Also, A × B is generally not commutative.

What are Relations?

  • A relation R from a non-empty set A to a non-empty set B is a subset of the Cartesian product A × B.
  • It defines a connection or relationship between elements of A and B.
  • R ⊆ A × B.

🎙️ A relation is essentially a rule that connects elements from one set to elements of another. It's a selection of some or all of the ordered pairs from the Cartesian product, based on a specific condition.

Defining Relations: Domain, Codomain, Range

  • Domain: The set of all first elements of the ordered pairs in a relation R.
  • Codomain: The entire set B from which the second elements are chosen.
  • Range: The set of all second elements of the ordered pairs in R.

🎙️ These three terms are critical for describing relations and later, functions. The domain is what you 'put into' the relation, the codomain is the set of all possible 'outputs', and the range is the set of actual 'outputs' you get.

Relation Example: 'is less than'

  • Let A = {1, 2, 3} and B = {2, 3, 4}.
  • Define R = { (a, b) : a ∈ A, b ∈ B, a < b }.
  • R = { (1, 2), (1, 3), (1, 4), (2, 3), (2, 4), (3, 4) }.

🎙️ Here, our relation is 'is less than'. We pick pairs where the first element from A is strictly less than the second element from B. The domain of R is {1, 2, 3}, the codomain is {2, 3, 4}, and the range is {2, 3, 4}.

Total Number of Relations

  • If n(A) = p and n(B) = q, then n(A × B) = pq.
  • A relation is any subset of A × B.
  • The total number of relations from A to B is 2^(pq).

🎙️ This is a common exam question. Since every subset of A × B is a relation, and a set with 'N' elements has 2^N subsets, the total number of relations is 2 raised to the power of the number of elements in the Cartesian product.

Introduction to Functions

  • A function is a special type of relation.
  • It maps each element of the domain to exactly one element of the codomain.
  • Often denoted as f: A → B.

🎙️ Functions are relations with two strict rules. Think of a machine where for every input, you get one and only one specific output. This unique output is what distinguishes a function from a general relation.

➡️
Unique Mapping

Formal Definition of a Function

  • A relation f from A to B is a function if:
  • 1. Every element of set A has an image in set B.
  • 2. Each element of set A has one and only one image in set B.

🎙️ These two conditions are paramount. Condition 1 means no element in the domain can be 'left out'. Condition 2 means an element in the domain cannot be mapped to two different elements in the codomain.

Functions: Domain, Codomain, Range Revisited

  • Domain of a function f: The entire set A.
  • Codomain of a function f: The entire set B.
  • Range of a function f: The set of all images of elements of A under f (a subset of B).

🎙️ For functions, the domain is always the entire starting set A. The codomain is the entire target set B. The range, however, is only the specific elements in B that are actually 'hit' by the function.

Is it a Function? Visual Test

  • One-to-one mapping: Valid function.
  • Many-to-one mapping: Valid function.
  • One-to-many mapping: NOT a function (violates uniqueness).

🎙️ Visually, you can check if it's a function. If any element in the domain has more than one arrow originating from it, it's not a function. If all domain elements have exactly one arrow, it is.

Real-Valued and Real Functions

  • A function f: A → B is called a real-valued function if its range is a subset of real numbers (R).
  • If both the domain and codomain are sets of real numbers (R), it's called a real function.
  • Most functions in Class 11 are real functions.

🎙️ In Class 11, we primarily deal with functions where the inputs and outputs are real numbers. This allows us to graph them on the Cartesian plane and study their properties like continuity and differentiability later.

Common Functions: Identity Function

  • Let R be the set of real numbers.
  • The function f: R → R defined by f(x) = x for each x ∈ R.
  • Domain = R, Range = R. Graph is a straight line y=x.

🎙️ The identity function is the simplest function. Whatever you put in, you get back the exact same value. It's like looking into a mirror. Its graph passes through the origin at a 45-degree angle.

Common Functions: Constant Function

  • The function f: R → R defined by f(x) = c, where c is a constant.
  • For every input x, the output is always c.
  • Domain = R, Range = {c}. Graph is a horizontal line.

🎙️ A constant function gives the same output value regardless of the input. Imagine a machine that always outputs '5', no matter what you feed into it. Its graph is a horizontal line parallel to the x-axis.

Common Functions: Polynomial Functions

  • A function f: R → R is a polynomial function if f(x) = a₀ + a₁x + ... + aₙxⁿ.
  • Here, n is a non-negative integer, and a₀, ..., aₙ are real constants.
  • Examples: f(x) = x² + 2x - 3, f(x) = 5x + 1.

🎙️ Polynomial functions are very common. They involve variables raised to non-negative integer powers, multiplied by coefficients. Their graphs can be smooth curves, without any breaks or sharp corners.

Common Functions: Rational Functions

  • A function of the form f(x) = P(x) / Q(x), where P(x) and Q(x) are polynomial functions.
  • The domain of a rational function excludes values of x for which Q(x) = 0.
  • Example: f(x) = (x+1) / (x-2). Domain is R - {2}.

🎙️ Rational functions are essentially ratios of polynomials. The crucial point here is that the denominator cannot be zero, so you must always identify and exclude those values from the domain.

Avoiding Common Mistakes

  • Confusing relations with functions: Functions are specific relations.
  • Incorrectly identifying Domain and Range: Pay attention to definitions.
  • Forgetting denominator cannot be zero in rational functions.

🎙️ Students often make mistakes by not checking both conditions for a function or by miscalculating the domain of functions like rational or square root functions. Always be methodical in your approach.
