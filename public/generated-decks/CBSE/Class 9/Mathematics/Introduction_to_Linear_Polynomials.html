What is a Linear Polynomial?

  • A polynomial with the highest degree of 1
  • Examples: x + 5, 2y - 3, z

🎙️ A 'linear polynomial' is a polynomial where the highest power of the variable is exactly one. When graphed, these polynomials form a straight line, hence the name 'linear'.

The General Form

  • A linear polynomial is generally written as ax + b
  • where 'a' and 'b' are constants, and 'a' cannot be zero.

🎙️ The standard way to write a linear polynomial is 'ax + b'. Here, 'a' is the coefficient of 'x', and 'b' is the constant term. It's important that 'a' is not zero, because if 'a' were zero, the 'x' term would vanish, and it would no longer be a linear polynomial.

Can You Identify Linear Polynomials?

  • Look for the highest power of the variable
  • It must be exactly 1.

🎙️ To identify a linear polynomial, simply check the highest power of the variable. If that power is 1, it's linear. For example, '3x + 7' is linear, but 'y² - 4' is not because its highest power is 2.

What is NOT a Linear Polynomial?

  • Expressions with degree > 1 (e.g., x², y³ + 2)
  • Expressions with negative or fractional powers (e.g., x⁻¹, √x).

🎙️ It's equally important to know what isn't a linear polynomial. Any polynomial with a variable's power greater than 1, like x² or y³, is not linear. Also, expressions with variables under a square root or with negative powers are not even polynomials.

Understanding the Zero of a Polynomial

  • A value of the variable that makes the polynomial equal to zero
  • Also known as the root of the polynomial.

🎙️ The 'zero of a polynomial' is a very important concept. It's simply the value of the variable that, when substituted into the polynomial, makes the entire expression equal to zero. This value is also sometimes called a 'root'.

How to Find the Zero?

  • Set the polynomial equal to zero (ax + b = 0)
  • Solve the resulting linear equation for 'x'.

🎙️ Finding the zero of a linear polynomial is straightforward. You just need to set the polynomial expression equal to zero, like 'ax + b = 0', and then solve this simple equation for 'x'. This will give you the unique zero.

Worked Example: Find the Zero

  • Find the zero of the polynomial P(x) = 2x + 6
  • Solution: 2x + 6 = 0 => 2x = -6 => x = -3.

🎙️ Let's try an example. If P(x) = 2x + 6, to find its zero, we set 2x + 6 = 0. Subtracting 6 from both sides gives 2x = -6. Then, dividing by 2, we get x = -3. So, -3 is the zero of this polynomial.

Another Example: Find the Zero

  • Find the zero of the polynomial P(y) = 5 - y
  • Solution: 5 - y = 0 => 5 = y => y = 5.

🎙️ Here's another one. For P(y) = 5 - y, we set 5 - y = 0. Adding 'y' to both sides gives 5 = y. So, the zero of this polynomial is 5. It's that simple!
