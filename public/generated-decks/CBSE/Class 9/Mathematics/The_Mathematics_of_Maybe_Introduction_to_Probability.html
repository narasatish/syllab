Key Terms: Experiment & Trial

  • An 'Experiment' is an action with uncertain outcomes.
  • Examples: Tossing a coin, rolling a die, drawing a card.
  • A 'Trial' is a single performance of an experiment.
  • Many trials make up an experiment.

🎙️ Before we calculate anything, let's understand some basic terms. An experiment is any process that has a well-defined set of possible results but whose actual outcome isn't known beforehand. Each time you perform that experiment, it's called a trial.

Key Terms: Outcome & Event

  • An 'Outcome' is a single result of an experiment.
  • Example: Getting 'Heads' when tossing a coin.
  • An 'Event' is one or more outcomes of an experiment.
  • Example: Getting an even number when rolling a die (2, 4, or 6).

🎙️ When you perform an experiment, whatever happens is an outcome. If you toss a coin, 'Heads' is an outcome, and 'Tails' is another. An event can be a single outcome or a collection of several outcomes that we are interested in.

Key Term: Sample Space

  • The 'Sample Space' is the set of ALL possible outcomes of an experiment.
  • It's usually denoted by 'S'.
  • Example: Tossing a coin, S = {Heads, Tails}.
  • Example: Rolling a die, S = {1, 2, 3, 4, 5, 6}.

🎙️ The sample space is like a complete list of everything that could possibly happen in an experiment. It's crucial to identify the sample space correctly because it forms the denominator in our probability calculations.

Calculating Probability: The Formula

  • Probability of an Event (P(E)) =
  • (Number of Favourable Outcomes) /
  • (Total Number of Possible Outcomes)
  • P(E) = n(E) / n(S)

🎙️ This is the fundamental formula for calculating probability. You need to count how many outcomes match your desired event and divide that by the total number of all possible outcomes. Remember, 'n(E)' is the count of favourable outcomes and 'n(S)' is the count of total outcomes in the sample space.

Worked Example: Coin Toss

  • Experiment: Tossing a fair coin.
  • Sample Space (S) = {Heads, Tails}. So, n(S) = 2.
  • Event (E): Getting a Head. Favourable outcome = {Heads}. So, n(E) = 1.
  • P(Head) = n(E) / n(S) = 1/2 = 0.5.

🎙️ Let's apply the formula. When you toss a coin, there are two equally likely outcomes: Heads or Tails. If we want to find the probability of getting a Head, there's only one favourable outcome. So, the probability is 1 divided by 2, which is 0.5 or 50%.

Worked Example: Dice Roll

  • Experiment: Rolling a fair six-sided die.
  • Sample Space (S) = {1, 2, 3, 4, 5, 6}. So, n(S) = 6.
  • Event (E): Getting an even number. Favourable outcomes = {2, 4, 6}. So, n(E) = 3.
  • P(Even Number) = n(E) / n(S) = 3/6 = 1/2 = 0.5.

🎙️ Here's another example with a die. The total possible outcomes are 1, 2, 3, 4, 5, or 6. If our event is getting an even number, then 2, 4, and 6 are our favourable outcomes. So, 3 favourable outcomes out of 6 total possibilities gives us a probability of 0.5.

The Probability Scale: 0 to 1

  • Probability values always range from 0 to 1.
  • 0 means the event is Impossible.
  • 1 means the event is Certain.
  • Values in between indicate varying likelihoods.

🎙️ It's very important to remember that a probability can never be less than 0 or greater than 1. A probability of 0 means something absolutely cannot happen, while a probability of 1 means it definitely will happen. Everything else falls somewhere in between.

Impossible Event

  • An event that cannot happen.
  • Its probability is 0.
  • Example: Rolling a 7 on a standard six-sided die.
  • n(E) = 0, so P(E) = 0/6 = 0.

🎙️ An impossible event is exactly what it sounds like – something that has no chance of occurring. If you're using a standard die, you simply cannot roll a 7, so the number of favourable outcomes is zero, making its probability zero.

Certain Event

  • An event that is guaranteed to happen.
  • Its probability is 1.
  • Example: Rolling a number less than 7 on a standard six-sided die.
  • n(E) = 6, so P(E) = 6/6 = 1.

🎙️ On the other end of the scale is a certain event. This is an event that is bound to occur. For instance, if you roll a die, you are guaranteed to get a number less than 7. All six outcomes are favourable, so the probability is 1.

Probability of an Event NOT Happening

  • If P(E) is the probability of an event E happening.
  • Then P(not E) is the probability of event E not happening.
  • P(E) + P(not E) = 1.
  • So, P(not E) = 1 - P(E).

🎙️ Sometimes it's easier to calculate the probability of an event not happening and then subtract it from 1. This concept is called complementary events. The sum of the probability of an event happening and not happening will always be 1.

Worked Example: Drawing Cards

  • Experiment: Drawing one card from a standard deck of 52 cards.
  • n(S) = 52.
  • Event (E): Drawing a King. There are 4 Kings in a deck. n(E) = 4.
  • P(King) = 4/52 = 1/13.

🎙️ A deck of cards is a great tool for probability examples. There are 52 cards in total. If you want to draw a King, there are four favourable outcomes (King of Hearts, Diamonds, Clubs, Spades). So the probability is 4 out of 52, which simplifies to 1/13.

Worked Example: Marbles in a Bag

  • A bag has 3 red, 2 blue, and 5 green marbles.
  • Total marbles n(S) = 3 + 2 + 5 = 10.
  • Event (E1): Picking a red marble. n(E1) = 3. P(Red) = 3/10.
  • Event (E2): Picking a blue marble. n(E2) = 2. P(Blue) = 2/10 = 1/5.

🎙️ Here, we have a mixed bag of marbles. First, find the total number of marbles. Then, for each colour, count the number of favourable marbles and divide by the total. Notice how each probability is a fraction between 0 and 1.

Summary of Key Concepts

  • Probability quantifies chance.
  • P(E) = Favourable Outcomes / Total Outcomes.
  • Values range from 0 (impossible) to 1 (certain).
  • P(E) + P(not E) = 1.

🎙️ Let's quickly recap what we've learned today. Probability helps us understand how likely things are. We use a simple formula, and the results are always between 0 and 1. We also know that an event either happens or it doesn't, and those two probabilities add up to 1.
