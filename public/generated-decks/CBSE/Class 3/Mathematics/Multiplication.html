What is Multiplication? It's Repeated Addition!

  • Imagine you have 3 friends.
  • Each friend has 2 apples.
  • How many apples in total?

🎙️ Multiplication is like adding the same number again and again. For example, if you have 3 friends and each has 2 apples, you can add 2 + 2 + 2. This is called repeated addition.

Meet the Multiplication Family: Terms

  • The number we multiply is the 'Multiplicand'.
  • The number we multiply by is the 'Multiplier'.
  • The answer is the 'Product'.

🎙️ Just like in addition where we have 'addends' and 'sum', in multiplication, we have special names for the numbers. The number being multiplied is the multiplicand, the number doing the multiplying is the multiplier, and the final answer is called the product.

Multiplication Property: Order Doesn't Matter!

  • If you multiply 2 x 3, the answer is 6.
  • If you multiply 3 x 2, the answer is also 6!
  • Changing the order does not change the product.

🎙️ Here's a fun fact about multiplication! If you multiply 2 by 3, you get 6. And if you change the order and multiply 3 by 2, you still get 6! This means the order of numbers doesn't change the answer in multiplication.

Special Numbers in Multiplication: 0 and 1

  • Any number multiplied by 1 is the number itself.
  • Any number multiplied by 0 is always 0.
  • These are magic rules!

🎙️ Numbers 0 and 1 have special powers in multiplication! If you multiply any number by 1, the number stays the same. And if you multiply any number by 0, the answer is always 0, no matter how big the number is!
