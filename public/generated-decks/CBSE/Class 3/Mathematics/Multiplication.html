What is Multiplication?

  • It is a quick way to do 'repeated addition'.
  • Instead of adding many times, we can multiply!

🎙️ Imagine you have 3 friends, and each friend gives you 2 apples. How many apples do you have in total? You can add 2 + 2 + 2. Multiplication helps us do this much faster!

Count and add using real objects like apples 🍎

Why Do We Multiply?

  • Multiplication helps us count big numbers quickly.
  • It saves time and makes math easy!

🎙️ Think about counting all the fingers in your classroom. If there are 30 children, and each has 10 fingers, adding 10, thirty times would take a long time! Multiplication helps us get the answer in a blink!

Fun Fact: Order Doesn't Change the Answer!

  • 2 x 3 is 6.
  • And 3 x 2 is also 6!
  • The answer stays the same.

🎙️ This is a very cool property! Whether you say 2 groups of 3 or 3 groups of 2, the total number of items will always be the same. It's like having 2 rows of 3 candies or 3 rows of 2 candies – you still have 6 candies!

Multiplying by One (1)

  • Any number multiplied by 1 gives the number itself.
  • 5 x 1 = 5.
  • 10 x 1 = 10.

🎙️ Think of it this way: if you have 5 apples, and you multiply them by 1, it means you just have 1 group of 5 apples. So, the number of apples remains 5. It's a very easy rule!

☝️
The number stays the same!

Multiplying by Zero (0)

  • Any number multiplied by 0 always gives 0.
  • 7 x 0 = 0.
  • 100 x 0 = 0.

🎙️ This is another super easy rule! If you have 7 empty boxes, and each box has 0 chocolates, how many chocolates do you have in total? Zero! So, any number multiplied by zero is always zero.
