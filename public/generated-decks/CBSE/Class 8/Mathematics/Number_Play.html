Numbers in General Form: The 2-Digit Story

  • A 2-digit number like 63 is 60 + 3.
  • This is (6 × 10) + (3 × 1).
  • If digits are 'a' and 'b', the number is 10a + b.
  • Here 'a' is the tens digit and 'b' is the units digit.

🎙️ Think about any two-digit number, say 63. It's simply six tens and three units. In general form, if we use variables 'a' for the tens digit and 'b' for the units digit, the number can always be written as 10 times 'a' plus 'b'. This form is super useful for solving number puzzles!

Playing with Numbers: Reversing 2-Digit Numbers

  • Original number: 10a + b.
  • Reversed number: 10b + a.
  • Adding them: (10a + b) + (10b + a) = 11a + 11b = 11(a + b).
  • The sum is always a multiple of 11!

🎙️ Remember our opening riddle? Now you know why the sum was 77, which is 11 times 7! When you add a two-digit number to its reverse, the sum is always a multiple of 11. This is because we can factor out 11 from the expression, proving the 'magic' mathematically.

Playing with Numbers: Difference of Reversed Digits

  • Original number: 10a + b (assume a > b).
  • Reversed number: 10b + a.
  • Subtracting them: (10a + b) - (10b + a) = 9a - 9b = 9(a - b).
  • The difference is always a multiple of 9!

🎙️ What happens if we subtract the reversed number instead of adding? If we assume the original tens digit is greater than the units digit, the difference will always be a multiple of 9. For example, 72 - 27 = 45, which is 9 times (7-2). This is another cool number trick!

Example: Letters for Digits - Simple Addition

  • Problem: A + A + A = BA
  • From units place: A + A + A = 3A. This must end in A.
  • Possible A values: 0 (3x0=0) or 5 (3x5=15).
  • If A=0, then 0+0+0 = 0. So BA = 00, which is not a 2-digit number.
  • If A=5, then 3A = 15. So units digit is 5, and 1 is carried over.
  • From tens place: Carry-over 1 = B. So B=1.
  • Solution: A=5, B=1. (5 + 5 + 5 = 15).

🎙️ Let's solve a simple one. A + A + A = BA. First, look at the units column. Three times 'A' must result in a number ending in 'A'. The only digits that work are 0 (3x0=0) or 5 (3x5=15). If A is 0, BA would be 00, which isn't a two-digit number. So A must be 5. This gives us a carry-over of 1 to the tens column. Since there are no other tens digits, B must be 1. So, 5 + 5 + 5 = 15!

Example: Letters for Digits - Complex Addition

  • Problem: 4A + B9 = 6C
  • Units place: A + 9 ends in C. (A+9 = C or A+9 = 1C).
  • Tens place: 4 + B (+ carry-over) = 6.
  • If A=1, C=0 (1+9=10, carry 1). Then 4+B+1=6 => 5+B=6 => B=1. But A and B must be unique. So A≠1.
  • If A=2, C=1 (2+9=11, carry 1). Then 4+B+1=6 => 5+B=6 => B=1. Unique. So A=2, B=1, C=1.
  • Solution: A=2, B=1, C=1. (42 + 19 = 61).

🎙️ Here's a slightly more challenging one. 4A + B9 = 6C. We need to find A, B, and C. Start with the units column: A + 9 results in C (and possibly a carry-over). Then, look at the tens column: 4 + B plus any carry-over must equal 6. We can systematically try values for A, remembering that A, B, and C must be unique digits. After trying A=1, we find A=2 works, giving us A=2, B=1, C=1. So, 42 + 19 = 61.

Example: Letters for Digits - Multiplication

  • Problem: A × 3 = CA
  • Units place: A × 3 ends in A. Possible A values: 0 or 5.
  • If A=0, then 0 × 3 = 0. So CA = 00, not a 2-digit number. So A≠0.
  • If A=5, then 5 × 3 = 15. Units digit is 5, carry-over is 1.
  • Tens place: C = carry-over = 1.
  • Solution: A=5, C=1. (5 × 3 = 15).

🎙️ Multiplication puzzles work similarly. Consider A multiplied by 3 gives CA. Focus on the units digit first. What digit, when multiplied by 3, results in a number ending in itself? Only 0 (0x3=0) and 5 (5x3=15) fit this. Since CA is a two-digit number, A cannot be 0. So A must be 5. This gives a carry-over of 1, which means C is 1. Thus, 5 times 3 is 15!

Divisibility Rule for 10: Ending in Zero!

  • A number is divisible by 10 if its unit digit is 0.
  • Example: 120, 500, 7890 are divisible by 10.
  • General form: Any number can be written as 10k + r (where r is remainder).
  • If r=0, then the number is 10k, which is always divisible by 10.

🎙️ This is probably the easiest divisibility rule! If a number ends in zero, it's divisible by 10. Think of it this way: 120 is 12 tens, so it's clearly divisible by 10. In general form, if a number can be written as 10 times some integer 'k', it means its units digit is 0, and it's perfectly divisible by 10.

Divisibility Rule for 5: Ends in 0 or 5!

  • A number is divisible by 5 if its unit digit is 0 or 5.
  • Example: 45, 130, 995 are divisible by 5.
  • General form: 10k + 0 or 10k + 5.
  • Both 10k and 5 are divisible by 5, so their sum is too.

🎙️ The rule for 5 is also quite straightforward. Numbers divisible by 5 always end in either 0 or 5. This is because any number can be thought of as a multiple of 10 plus its unit digit. Since 10k is always divisible by 5, if the unit digit (0 or 5) is also divisible by 5, then the whole number is divisible by 5.

Divisibility Rule for 2: Even Numbers!

  • A number is divisible by 2 if its unit digit is 0, 2, 4, 6, or 8 (an even number).
  • Example: 72, 104, 568 are divisible by 2.
  • General form: 10k + u (where u is the unit digit).
  • Since 10k is divisible by 2, if 'u' is also divisible by 2, the whole number is.

🎙️ You've probably known this rule since primary school! Even numbers are divisible by 2. This means their last digit is 0, 2, 4, 6, or 8. Using our general form, a number is 10k plus its unit digit. Since 10k is always an even number (a multiple of 2), if the unit digit is also even, the entire number will be divisible by 2.

Divisibility Rule for 3: Sum of Digits!

  • A number is divisible by 3 if the sum of its digits is divisible by 3.
  • Example: For 123, sum = 1+2+3 = 6. Since 6 is divisible by 3, 123 is too.
  • General form for 3-digit number (100a+10b+c):
  • 100a+10b+c = (99a+a) + (9b+b) + c = 99a+9b + (a+b+c).
  • Since 99a+9b is always divisible by 3, if (a+b+c) is divisible by 3, the number is.

🎙️ This is a slightly more interesting rule! For a number to be divisible by 3, the sum of its digits must be divisible by 3. The proof uses our general form: we can rearrange the number to show that it's a sum of a number always divisible by 3 (like 99a + 9b) and the sum of its digits. So, if the sum of digits is divisible by 3, the whole number is!

Divisibility Rule for 3 and 9: Deeper Dive

  • Consider a 3-digit number 'abc' = 100a + 10b + c.
  • We can write 100a = (99 + 1)a = 99a + a.
  • And 10b = (9 + 1)b = 9b + b.
  • So, abc = 99a + a + 9b + b + c = (99a + 9b) + (a + b + c).
  • Since (99a + 9b) is always divisible by 3 (and 9), 'abc' is divisible by 3 (or 9) if and only if (a+b+c) is.

🎙️ This slide provides a more formal explanation of why the sum of digits rule works for 3 and 9. By cleverly rewriting 100a as 99a + a, and 10b as 9b + b, we can separate the number into two parts: one that is always a multiple of 3 (or 9), and the other part which is simply the sum of the digits. This proves the rule!

Divisibility Rule for 11: Alternating Sum!

  • A number is divisible by 11 if the difference between the sum of digits at odd places and the sum of digits at even places is either 0 or a multiple of 11.
  • Example: For 1331: (1+3) - (3+1) = 4 - 4 = 0. So 1331 is divisible by 11.
  • This rule is a bit more complex but very powerful.

🎙️ The divisibility rule for 11 is quite unique! It involves an 'alternating sum.' You take the sum of digits at odd places (from the right) and subtract the sum of digits at even places. If this difference is 0 or a multiple of 11, then the number is divisible by 11. Let's look at an example to make this clearer.

Example: Divisibility Rule for 11

  • Check if 61809 is divisible by 11.
  • Digits at odd places (from right): 9, 8, 6. Sum = 9 + 8 + 6 = 23.
  • Digits at even places (from right): 0, 1. Sum = 0 + 1 = 1.
  • Difference = 23 - 1 = 22.
  • Since 22 is a multiple of 11 (22 = 11 × 2), 61809 is divisible by 11.

🎙️ Let's apply the rule to 61809. Starting from the right, the digits at odd positions are 9, 8, and 6. Their sum is 23. The digits at even positions are 0 and 1. Their sum is 1. The difference between these sums is 23 - 1 = 22. Since 22 is a multiple of 11, we know that 61809 is indeed divisible by 11!

Advanced Divisibility: Finding Missing Digits

  • Problem: If 31Z5 is a multiple of 3, what is the value of Z?
  • For divisibility by 3, sum of digits must be a multiple of 3.
  • Sum = 3 + 1 + Z + 5 = 9 + Z.
  • Possible values for Z: 0, 3, 6, 9 (since 9+0=9, 9+3=12, 9+6=15, 9+9=18 are multiples of 3).
  • All these values are possible.

🎙️ We can use divisibility rules to find missing digits in a number. If 31Z5 is a multiple of 3, then the sum of its digits (3+1+Z+5) must be a multiple of 3. This simplifies to 9+Z. Now we just need to find digits Z (from 0 to 9) that make 9+Z a multiple of 3. Z could be 0, 3, 6, or 9.

Advanced Divisibility: Finding Multiple Digits

  • Problem: If 21Y5X is a multiple of 10, 5, and 3, find X and Y.
  • Multiple of 10: X must be 0.
  • Multiple of 5: X must be 0 or 5. Since X=0, this is satisfied.
  • Multiple of 3: Sum of digits (2+1+Y+5+X) must be a multiple of 3.
  • Sum = 2+1+Y+5+0 = 8+Y. Possible Y values: 1, 4, 7.
  • So, X=0 and Y can be 1, 4, or 7.

🎙️ Here's a more complex problem involving multiple divisibility rules. We have 21Y5X. First, for it to be a multiple of 10, X must be 0. This also satisfies the condition for divisibility by 5. Now, for divisibility by 3, the sum of all digits must be a multiple of 3. Substituting X=0, we get 8+Y. What values of Y (0-9) make 8+Y a multiple of 3? Y can be 1, 4, or 7. So, we have multiple solutions for Y.

Common Mistakes to Avoid!

  • Confusing 'a' and '10a' in general form.
  • Forgetting 'carry-overs' in letter puzzles.
  • Assuming a letter can be 0 when it's the first digit.
  • Incorrectly applying divisibility rules (e.g., for 11).
  • Not testing all possible digit values in puzzles.

🎙️ Even experts make mistakes! Be careful when writing numbers in general form; 'a' is a digit, '10a' is its place value. Always remember carry-overs in addition/multiplication puzzles. A number can't start with zero. And for divisibility rules, especially 11, practice makes perfect. Always double-check your work!
