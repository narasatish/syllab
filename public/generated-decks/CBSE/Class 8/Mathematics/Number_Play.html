Numbers in General Form: Two-Digit

  • A two-digit number 'ab' means 10a + b.
  • Here, 'a' is the tens digit and 'b' is the units digit.
  • Example: 37 = 10 × 3 + 7.

🎙️ Every number has a place value. For a two-digit number, the first digit represents tens and the second represents units. So, if we have a number 'ab', it's actually 'a' multiplied by 10, plus 'b'. This general form is very powerful.

Numbers in General Form: Three-Digit

  • A three-digit number 'abc' means 100a + 10b + c.
  • Here, 'a' is hundreds, 'b' is tens, 'c' is units.
  • Example: 524 = 100 × 5 + 10 × 2 + 4.

🎙️ Similarly, for a three-digit number, we extend the concept. The first digit is multiplied by 100, the second by 10, and the third is the unit digit. Understanding this structure is key to solving number puzzles.

Reversing Digits: Two-Digit Numbers

  • Original number 'ab' is 10a + b.
  • Reversed number 'ba' is 10b + a.
  • The difference or sum can reveal interesting patterns.

🎙️ What happens when we swap the digits of a two-digit number? The original number 'ab' becomes 'ba'. This simple change can lead to some fascinating mathematical properties, especially when we add or subtract them.

1Original: ab (10a+b)
2Reverse: ba (10b+a)

Worked Example: Reversing 2-Digit

  • Let the number be 43.
  • Original form: 10 × 4 + 3 = 43.
  • Reversed form: 10 × 3 + 4 = 34.
  • Sum: 43 + 34 = 77. Difference: 43 - 34 = 9.

🎙️ Let's take 43. When reversed, it becomes 34. Notice the sum is 77, which is 7 times 11. The difference is 9. We'll explore these patterns more, but for now, understand the mechanics of reversing digits.

1Number: 43
2Reversed: 34
3Sum: 77
4Difference: 9

Reversing Digits: Three-Digit Numbers

  • Original number 'abc' is 100a + 10b + c.
  • Reversed number 'cba' is 100c + 10b + a.
  • The middle digit 'b' remains in the tens place.

🎙️ For three-digit numbers, reversing means the hundreds digit becomes units, and the units digit becomes hundreds. The tens digit stays in its position. This leads to slightly different but equally interesting patterns.

1Original: abc (100a+10b+c)
2Reverse: cba (100c+10b+a)

Divisibility Rules: Introduction

  • Rules to quickly check if a number is divisible by another.
  • No need for long division!
  • Helps in factorisation and problem-solving.

🎙️ Divisibility rules are fantastic shortcuts! Instead of doing a full division, these rules tell us if a number can be divided evenly by another. They are super useful for simplifying fractions and solving problems faster.

Divisibility Rule for 10

  • A number is divisible by 10 if its units digit is 0.
  • Example: 120, 3450, 700 are all divisible by 10.
  • Numbers ending in any other digit are not.

🎙️ This is one of the easiest rules! If a number ends with a zero, it's definitely divisible by 10. Think of tens, hundreds, thousands – they all end in zero. This rule is straightforward and very helpful.

Divisibility Rule for 5

  • A number is divisible by 5 if its units digit is 0 or 5.
  • Example: 25, 130, 755 are all divisible by 5.
  • Numbers like 12, 47, 91 are not.

🎙️ Similar to the rule for 10, the rule for 5 is also about the last digit. If a number ends in either a 0 or a 5, it's perfectly divisible by 5. This makes checking for factors of 5 very quick.

Divisibility Rule for 2

  • A number is divisible by 2 if its units digit is an even number (0, 2, 4, 6, 8).
  • Example: 48, 102, 566 are all divisible by 2.
  • These are also called even numbers.

🎙️ For divisibility by 2, we just look at the very last digit. If it's an even number – 0, 2, 4, 6, or 8 – then the entire number is divisible by 2. This rule defines what an 'even' number is.

Divisibility Rule for 3

  • A number is divisible by 3 if the sum of its digits is divisible by 3.
  • Example: For 123, sum = 1+2+3 = 6. Since 6 is divisible by 3, 123 is divisible by 3.
  • For 25, sum = 2+5 = 7. Not divisible by 3.

🎙️ This rule is a bit different; we sum up all the digits of the number. If that sum is a multiple of 3, then the original number is also divisible by 3. It's a clever trick!

1Sum the digits
2Check if sum ÷ 3

Divisibility Rule for 9

  • A number is divisible by 9 if the sum of its digits is divisible by 9.
  • Example: For 459, sum = 4+5+9 = 18. Since 18 is divisible by 9, 459 is divisible by 9.
  • For 123, sum = 1+2+3 = 6. Not divisible by 9.

🎙️ The rule for 9 is very similar to the rule for 3. Again, you sum the digits, but this time, you check if the sum is divisible by 9. If it is, the original number is divisible by 9.

1Sum the digits
2Check if sum ÷ 9

Rules for Letters for Digits

  • Each letter must represent only one digit.
  • The same letter always represents the same digit.
  • The first digit of a number cannot be 0.

🎙️ Remember these three crucial rules. Every letter is unique, and its value stays consistent throughout the puzzle. And just like real numbers, a multi-digit number cannot start with a zero.

Worked Example: Addition Puzzle

  • Puzzle: A + A + A = BA
  • Find A and B.

🎙️ Let's solve a classic puzzle. Here, A+A+A equals a two-digit number BA. We look at the units column first. 3 times A must end in A. This only happens if A is 0 or 5. Since A cannot be 0 (as it's the first digit in BA), A must be 5. Then, 3 times 5 is 15, so B is 1.

1Units column: 3A ends in A. So A must be 0 or 5.
2If A=0, then 0+0+0=0. B=0. But letters must be unique. So A≠0.
3If A=5, then 3A = 15. Units digit is 5 (A), carry-over is 1.
4Tens column: B = carry-over = 1.
5Solution: A=5, B=1. (5+5+5=15)

Worked Example: Multiplication Puzzle

  • A B
  • x 3
  • -----
  • C A B
  • Find A, B, C.

🎙️ In this multiplication puzzle, AB times 3 equals CAB. First, look at the units digit: B multiplied by 3 must result in a number ending in B. This means B can be 0 or 5. If B is 0, then 3 times A ends in A, which means A is 0 or 5. Since A cannot be 0 (first digit), A must be 5. So, 50 times 3 is 150, giving A=5, B=0, C=1.

1B x 3 ends in B. So B must be 0 or 5.
2If B=0: A0 x 3 = CA0. So 3A ends in A. A must be 0 or 5.
3A cannot be 0 (first digit). So A=5. (3x5=15, C=1, A=5).
4Check: 50 x 3 = 150. So A=5, B=0, C=1.
