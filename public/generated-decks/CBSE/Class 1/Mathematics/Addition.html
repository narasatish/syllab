Jump on the Number Line!

  • Let's add 2 + 3.
  • Start at number 2.
  • Jump 3 steps forward: 3, 4, 5.
  • We land on 5! So, 2 + 3 = 5.

🎙️ Let's add 2 plus 3 using the number line. First, find number 2 on the line. Now, we need to jump 3 steps forward. One jump to 3, two jumps to 4, three jumps to 5! We landed on 5, so 2 plus 3 is 5.

Adding Zero (0)

  • Zero means 'nothing'.
  • If you add zero to any number, the number stays the same.
  • Example: 3 cookies + 0 cookies = 3 cookies.

🎙️ Zero is a special number! If you have 3 yummy cookies and no one gives you any more (that means 0 more), how many cookies do you still have? You still have 3! Adding zero never changes the number.

Adding One (1)

  • If you add one to any number, you get the 'next' number.
  • It's like counting one step forward.
  • Example: 4 pencils + 1 pencil = 5 pencils.

🎙️ Adding one is also very easy! When you add 1 to a number, you just get the very next number in the counting sequence. For example, if you have 4 pencils and get 1 more, you now have 5 pencils, which is the next number after 4.

Oops! Common Mistakes

  • Not counting all items: Make sure to count everything.
  • Forgetting to add 1: If you add 1, always go to the next number.
  • Mixing up + and - signs: Remember + means 'put together'.

🎙️ Sometimes, we make small mistakes, and that's okay! A common one is forgetting to count all the items. Always double-check your count. Also, remember that adding 1 always gives you the next number. And don't confuse the plus sign with other signs!
