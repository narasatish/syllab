What is "Addition"?

  • It means putting things together.
  • We find out 'how many in all'.
  • It makes numbers bigger!

🎙️ Addition is simply when we take two or more groups of things and put them all together. When we do this, the total number of things becomes more than what we started with in each group. We want to know 'how many altogether'!

The "Plus" Sign ( + )

  • This sign means 'add'.
  • We read it as 'plus'.
  • It tells us to put numbers together.

🎙️ Look at this special sign! It looks like a small cross. This is called the 'plus sign'. Whenever you see this sign between numbers, it means you need to add them, or put them together.

Adding "Zero" (0)

  • Zero means 'nothing'.
  • When we add zero, the number stays the same.
  • 5 + 0 = 5.

🎙️ Zero is a very special number! It means there is nothing. If you have 5 chocolates and I give you 0 more chocolates, how many do you have? Still 5! So, adding zero doesn't change the number.

0️⃣
Nothing Added

Adding "One" (1)

  • When we add one, the number becomes the 'next' number.
  • It's like counting forward one step.
  • 7 + 1 = 8.

🎙️ Adding one is super easy! If you have 7 toys and I give you 1 more, you get the next number, which is 8! It's like taking one step forward on a number line. Always the next number!

Adding Up and Down!

  • We can write numbers one below the other.
  • We add the numbers from top to bottom.
  • This makes it neat and easy!

🎙️ Sometimes, it's easier to add numbers by writing them one on top of the other. This is called 'vertical addition'. We always start from the top and add downwards. It helps us keep our work tidy!

Adding More Numbers!

  • We can add three or more numbers too!
  • Just add two numbers first, then add the third one.
  • Example: 1 + 2 + 3 = ?

🎙️ Sometimes, we might need to add more than two numbers together. It's just as easy! You add the first two numbers, get a total, and then add the third number to that total. For example, 1 + 2 is 3, and then 3 + 3 is 6!

🔶🔶🔶🔶🔶🔶
1 + 2 + 3 = 6
