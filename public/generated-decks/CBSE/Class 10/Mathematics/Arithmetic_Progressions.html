What is an Arithmetic Progression (AP)?

  • A special type of sequence.
  • The difference between consecutive terms is constant.
  • This constant difference is key to an AP!

🎙️ An Arithmetic Progression, or AP, is a very special sequence. What makes it special? The difference between any term and its preceding term is always the same. It's like adding the same number again and again!

➕
Constant Addition

The Common Difference (d)

  • The constant difference in an AP.
  • Found by subtracting any term from its succeeding term.
  • Can be positive, negative, or zero.

🎙️ We call this constant difference the 'common difference' and denote it by 'd'. To find 'd', just pick any term and subtract the term before it. Remember, 'd' can be positive, negative, or even zero!

The General Form of an AP

  • First term: 'a'
  • Common difference: 'd'
  • Terms are: a, a+d, a+2d, a+3d, ...

🎙️ Every AP can be written in a general form using just two values: the first term, 'a', and the common difference, 'd'. Each subsequent term is found by simply adding 'd' to the previous term. This pattern helps us understand and predict the terms.

Finding the nth Term (a_n)

  • Formula: a_n = a + (n-1)d
  • a_n: the nth term
  • a: first term, d: common difference, n: term number

🎙️ What if we want to find the 100th term without listing all of them? This formula is our magic key! It allows us to find any term in an AP directly, given the first term, common difference, and the term number 'n'.

🔍

Worked Example: Find the 10th term

  • AP: 2, 7, 12, ...
  • Identify: a = 2, d = 5, n = 10
  • a_10 = 2 + (10-1)5 = 2 + 9*5 = 2 + 45 = 47

🎙️ Here's how we use the formula. First, identify 'a', 'd', and 'n' from the problem. Then, substitute these values into the nth term formula and perform the calculation. The 10th term of this AP is 47.

Worked Example: Find 'n'

  • Which term of the AP 21, 18, 15, ... is -81?
  • Identify: a = 21, d = -3, a_n = -81
  • -81 = 21 + (n-1)(-3) => n = 35

🎙️ Sometimes, we know the value of a term but not its position. In this case, we set a_n to -81 and solve the equation for 'n'. Remember to be careful with negative common differences. We find that -81 is the 35th term.

Sum of First n Terms (S_n)

  • Formula: S_n = n/2 [2a + (n-1)d]
  • Alternative: S_n = n/2 [a + l] (where l = last term)
  • Used to find the total of the first 'n' terms.

🎙️ Sometimes we need to add up many terms of an AP, like the total number of seats in an auditorium where each row has more seats than the previous. These formulas help us find the sum of the first 'n' terms efficiently.

Worked Example: Find the Sum

  • Find the sum of the first 20 terms of the AP: 1, 3, 5, ...
  • Identify: a = 1, d = 2, n = 20
  • S_20 = 20/2 [2*1 + (20-1)2] = 10 [2 + 38] = 10 * 40 = 400

🎙️ Let's apply the sum formula. First, identify 'a', 'd', and 'n'. Substitute these into the formula and simplify. The sum of the first 20 odd numbers starting from 1 is 400. This is much faster than adding them one by one!

Worked Example: Find 'n' from Sum

  • How many terms of AP 9, 17, 25, ... give a sum of 636?
  • Identify: a = 9, d = 8, S_n = 636
  • 636 = n/2 [2*9 + (n-1)8] => 4n^2 + 5n - 636 = 0 => n = 12 (ignoring negative n)

🎙️ This is a slightly more complex problem where we need to find 'n' when the sum is given. It often leads to a quadratic equation. We solve the quadratic equation and choose the positive integer value for 'n' as the number of terms cannot be negative.

Interesting Properties of an AP

  • If a constant is added/subtracted to each term, the new sequence is also an AP.
  • If each term is multiplied/divided by a constant, the new sequence is also an AP.
  • The sum of terms equidistant from the beginning and end is constant.

🎙️ APs have some neat properties! If you shift all the terms up or down by the same amount, it's still an AP. The same goes for scaling them up or down. Also, a cool fact: the sum of the first and last term is the same as the sum of the second and second-to-last, and so on.

The Arithmetic Mean

  • If a, b, c are in AP, then b is the Arithmetic Mean of a and c.
  • Formula: b = (a + c) / 2
  • It's the middle term of three consecutive terms in an AP.

🎙️ For any three consecutive terms in an AP, the middle term is exactly the average of the first and the third term. This 'middle' term is called the Arithmetic Mean, and it represents the 'balance point' between the two outer terms.
