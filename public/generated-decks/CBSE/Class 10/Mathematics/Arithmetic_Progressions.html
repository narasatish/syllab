What is a Sequence?

  • An ordered list of numbers.
  • Each number is called a 'term'.
  • Example: 1, 3, 5, 7, ... (odd numbers).

🎙️ A sequence is simply a list of numbers arranged in a particular order. Think of it like a line of students, each student is a term, and they are in a specific order.

Introducing Arithmetic Progression (AP)

  • A sequence where each term (after the first) is obtained by adding a fixed number to the preceding term.
  • This fixed number is called the 'common difference'.
  • Example: 5, 10, 15, 20, ... (adding 5 each time).

🎙️ An Arithmetic Progression, or AP, is a special kind of sequence. The key idea is that the difference between any two consecutive terms is always the same. This 'same difference' is very important.

Key Features of an AP

  • First Term (a): The starting number.
  • Common Difference (d): The fixed number added.
  • Terms: a1, a2, a3, ..., an.

🎙️ Every AP has two main ingredients: its first term, usually denoted by 'a', and its common difference, denoted by 'd'. Knowing these two values helps us understand the entire progression.

Common Difference (d)

  • Calculated by subtracting any term from its succeeding term.
  • d = a2 - a1 = a3 - a2, and so on.
  • Can be positive, negative, or zero.

🎙️ The common difference 'd' is the heart of an AP. To find it, you simply pick any term and subtract the term just before it. Make sure this difference is consistent throughout the sequence for it to be an AP.

First Term (a)

  • The very first number in the sequence.
  • It's the starting point of the progression.
  • Example: In 3, 7, 11, 15, ..., the first term (a) is 3.

🎙️ The first term, 'a', is straightforward – it's just the initial number from which the progression starts. All other terms are built upon this first term and the common difference.

General Form of an AP

  • An AP can be written as: a, a+d, a+2d, a+3d, ...
  • Here 'a' is the first term and 'd' is the common difference.
  • This form helps us generate any term in the sequence.

🎙️ This general form is like a blueprint for any arithmetic progression. If you know 'a' and 'd', you can write out as many terms of the AP as you like, simply by adding 'd' repeatedly.

Finding the nth Term of an AP (an)

  • What if we want to find the 100th term without listing them all?
  • We use a special formula for this.
  • The 'nth term' means any term at position 'n'.

🎙️ Imagine an AP with thousands of terms. We can't list them all out to find a specific one like the 50th or 1000th term. Thankfully, there's a powerful formula that helps us jump directly to any term we want.

🔍
Locating a Term
12 / 26

Deriving the nth Term Formula

  • a1 = a
  • a2 = a + d
  • a3 = a + 2d
  • a4 = a + 3d

🎙️ Look at the pattern: the coefficient of 'd' is always one less than the term number. So for the 'n'th term, it will be (n-1)d. This gives us the general formula for the nth term.

1a1 = a
2a2 = a + (2-1)d
3a3 = a + (3-1)d
4an = a + (n-1)d
13 / 26

Formula for nth Term: an = a + (n-1)d

  • a: first term
  • d: common difference
  • n: position of the term you want to find
  • an: the value of the nth term

🎙️ This is a very important formula. Memorize it! It allows you to find any term in an AP if you know the first term, the common difference, and which term number you are looking for.

✨
The Magic Formula

Worked Example 1: Finding a Term

  • Find the 10th term of the AP: 2, 7, 12, ...
  • Here, a = 2, d = 7-2 = 5, n = 10.
  • Using an = a + (n-1)d: a10 = 2 + (10-1)5
  • a10 = 2 + 9*5 = 2 + 45 = 47.

🎙️ Let's apply the formula. First, identify 'a', 'd', and 'n' from the given problem. Then, substitute these values into the formula and calculate. It's a straightforward process once you have the values.

15 / 26

Worked Example 2: Finding 'n'

  • Which term of the AP: 21, 18, 15, ... is -81?
  • Here, a = 21, d = 18-21 = -3, an = -81.
  • Using an = a + (n-1)d: -81 = 21 + (n-1)(-3)
  • -81 - 21 = -3(n-1) => -102 = -3(n-1) => 34 = n-1 => n = 35.

🎙️ Sometimes, you might be given a term's value and asked to find its position 'n'. The process is similar: plug in the known values into the formula and then solve the equation for 'n'. Remember to handle negative numbers carefully.

Sum of First n Terms of an AP (Sn)

  • What if we need to add up all the terms in an AP?
  • Example: Sum of first 5 terms of 1, 2, 3, 4, 5.
  • We have a formula for this too!

🎙️ Sometimes, we don't just want to find a specific term, but the total sum of a certain number of terms in an AP. Imagine adding all the savings from our previous example for 30 days. This formula makes it easy.

➕
Adding Them Up
19 / 26

Deriving the Sum Formula

  • Sn = a + (a+d) + ... + (a+(n-1)d) (Eq 1)
  • Sn = (a+(n-1)d) + ... + (a+d) + a (Eq 2)
  • Add Eq 1 and Eq 2: 2Sn = n * [2a + (n-1)d]

🎙️ This derivation is famously attributed to young Gauss. By writing the sum forwards and backwards and adding them, you'll notice that each pair of terms sums to the same value, leading us to the formula.

1Sn = a + ... + l
2Sn = l + ... + a
32Sn = n(a + l)
4Sn = n/2 (a + l)
20 / 26

Formula for Sum of n Terms: Sn = n/2 [2a + (n-1)d]

  • a: first term
  • d: common difference
  • n: number of terms to sum
  • Sn: the sum of the first 'n' terms

🎙️ This is the primary formula for the sum of 'n' terms. It's crucial for solving problems where you need to find the total value of a series of numbers that form an AP.

∑
The Summation Formula

Alternative Sum Formula: Sn = n/2 [a + l]

  • Where 'l' is the last term (or the nth term, an).
  • This formula is useful when the last term is known.
  • It's derived from Sn = n/2 [a + a + (n-1)d].

🎙️ If you already know the last term of the AP you're summing, this alternative formula is even simpler to use. Remember, 'l' is just another way of writing 'an' - the nth term.

Worked Example 3: Finding the Sum

  • Find the sum of the first 20 terms of the AP: 1, 3, 5, 7, ...
  • Here, a = 1, d = 2, n = 20.
  • Sn = n/2 [2a + (n-1)d]
  • S20 = 20/2 [2*1 + (20-1)2] = 10 [2 + 19*2] = 10 [2 + 38] = 10 * 40 = 400.

🎙️ Let's put the sum formula into practice. Identify 'a', 'd', and 'n'. Substitute them carefully into the formula and perform the calculations. Always double-check your arithmetic.

Worked Example 4: Mixed Problem

  • The first term of an AP is 5, the last term is 45, and the sum is 400. Find the number of terms (n).
  • Given a = 5, l = 45, Sn = 400.
  • Using Sn = n/2 [a + l]: 400 = n/2 [5 + 45]
  • 400 = n/2 [50] => 400 = 25n => n = 16.

🎙️ This problem uses the alternative sum formula. When you're given the first term, last term, and the sum, this formula is perfect for finding 'n', the number of terms. It's a quick way to solve.

Recap: What We've Learned

  • Arithmetic Progression: Sequence with a common difference (d).
  • General form: a, a+d, a+2d, ...
  • nth term formula: an = a + (n-1)d
  • Sum of n terms formula: Sn = n/2 [2a + (n-1)d] or Sn = n/2 [a + l]

🎙️ We've covered the core concepts of Arithmetic Progressions today. Remember the definitions of 'a' and 'd', and most importantly, the two main formulas for the nth term and the sum of n terms. These are your tools for solving AP problems.
