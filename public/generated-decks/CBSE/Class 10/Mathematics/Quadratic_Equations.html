What IS a Quadratic Equation?

  • An equation with degree 2.
  • Highest power of the variable is 2.
  • Must contain an x² term.

🎙️ So, a quadratic equation is simply an equation where the highest power of the variable is exactly 2. If it has x² and nothing higher, it's quadratic. If x² is missing, it's not!

The Standard Form: ax² + bx + c = 0

  • a, b, c are real numbers.
  • a cannot be zero (otherwise, it's linear!).
  • x is the variable.

🎙️ This is the blueprint for all quadratic equations. Remember, 'a' cannot be zero because if it were, the x² term would vanish, and we'd be left with a linear equation, not a quadratic one.

Identifying Quadratic Equations

  • Example 1: x² + 5x - 6 = 0 (Yes, a=1).
  • Example 2: (x+1)² = 2x - 3 (Yes, simplifies to x² + 4 = 0).
  • Example 3: x³ + x² + 1 = 0 (No, degree 3).

🎙️ To identify a quadratic equation, always simplify it first. Then, look for the highest power of the variable. If it's 2, and the coefficient of x² is not zero, then it's a quadratic equation.

Solving by Factorisation: The Art of Splitting

  • Goal: Break ax² + bx + c = 0 into (px+q)(rx+s) = 0.
  • This means px+q = 0 or rx+s = 0.
  • Then solve for x in each part.

🎙️ Factorisation is like breaking a big problem into smaller, easier ones. We split the middle term bx in such a way that we can group terms and factor them, leading to two simpler linear equations.

2Split Middle Term

13 / 31

Example: Solve x² - 5x + 6 = 0

  • 1. Find two numbers whose product is 6 and sum is -5. (Ans: -2, -3)
  • 2. Split the middle term: x² - 2x - 3x + 6 = 0
  • 3. Factor by grouping: x(x-2) - 3(x-2) = 0
  • 4. (x-2)(x-3) = 0 => x=2 or x=3.

🎙️ Here, we look for two numbers that multiply to ac (1*6=6) and add up to b (-5). Once we find them, we replace the middle term, group, and factor out common terms to get our roots.

✂️
Splitting Term
14 / 31

Example: Solve 2x² + x - 6 = 0

  • 1. Product ac = 2 * -6 = -12, Sum b = 1. (Ans: 4, -3)
  • 2. Split: 2x² + 4x - 3x - 6 = 0
  • 3. Group: 2x(x+2) - 3(x+2) = 0
  • 4. (2x-3)(x+2) = 0 => x = 3/2 or x = -2.

🎙️ This example shows that the numbers might not always be integers. The process remains the same: find two numbers, split the middle term, factor by grouping, and solve the resulting linear equations.

Completing the Square: Making a Perfect Match

  • Transform ax² + bx + c = 0 into (x + k)² = d.
  • Then take square root on both sides.
  • Useful when factorisation is difficult.

🎙️ This method is like trying to complete a puzzle to form a perfect square. We manipulate the equation to get an expression like (x+k)² on one side, which then makes solving for 'x' much simpler.

🖼️
Perfect Picture
17 / 31

Example: Solve x² + 6x + 5 = 0

  • 1. Move constant: x² + 6x = -5
  • 2. Add (b/2)² to both sides: (6/2)² = 9
  • x² + 6x + 9 = -5 + 9
  • 3. (x+3)² = 4
  • 4. x+3 = ±2 => x = -3+2 = -1 or x = -3-2 = -5.

🎙️ Here, we first isolate the x terms. Then, we add (b/2)² to both sides to create a perfect square trinomial on the left. This allows us to take the square root and easily solve for x.

2Add (b/2)²

18 / 31

Example: Solve 2x² - 7x + 3 = 0

  • 1. Divide by a: x² - (7/2)x + 3/2 = 0
  • 2. Move constant: x² - (7/2)x = -3/2
  • 3. Add (b/2)²: (-7/4)² = 49/16
  • x² - (7/2)x + 49/16 = -3/2 + 49/16
  • 4. (x - 7/4)² = 25/16
  • 5. x - 7/4 = ±5/4 => x = 7/4 + 5/4 = 12/4 = 3 or x = 7/4 - 5/4 = 2/4 = 1/2.

🎙️ When 'a' is not 1, we first divide the entire equation by 'a' to make the coefficient of x² equal to 1. Then, we follow the same steps as before. Don't be afraid of fractions!

The Magic Formula: Always Works!

  • Derived from Completing the Square.
  • Provides roots for any quadratic equation.
  • No need to guess factors or manipulate terms.

🎙️ This is arguably the most powerful method! The Quadratic Formula is a direct way to find the roots, no matter how complex the equation. It's a universal key that works every time.

✨
Universal Solution
21 / 31

Introducing the Quadratic Formula: x = [-b ± sqrt(b² - 4ac)] / 2a

  • Identify a, b, c from ax² + bx + c = 0.
  • Substitute values carefully.
  • Calculate the two possible roots (due to ±).

🎙️ Memorize this formula! It will be your best friend for quadratic equations. Just plug in the values of 'a', 'b', and 'c' from your equation, and it will give you the solutions directly.

➗
The Formula
22 / 31

Example: Solve x² + 5x + 6 = 0

  • 1. Identify: a=1, b=5, c=6.
  • 2. Substitute into formula: x = [-5 ± sqrt(5² - 4*1*6)] / (2*1)
  • 3. Calculate: x = [-5 ± sqrt(25 - 24)] / 2
  • x = [-5 ± sqrt(1)] / 2
  • 4. x = (-5 + 1) / 2 = -4/2 = -2 or x = (-5 - 1) / 2 = -6/2 = -3.

🎙️ This is the same equation we solved by factorisation. Notice how the formula gives us the exact same roots. It's a reliable method, especially when factorisation isn't obvious.

🔢
Calculation Steps
23 / 31

Example: Solve 3x² - 5x + 2 = 0

  • 1. Identify: a=3, b=-5, c=2.
  • 2. Substitute: x = [-(-5) ± sqrt((-5)² - 4*3*2)] / (2*3)
  • 3. Calculate: x = [5 ± sqrt(25 - 24)] / 6
  • x = [5 ± sqrt(1)] / 6
  • 4. x = (5 + 1) / 6 = 6/6 = 1 or x = (5 - 1) / 6 = 4/6 = 2/3.

🎙️ Pay close attention to the signs, especially when 'b' is negative, as (-b) will become positive. Always perform the operations inside the square root first, then simplify.

Nature of Roots: What Kinds of Keys?

  • The expression b² - 4ac is called the Discriminant (D).
  • It 'discriminates' between the nature of the roots.
  • Tells us if roots are real, equal, or not real.

🎙️ The discriminant is a very powerful part of the quadratic formula! Just by looking at its value, we can predict whether our equation will have two distinct real solutions, one repeated real solution, or no real solutions at all.

🤔
What Kind?

Understanding the Discriminant (D)

  • 1. D > 0: Two distinct real roots.
  • 2. D = 0: Two equal real roots (or one repeated root).
  • 3. D < 0: No real roots (roots are complex/imaginary).

🎙️ These three cases are crucial. If D is positive, you get two different real numbers. If D is zero, you get one real number repeated. If D is negative, you can't take the square root of a negative number in real numbers, so there are no real solutions.

Beware! Common Pitfalls!

  • **Sign Errors**: Especially with (-b) or (-4ac).
  • **Calculation Errors**: Squaring negative numbers, order of operations.
  • **Not Simplifying**: Forgetting to convert to standard form ax² + bx + c = 0.
  • **Incorrectly Identifying a, b, c**.

🎙️ Many errors happen due to small slips. Always double-check your signs, perform calculations carefully, and ensure your equation is in the standard form before identifying a, b, c.
