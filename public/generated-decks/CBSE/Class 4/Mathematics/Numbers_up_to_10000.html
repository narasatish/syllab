Breaking Down Numbers

  • We can write numbers by showing the value of each digit.
  • This is called the Expanded Form.

🎙️ Think of a number as a puzzle. Each piece is a digit, and it has a special value based on its place. Expanded form means we break the number into these value pieces.

Compare 2345 and 2435

  • Thousands place: Both have '2'.
  • Hundreds place: 2345 has '3', 2435 has '4'.
  • So, 2435 is greater than 2345!

🎙️ Let's compare 2345 and 2435. The thousands digit is the same (2). So we move to the hundreds digit. Here, 3 is smaller than 4, so 2435 is the bigger number!
