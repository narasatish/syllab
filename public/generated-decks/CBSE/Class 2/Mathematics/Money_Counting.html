Let's Count Coins Together!

  • If you have one ₹5 coin and one ₹2 coin.
  • How much money is it? ₹5 + ₹2 = ₹7.

🎙️ Now, let's try counting! It's like adding numbers. If you have a five rupee coin and a two rupee coin, you just add their values to find the total amount of money you have.

🪙🪙

More Coin Counting Fun!

Counting Notes is Easy!

  • If you have one ₹10 note and one ₹20 note.
  • How much money is it? ₹10 + ₹20 = ₹30.

🎙️ Counting notes is just like counting coins! You simply add the numbers written on them. A ten rupee note and a twenty rupee note together make thirty rupees. See, it's simple!
