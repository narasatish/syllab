Recap: Sets and Cartesian Product

  • A Set is a well-defined collection of distinct objects.
  • A x B = { (a, b) : a ∈ A, b ∈ B } is the Cartesian Product.
  • It consists of all possible ordered pairs.
  • Example: If A={1,2}, B={a,b}, then A x B = {(1,a), (1,b), (2,a), (2,b)}.

🎙️ Before we define relations, it's vital to recall sets and the Cartesian product. Remember, a set is simply a collection, and the Cartesian product gives us all possible pairings between elements of two sets. This forms the universal set for any relation we define.

What is a Relation?

  • A relation R from a non-empty set A to a non-empty set B is a subset of the Cartesian product A x B.
  • R ⊆ A x B.
  • If (a, b) ∈ R, we say 'a is related to b'.
  • Relations define connections between elements.

🎙️ A relation is essentially a rule or condition that connects elements from one set to another. It's not just any connection, but a specific collection of ordered pairs, chosen from the Cartesian product. Think of it as a directed link or association.

Domain, Codomain, and Range of a Relation

  • Domain: The set of all first elements of the ordered pairs in R.
  • Codomain: The entire set B (where the relation maps to).
  • Range: The set of all second elements of the ordered pairs in R.
  • Range is always a subset of the Codomain.

🎙️ These three terms are crucial for describing a relation precisely. The domain tells us 'from where' the relation starts, the codomain tells us 'to where' it could potentially map, and the range tells us 'to where' it actually maps. Don't confuse codomain with range; range is a subset of the codomain.

Types of Relations on a Set A

  • We often study relations from a set A to itself (R ⊆ A x A).
  • Empty Relation: No elements are related.
  • Universal Relation: All elements are related.
  • Reflexive, Symmetric, Transitive: Key properties.

🎙️ When a relation is defined on a single set A, meaning from A to A, we categorize them based on specific properties. These classifications are fundamental and will help us understand more complex concepts like equivalence relations. Let's look at each type in detail.

Type 1: Empty Relation (Void Relation)

  • A relation R on set A is empty if no element of A is related to any element of A.
  • R = ∅ ⊂ A x A.
  • No ordered pair (a,b) satisfies the relation's condition.
  • Example: R = {(a,b) : a,b ∈ A, a - b = 100} on A = {1,2,3,4}.

🎙️ An empty relation is one where the given rule or condition is impossible to satisfy for any pair of elements in the set. It's a valid relation because the empty set is a subset of any set, including A x A. It represents a complete lack of connection.

Type 2: Universal Relation

  • A relation R on set A is universal if every element of A is related to every element of A.
  • R = A x A.
  • All possible ordered pairs are part of the relation.
  • Example: R = {(a,b) : a,b ∈ A, |a - b| ≥ 0} on A = {1,2,3}.

🎙️ In contrast to the empty relation, a universal relation means that every element is connected to every other element, including itself, based on the defined rule. The condition for a universal relation is always true for any pair of elements from the set. Both empty and universal relations are sometimes called trivial relations.

Type 3: Reflexive Relation

  • A relation R on set A is reflexive if (a, a) ∈ R for every a ∈ A.
  • Every element must be related to itself.
  • Example: R = {(a,b) : a divides b} on positive integers.
  • Example: 'is equal to' (a=a) is reflexive.

🎙️ A reflexive relation is like looking in a mirror; every element sees itself. The key is that this property must hold for *every* element in the set A. If even one element 'a' does not have (a,a) in the relation, then it's not reflexive.

Type 4: Symmetric Relation

  • A relation R on set A is symmetric if (a, b) ∈ R implies (b, a) ∈ R for all a, b ∈ A.
  • If a is related to b, then b must be related to a.
  • Example: R = {(a,b) : a is a sibling of b} on a set of people.
  • Example: 'is perpendicular to' for lines.

🎙️ Symmetry in relations means a two-way street. If there's a connection from 'a' to 'b', there must be an identical connection from 'b' to 'a'. If (a,b) is not in R, then (b,a) is not required to be in R for symmetry to hold. It only applies if (a,b) is present.

🤝

Type 5: Transitive Relation

  • A relation R on set A is transitive if (a, b) ∈ R and (b, c) ∈ R implies (a, c) ∈ R for all a, b, c ∈ A.
  • If a is related to b, and b is related to c, then a must be related to c.
  • Example: R = {(a,b) : a is less than b} on integers (a < b and b < c implies a < c).
  • Example: 'is a subset of' for sets.

🎙️ Transitivity means that if you can form a chain of relationships, the first element is also directly related to the last. This property is often tricky for students. Remember, if there is no 'chain' (i.e., no (a,b) and (b,c) present), then the condition for transitivity is vacuously true.

Equivalence Relation

  • A relation R on a set A is an equivalence relation if it is simultaneously:
  • 1. Reflexive
  • 2. Symmetric
  • 3. Transitive
  • Equivalence relations partition a set into disjoint equivalence classes.

🎙️ Equivalence relations are extremely important in mathematics. They group elements that are 'equivalent' in some sense, creating partitions within the set. Think of 'is equal to' or 'has the same birthday as' – these are common equivalence relations you encounter daily.

Worked Example 1: Checking Equivalence Relation

  • Show that R = {(a,b) : a - b is an even integer} on Z (integers) is an equivalence relation.
  • Step 1: Check Reflexivity
  • Step 2: Check Symmetry
  • Step 3: Check Transitivity

🎙️ Let's walk through this classic example. For reflexivity, we need to show that a-a is always even. For symmetry, if a-b is even, then b-a must also be even. For transitivity, if a-b and b-c are even, their sum a-c must also be even. Since all three hold, R is an equivalence relation.

1Reflexive: a-a=0 (even). Yes.
2Symmetric: a-b=2k => b-a=-2k (even). Yes.
3Transitive: a-b=2k, b-c=2m => a-c=2(k+m) (even). Yes.

Common Mistakes in Relations

  • Confusing Codomain and Range.
  • Missing a single element for reflexivity (must hold for ALL).
  • Incorrectly applying symmetry (only if (a,b) exists).
  • Misinterpreting transitivity (vacuously true if no chain).
  • Not writing clear logical steps for proofs.

🎙️ Students often lose marks due to these common errors. Always be precise with definitions, especially when proving properties. Ensure you check the conditions for *all* relevant elements or pairs, and articulate your reasoning clearly using mathematical notation. Practice is key to avoiding these pitfalls.

Recap: Functions from Class 11

  • A function f from A to B (f: A → B) is a relation where every element in A has exactly one image in B.
  • Domain: Set A. Codomain: Set B. Range: {f(x) : x ∈ A}.
  • Vertical Line Test for graphs.
  • Types: One-to-one, Onto, Many-to-one, Into.

🎙️ Recall that a function is a very special type of relation. It mandates two crucial conditions: every element in the domain must be mapped, and it must be mapped to only one element in the codomain. This 'input-output machine' concept is fundamental for understanding advanced functions.

Type 1: One-to-One (Injective) Function

  • A function f: A → B is one-to-one if distinct elements of A have distinct images in B.
  • If f(x₁) = f(x₂), then x₁ = x₂.
  • No two different elements map to the same image.
  • Horizontal Line Test for graphs.

🎙️ An injective function ensures that each element in the domain has a unique partner in the codomain. Think of it as each person having their own unique seat. To prove it, we assume the images are equal and show that the original elements must also be equal.

Unique Mapping

Type 2: Onto (Surjective) Function

  • A function f: A → B is onto if every element in B is the image of at least one element in A.
  • For every y ∈ B, there exists an x ∈ A such that f(x) = y.
  • The range of the function is equal to its codomain.
  • Every element in the codomain is 'covered'.

🎙️ A surjective function means that the function 'hits' every element in the codomain. There are no 'unmapped' elements left in B. To prove surjectivity, you typically take an arbitrary 'y' from the codomain and show that you can find an 'x' in the domain such that f(x) = y.

Type 3: Bijective Function

  • A function f: A → B is bijective if it is both one-to-one (injective) AND onto (surjective).
  • Each element in A maps to a unique element in B, and all elements in B are mapped to.
  • Such functions have an inverse.
  • Crucial for advanced topics like inverse functions and isomorphisms.

🎙️ A bijective function is the 'perfect' mapping, establishing a one-to-one correspondence between the elements of two sets. This perfect pairing is what allows us to define an inverse function, which is a key concept we'll discuss next. Understanding bijectivity is vital.

  • Examine the function f: N → N given by f(x) = 2x for injectivity and surjectivity.
  • Step 1: Check for Injectivity (One-to-one)
  • Step 2: Check for Surjectivity (Onto)
  • N represents the set of natural numbers {1, 2, 3, ...}.

Composition of Functions

  • Let f: A → B and g: B → C be two functions.
  • The composition of f and g, denoted by gof, is a function gof: A → C.
  • Defined as (gof)(x) = g(f(x)) for all x ∈ A.
  • The range of f must be a subset of the domain of g.

🎙️ Function composition is like a relay race where the output of one function becomes the input for another. The order matters! (gof)(x) means applying f first, then g. The condition for composition is crucial: the output set of the first function must align with the input set of the second.

Worked Example 3: Composition of Functions

  • Let f: R → R be f(x) = 2x + 3.
  • Let g: R → R be g(x) = x² + 1.
  • Find (gof)(x) and (fog)(x).
  • Note: R is the set of real numbers.

🎙️ Here, we substitute the entire expression of the inner function into the outer function. Notice that (gof)(x) is generally not equal to (fog)(x), which highlights that function composition is not commutative. Pay attention to the order of operations.

1(gof)(x) = g(f(x)) = g(2x+3) = (2x+3)² + 1.
2(fog)(x) = f(g(x)) = f(x²+1) = 2(x²+1) + 3.

Inverse of a Function

  • A function f: A → B has an inverse function, denoted f⁻¹: B → A, if and only if f is bijective.
  • If f(x) = y, then f⁻¹(y) = x.
  • The inverse 'undoes' the original function.
  • Domain of f becomes range of f⁻¹, and vice-versa.

🎙️ An inverse function exists only when the original function is bijective – meaning it's both one-to-one and onto. This ensures that for every output 'y', there's exactly one unique input 'x' that produced it, allowing us to reverse the mapping unambiguously. If a function is not bijective, its inverse does not exist.

Worked Example 4: Finding Inverse Function

  • Find the inverse of the function f: R → R given by f(x) = 3x - 5.
  • Step 1: Verify if f is bijective (It is).
  • Step 2: Let y = f(x) and swap x and y.
  • Step 3: Solve for y in terms of x.

🎙️ To find the inverse, we first confirm bijectivity (f(x)=3x-5 is indeed bijective). Then, we replace f(x) with y, swap x and y to represent the inverse operation, and finally solve for y to express the inverse function in terms of x. This systematic approach ensures accuracy.

1y = 3x - 5
2Swap x and y: x = 3y - 5
3Solve for y: 3y = x + 5 => y = (x + 5)/3
4So, f⁻¹(x) = (x + 5)/3
