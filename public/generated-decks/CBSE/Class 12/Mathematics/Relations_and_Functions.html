Building Blocks: Sets and Cartesian Product (Recall)

  • A Set is a well-defined collection of distinct objects.
  • An Ordered Pair (a, b) has 'a' as the first element and 'b' as the second.
  • Cartesian Product A × B: The set of all possible ordered pairs (a, b) where a ∈ A and b ∈ B.

🎙️ Remember from Class 11, sets are fundamental. The Cartesian Product is how we create pairs from elements of two sets. For example, if A={1,2} and B={a,b}, then A x B = {(1,a), (1,b), (2,a), (2,b)}.

Defining a Relation: From A to B

  • A relation R from a non-empty set A to a non-empty set B is a subset of the Cartesian Product A × B.
  • If (a, b) ∈ R, we say 'a is related to b'.
  • Domain: Set of all first elements; Range: Set of all second elements.

🎙️ Formally, a relation R is simply a collection of ordered pairs (a, b) that satisfy a certain condition. These pairs are always chosen from the Cartesian product of the sets involved. The domain and range help us understand which elements are actively participating in the relation.

1Start with two sets A & B
2Form Cartesian Product A x B
3Select pairs based on a rule (R ⊆ A x B)

The 'No Connection' Relation: Empty Relation

  • Analogy: In a class of 12th graders, is anyone 'older than 100 years'?
  • No one satisfies this condition, so the relation is empty.
  • Definition: R = ∅ (the empty set), a subset of A × A.

🎙️ An empty relation, also known as a void relation, is when no element of a set is related to any element of the same set or another set under a given rule. It's a relation with no pairs in it.

The 'Every Connection' Relation: Universal Relation

  • Analogy: In a class, is anyone 'a student'?
  • Yes, everyone is a student, so everyone is related to everyone under this rule.
  • Definition: R = A × A (the entire Cartesian product).

🎙️ A universal relation means that every element of the set is related to every other element (including itself) under the given condition. It includes all possible ordered pairs from the Cartesian product.

'Looking in the Mirror': Reflexive Relation

  • Analogy: 'Is equal to' (a = a). Every number is equal to itself.
  • Definition: For every element 'a' in set A, (a, a) must belong to the relation R.
  • Every element is related to itself.

🎙️ A reflexive relation is like looking in a mirror; every element sees itself. For any element 'a' in the set, the pair (a, a) must be present in the relation R. If even one element doesn't have a self-loop, it's not reflexive.

'Two-Way Street': Symmetric Relation

  • Analogy: 'Is a sibling of'. If Ram is a sibling of Sita, then Sita is a sibling of Ram.
  • Definition: If (a, b) ∈ R, then (b, a) must also belong to R, for all a, b ∈ A.
  • The relationship works both ways.

🎙️ A symmetric relation implies reciprocity. If element 'a' is related to 'b', then 'b' must also be related to 'a' under the same rule. Think of it as a two-way connection or a mutual relationship.

'Chain Reaction': Transitive Relation

  • Analogy: 'Is taller than'. If A is taller than B, and B is taller than C, then A is taller than C.
  • Definition: If (a, b) ∈ R and (b, c) ∈ R, then (a, c) ∈ R, for all a, b, c ∈ A.
  • The relation can be extended through an intermediate element.

🎙️ A transitive relation is like a chain. If there's a link from 'a' to 'b' and from 'b' to 'c', then there must be a direct link from 'a' to 'c'. This property is crucial for many mathematical structures.

The 'Equally Connected' Relation: Equivalence Relation

  • A relation R on a set A is an Equivalence Relation if it is:
  • 1. Reflexive: (a, a) ∈ R for all a ∈ A.
  • 2. Symmetric: If (a, b) ∈ R, then (b, a) ∈ R.
  • 3. Transitive: If (a, b) ∈ R and (b, c) ∈ R, then (a, c) ∈ R.

🎙️ An equivalence relation is a special type of relation that satisfies all three properties: reflexive, symmetric, and transitive. These relations are fundamental because they partition a set into disjoint subsets called equivalence classes.

Worked Example: Proving Equivalence

  • Let L be the set of all lines in a plane. R is a relation on L defined by R = {(L1, L2) : L1 || L2}.
  • Prove R is an equivalence relation.
  • Step 1: Reflexive (L1 || L1? Yes, every line is parallel to itself).
  • Step 2: Symmetric (If L1 || L2, then L2 || L1? Yes).

🎙️ Let's walk through this example. For reflexivity, a line is indeed parallel to itself. For symmetry, if line L1 is parallel to L2, it logically follows that L2 is parallel to L1. These are straightforward.

16 / 32

Worked Example: Proving Equivalence (Continued)

  • Step 3: Transitive (If L1 || L2 and L2 || L3, then L1 || L3? Yes).
  • Since R is reflexive, symmetric, and transitive, it is an equivalence relation.
  • Equivalence classes are sets of parallel lines.

🎙️ Finally, for transitivity, if L1 is parallel to L2 and L2 is parallel to L3, then L1 must be parallel to L3. Since all three properties hold, the relation 'is parallel to' is an equivalence relation on the set of lines. This relation groups all parallel lines together.

The 'Input-Output Machine': What is a Function?

  • Analogy: A vending machine. You put in money (input), and you get one specific item (output).
  • A function is a special type of relation.
  • Every input has exactly one output.

🎙️ Think of a function as a well-behaved machine. For every valid input you give it, it produces one and only one output. You can't put in ₹10 and get both a chocolate and a packet of chips; it's one output per input.

Defining a Function: A Special Relation

  • A relation f from set A to set B is a function if:
  • 1. Every element of A has an image in B (no element in A is left unmapped).
  • 2. Each element of A has a unique image in B (no element in A maps to more than one element in B).
  • Notation: f: A → B.

🎙️ These two conditions are critical. If any element in the domain A doesn't have an image, or if an element has multiple images, it's not a function. Functions ensure a predictable and consistent mapping.

1All elements in A mapped
2Each element in A mapped uniquely

'Unique Pairing': One-to-One (Injective) Function

  • Analogy: Assigning unique roll numbers to students. No two students get the same roll number.
  • Definition: Different elements of A have different images in B.
  • If f(x1) = f(x2), then x1 = x2.

🎙️ An injective function ensures that each distinct input maps to a distinct output. There are no shared outputs among different inputs. Think of it as a direct, non-overlapping mapping.

'Covering All Bases': Onto (Surjective) Function

  • Analogy: Every seat in a concert hall is filled by an audience member.
  • Definition: Every element in the codomain B is the image of at least one element in the domain A.
  • The range of the function is equal to its codomain (Range = B).

🎙️ A surjective function means that the function 'covers' the entire codomain. There are no elements left out in the codomain that aren't mapped to by some element in the domain. Every possible output is achieved.

'Perfect Match': Bijective Function

  • A function f: A → B is a Bijective Function if it is both:
  • 1. Injective (One-to-One)
  • 2. Surjective (Onto)
  • This means there's a perfect one-to-one correspondence between elements of A and B.

🎙️ A bijective function is the 'gold standard' for mappings. It's a perfect pairing where every input has a unique output, and every possible output is reached. Bijective functions are the only ones that have an inverse function.

Worked Example: Checking Injectivity and Surjectivity

  • Consider f: N → N given by f(x) = 2x.
  • Is it Injective?
  • Assume f(x1) = f(x2) => 2x1 = 2x2 => x1 = x2. Yes, it's injective.
  • Is it Surjective?

🎙️ Let's test this function. For injectivity, if two outputs are the same, their inputs must also be the same. Here, if 2x1 equals 2x2, then x1 must equal x2, so it is indeed one-to-one.

25 / 32

Worked Example: Checking Injectivity and Surjectivity (Continued)

  • Is f(x) = 2x Surjective on N (Natural Numbers)?
  • Let y be an element in the codomain N. We need to find x in domain N such that f(x) = y.
  • So, 2x = y => x = y/2.
  • If y = 3 (an odd number in N), then x = 3/2, which is not in N. So, not surjective.

🎙️ For surjectivity, we need every element in the codomain to have a pre-image in the domain. Here, if we pick an odd number like 3 from the codomain (Natural Numbers), its pre-image would be 3/2, which is not a natural number. Therefore, not all elements in the codomain are mapped to, so it's not surjective.

'Functions within Functions': Composition of Functions

  • Analogy: An assembly line. Product A goes through Machine 1, then its output goes into Machine 2.
  • Combining two functions to form a new function.
  • If f: A → B and g: B → C, then (g o f): A → C is defined as (g o f)(x) = g(f(x)).

🎙️ Composition is essentially applying one function after another. The output of the first function becomes the input for the second. The order matters significantly in composition, so g o f is generally not the same as f o g.

1Input x into f
2Output f(x) becomes input for g
3Final Output g(f(x))

'Reversing the Process': Inverse of a Function

  • Analogy: An 'undo' button. If a function encrypts a message, its inverse decrypts it.
  • Only bijective functions (one-to-one and onto) have inverses.
  • If f: A → B is bijective, then f⁻¹: B → A exists such that f(x) = y ⇔ f⁻¹(y) = x.

🎙️ An inverse function essentially reverses the mapping of the original function. If f takes x to y, then f inverse takes y back to x. This 'undo' operation is only possible if the function is both injective and surjective, ensuring a unique path back.

Avoiding Pitfalls: Common Mistakes

  • Not checking all three conditions for Equivalence Relations.
  • Confusing one-to-one with onto, especially in examples with R → R.
  • Incorrectly determining domain/codomain for function composition.
  • Assuming an inverse exists without proving bijectivity.

🎙️ Students often rush through proofs or misinterpret definitions. Always list out the conditions for each type of relation or function and systematically verify them. Pay close attention to the specified domain and codomain, as they can drastically change the type of function.
