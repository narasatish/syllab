Understanding Continuity Intuitively

  • A function is continuous if its graph can be drawn without lifting the pen.
  • No breaks, jumps, or holes in the graph.
  • Smooth flow along the curve.

🎙️ Imagine drawing a graph. If you can draw the entire graph of a function without ever lifting your pen from the paper, then the function is continuous. It means there are no sudden breaks, gaps, or sharp jumps in its path.

Defining Continuity at a Point (c)

  • A function f(x) is continuous at x = c if:
  • 1. f(c) is defined (the point exists).
  • 2. lim f(x) as x→c exists (the limit exists).
  • 3. lim f(x) as x→c = f(c) (limit equals function value).

🎙️ Now for the formal definition. For a function to be continuous at a specific point 'c', three conditions must be met. First, the function must actually have a value at 'c'. Second, the limit of the function as x approaches 'c' must exist. And finally, the limit's value must be exactly equal to the function's value at 'c'.

Three Conditions for Continuity

  • Specifically, for lim f(x) as x→c to exist:
  • Left-Hand Limit (LHL) = Right-Hand Limit (RHL).
  • So, LHL = RHL = f(c) for continuity at x = c.

🎙️ Expanding on the second condition, for the limit to exist, the function must approach the same value from both the left and the right sides. Therefore, the complete condition for continuity at a point 'c' is that the Left-Hand Limit, the Right-Hand Limit, and the function's value at 'c' must all be equal.

Worked Example 1: Checking Continuity

  • Check the continuity of the function f(x) = 2x + 3 at x = 1.
  • This is a polynomial function.
  • We need to evaluate LHL, RHL, and f(1).

🎙️ Let's work through an example. We'll check the continuity of a simple polynomial function, f(x) = 2x + 3, at the point x = 1. Remember, we need to find the Left-Hand Limit, Right-Hand Limit, and the function's value at x=1.

Solution to Example 1

  • 1. f(1) = 2(1) + 3 = 5.
  • 2. LHL = lim (x→1⁻) (2x + 3) = 2(1) + 3 = 5.
  • 3. RHL = lim (x→1⁺) (2x + 3) = 2(1) + 3 = 5.
  • Since LHL = RHL = f(1) = 5, f(x) is continuous at x = 1.

🎙️ Here's the solution. We found f(1) to be 5. Both the Left-Hand Limit and the Right-Hand Limit as x approaches 1 also evaluate to 5. Since all three values are equal, we can confidently say that the function f(x) = 2x + 3 is continuous at x = 1.

Continuity of Common Functions

  • Polynomial functions are continuous everywhere.
  • Modulus function |x| is continuous everywhere.
  • Exponential functions (e^x, a^x) are continuous everywhere.
  • Logarithmic functions (log x) are continuous in their domain.

🎙️ It's helpful to know that many common functions are inherently continuous. Polynomials, modulus functions, and exponential functions are continuous over their entire domain. Logarithmic functions are continuous within their defined domain, which is typically for positive values of x.

Understanding Discontinuity

  • A function is discontinuous at a point if it's not continuous there.
  • This means at least one of the three continuity conditions fails.
  • Common types: Removable, Jump, Infinite discontinuity.

🎙️ If a function fails any of the three conditions for continuity at a point, then it is said to be discontinuous at that point. We categorize discontinuities into removable, jump, and infinite types, each representing a different kind of 'break' in the graph.

Algebra of Continuous Functions

  • If f and g are continuous functions, then:
  • f + g, f - g, f * g are also continuous.
  • f / g is continuous, provided g(x) ≠ 0.
  • Composition (f o g)(x) is continuous if f is continuous at g(x).

🎙️ A very useful property is that continuity is preserved under basic arithmetic operations. If you combine two continuous functions through addition, subtraction, multiplication, or division (where the denominator is not zero), the resulting function will also be continuous. The same applies to function composition.

Introducing Differentiability: A Smooth Ride

  • Intuitively, differentiability means the function's graph is 'smooth'.
  • No sharp corners, cusps, or vertical tangents.
  • A unique tangent line can be drawn at every point.

🎙️ Now, let's move to differentiability. Think of a roller coaster track. For a smooth ride, the track must not have any sudden sharp turns or breaks. Similarly, a differentiable function has a graph that is smooth, without any sharp corners or cusps where you can't draw a unique tangent.

Defining Differentiability at a Point

  • A function f(x) is differentiable at x = c if its derivative f'(c) exists.
  • f'(c) = lim (h→0) [f(c + h) - f(c)] / h.
  • This limit must exist and be finite.

🎙️ Formally, a function is differentiable at a point 'c' if the limit defining its derivative exists at that point. This limit represents the slope of the tangent line to the curve at 'c'. For the derivative to exist, the function must approach the same slope from both sides of 'c'.

Conditions for Differentiability

  • For the derivative f'(c) to exist, the Left-Hand Derivative (LHD) must equal the Right-Hand Derivative (RHD).
  • LHD = lim (h→0⁻) [f(c + h) - f(c)] / h.
  • RHD = lim (h→0⁺) [f(c + h) - f(c)] / h.
  • If LHD = RHD, then f(x) is differentiable at x = c.

🎙️ Just like with limits for continuity, for differentiability, we need to ensure the slope is consistent from both sides. The Left-Hand Derivative must be equal to the Right-Hand Derivative. If these two values are equal, then the function is differentiable at that point.

Differentiability Implies Continuity

  • If a function is differentiable at a point, it must be continuous at that point.
  • A smooth curve cannot have breaks or jumps.
  • Converse is NOT true: A continuous function may not be differentiable.

🎙️ This is a fundamental relationship: differentiability is a stronger condition than continuity. If a function is differentiable at a point, it automatically means it is continuous there. However, the reverse is not true; a continuous function can still have sharp corners where it's not differentiable, like the absolute value function at x=0.

Worked Example 2: Differentiability of |x|

  • Check the differentiability of f(x) = |x| at x = 0.
  • Recall: |x| = x for x ≥ 0 and -x for x < 0.
  • We need to compare LHD and RHD at x = 0.

🎙️ Let's examine a classic example: the function f(x) = |x| at x = 0. This function is continuous at x=0, but is it differentiable? We'll use the LHD and RHD definitions to find out, remembering how the absolute value function is defined.

17 / 25

Solution to Example 2

  • 1. LHD = lim (h→0⁻) [f(0 + h) - f(0)] / h = lim (h→0⁻) [|-h| - |0|] / h = lim (h→0⁻) [-h] / h = -1.
  • 2. RHD = lim (h→0⁺) [f(0 + h) - f(0)] / h = lim (h→0⁺) [|h| - |0|] / h = lim (h→0⁺) [h] / h = 1.
  • Since LHD ≠ RHD (-1 ≠ 1), f(x) = |x| is not differentiable at x = 0.

🎙️ For f(x) = |x| at x = 0, the Left-Hand Derivative is -1, and the Right-Hand Derivative is 1. Since these two values are not equal, the function |x| is not differentiable at x = 0. This illustrates that a continuous function can indeed fail to be differentiable at certain points, specifically at sharp corners.

Avoiding Common Mistakes

  • Confusing continuity with differentiability (remember the |x| example).
  • Incorrectly evaluating limits for LHL/RHL or LHD/RHD.
  • Assuming differentiability from a simple graph without formal checks.
  • Not checking the domain of functions before evaluating continuity/differentiability.

🎙️ Students often make mistakes by assuming that continuity automatically implies differentiability, or by incorrectly calculating limits. Always formally check LHL/RHL and LHD/RHD. Also, remember to consider the function's domain, especially for functions like logarithms or square roots.

Algebra of Differentiable Functions

  • If f and g are differentiable functions, then:
  • f + g, f - g, f * g are also differentiable.
  • f / g is differentiable, provided g(x) ≠ 0.
  • Chain rule for composition: (f o g)'(x) = f'(g(x)) * g'(x).

🎙️ Similar to continuous functions, differentiable functions also behave well under basic arithmetic operations. Their sum, difference, product, and quotient (where the denominator is non-zero) are also differentiable. For composite functions, we use the very important Chain Rule, which you will study in more detail soon.
