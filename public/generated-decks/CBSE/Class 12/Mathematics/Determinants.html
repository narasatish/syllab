What is a Determinant?

  • A scalar value associated with a square matrix.
  • Represented by |A| or det(A).
  • It's a unique number, not another matrix.

🎙️ Simply put, a determinant is a special number calculated from the elements of a square matrix. Think of it as a fingerprint for a matrix – unique and characteristic. It's always a scalar, a single number.

Determinants vs. Matrices: Key Differences

  • Matrices are arrangements of numbers.
  • Determinants are scalar values.
  • Only square matrices have determinants.

🎙️ It's vital not to confuse matrices with determinants. A matrix is a rectangular array, while a determinant is a single numerical value derived from a square matrix. Not all matrices have determinants.

Determinant of a Matrix of Order 1

  • For A = [a], det(A) = a.
  • The simplest case.
  • The value is just the element itself.

🎙️ Let's start with the basics. If you have a 1x1 matrix, say A with element 'a', its determinant is simply 'a'. This is straightforward and forms the base for understanding higher orders.

Determinant of a Matrix of Order 2

  • For A = [[a, b], [c, d]], det(A) = ad - bc.
  • Diagonal product difference.
  • Always remember the 'ad minus bc' formula.

🎙️ This is where it gets interesting. For a 2x2 matrix, the determinant is calculated by multiplying the elements of the main diagonal and subtracting the product of the elements of the off-diagonal. This formula is critical.

1Multiply diagonals (ad)
2Multiply off-diagonals (bc)
3Subtract (ad - bc)

Worked Example: Order 2 Determinant

  • Calculate det(A) for A = [[3, 2], [1, 5]].
  • Solution: (3 * 5) - (2 * 1)
  • = 15 - 2 = 13.

🎙️ Let's try an example. Given the matrix A, we apply the formula: (3 times 5) minus (2 times 1). This gives us 15 minus 2, which results in 13. Simple, right?

Determinant of a Matrix of Order 3

  • Expanded along a row or column.
  • Involves minors and cofactors.
  • More complex, but systematic.

🎙️ Calculating the determinant of a 3x3 matrix requires a systematic approach, involving what we call minors and cofactors. You can expand along any row or column, and the result will be the same. Let's learn how.

Minors and Cofactors

  • Minor (M_ij): Determinant of submatrix after removing row 'i' and column 'j'.
  • Cofactor (A_ij): (-1)^(i+j) * M_ij.
  • The sign depends on the position (i+j).

🎙️ Minors are determinants of smaller matrices. For a 3x3 matrix, a minor will be a 2x2 determinant. Cofactors are minors with an attached sign, determined by the position of the element. Pay close attention to the (-1)^(i+j) part.

Worked Example: Minors and Cofactors

  • For A = [[1,2,3],[4,5,6],[7,8,9]], find M_11 and A_11.
  • M_11 = det([[5,6],[8,9]]) = (5*9)-(6*8) = 45-48 = -3.
  • A_11 = (-1)^(1+1) * M_11 = 1 * (-3) = -3.

🎙️ Let's find the minor and cofactor for element at (1,1). We remove the first row and first column, calculate the 2x2 determinant. Then, apply the sign rule. Here, it's positive, so A_11 is -3.

Expansion using Cofactors (Order 3)

  • det(A) = a_11 A_11 + a_12 A_12 + a_13 A_13 (along R1).
  • Can be expanded along any row or column.
  • Sum of products of elements with their cofactors.

🎙️ To find the determinant of a 3x3 matrix, you pick a row or column, multiply each element by its corresponding cofactor, and then sum these products. This method guarantees the correct determinant value.

1Choose a row/column
2Find cofactors for its elements
3Multiply elements by cofactors
4Sum the products

Worked Example: Order 3 Determinant

  • Calculate det(A) for A = [[1, 2, 3], [0, 1, 0], [4, 5, 6]].
  • Expand along R2 (due to '0's):
  • det(A) = 0*A_21 + 1*A_22 + 0*A_23 = 1*A_22.

🎙️ Let's calculate A_22. M_22 = det([[1,3],[4,6]]) = (1*6)-(3*4) = 6-12 = -6. A_22 = (-1)^(2+2)*M_22 = 1*(-6) = -6. So, det(A) = -6. Choosing a row/column with zeros simplifies calculations significantly!

Common Mistake: Sign Errors in Cofactors

  • For A_ij, the sign is (-1)^(i+j).
  • Alternating signs: + - + / - + - / + - +.
  • Double-check signs, especially during expansion.

🎙️ A very common mistake students make is with the signs of cofactors. Remember the alternating pattern. A simple error here can lead to a completely wrong determinant. Always be vigilant with the signs!

Property 1: Row/Column Interchange

  • If any two rows or columns are interchanged, the sign of the determinant changes.
  • Magnitude remains the same.
  • det(B) = -det(A) if B is from A by R_i ↔ R_j.

🎙️ This is a fundamental property. Swapping any two parallel lines (rows or columns) in a matrix will flip the sign of its determinant, but the absolute value stays the same. Understand this well for problem-solving.

Property 2: Identical Rows/Columns or Zero Row/Column

  • If any two rows or columns are identical, det(A) = 0.
  • If a row or column consists of all zeros, det(A) = 0.
  • These are quick ways to identify a zero determinant.

🎙️ These properties are powerful shortcuts. If you spot two identical rows or columns, or an entire row/column of zeros, you immediately know the determinant is zero without any calculation. This saves valuable exam time.

Property 3: Scalar Multiplication

  • If each element of a row/column is multiplied by 'k', det(A) is multiplied by 'k'.
  • det(kA) = k^n * det(A) for an n x n matrix.
  • Important for factoring out common terms.

🎙️ When you multiply a matrix by a scalar 'k', each element is multiplied. However, for a determinant, if only one row or column is multiplied by 'k', the determinant itself is multiplied by 'k'. If the whole matrix A is multiplied by k, the determinant becomes k to the power n times det(A).

Property 4: Sum of Elements (Distribution)

  • If elements of a row/column are sum of two terms, determinant can be expressed as sum of two determinants.
  • Example: det([[a+x, b],[c+y, d]]) = det([[a,b],[c,d]]) + det([[x,b],[y,d]]).
  • Useful for splitting complex determinants.

🎙️ This property allows us to break down complex determinants into simpler ones. If an element in a row or column is a sum of two terms, you can express the original determinant as the sum of two determinants, each containing one of those terms.

Property 5: Row/Column Operations (R_i → R_i + kR_j)

  • If to elements of any row/column, corresponding elements of another row/column are added (multiplied by a constant 'k'), det(A) remains unchanged.
  • det(A) = det(B) where B is obtained by R_i → R_i + kR_j.
  • Most powerful property for simplification.

🎙️ This is arguably the most important property for solving problems efficiently. Performing elementary row or column operations of the type R_i -> R_i + kR_j does not change the value of the determinant. Use this to create zeros and simplify calculations.

Application: Area of a Triangle

  • Area of triangle with vertices (x1, y1), (x2, y2), (x3, y3).
  • Area = 1/2 | det([[x1, y1, 1], [x2, y2, 1], [x3, y3, 1]]) |.
  • The determinant value can be negative, so take absolute value.

🎙️ Determinants have practical applications in geometry. You can find the area of a triangle given its vertices using this determinant formula. Remember, area is always positive, so we take the absolute value of the determinant.

Worked Example: Area of Triangle

  • Find area of triangle with vertices (1,0), (6,0), (4,3).
  • det = [[1,0,1],[6,0,1],[4,3,1]] = 1(0-3) - 0(6-4) + 1(18-0).
  • det = -3 + 18 = 15. Area = 1/2 * |15| = 7.5 sq. units.

🎙️ Let's apply the formula. We set up the determinant and expand it. Notice expanding along the second column would be fastest due to the zeros. The calculated determinant is 15, so the area is 7.5 square units.

Application: Collinearity of Three Points

  • Three points (x1, y1), (x2, y2), (x3, y3) are collinear if area of triangle is 0.
  • Condition: det([[x1, y1, 1], [x2, y2, 1], [x3, y3, 1]]) = 0.
  • A quick test for points lying on a straight line.

🎙️ This is a direct consequence of the area formula. If three points lie on a straight line, they cannot form a triangle, meaning the area enclosed by them is zero. Thus, the determinant value must be zero for collinear points.
