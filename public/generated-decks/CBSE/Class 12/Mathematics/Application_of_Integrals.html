Area Under Simple Curves: The Basic Idea

  • We use definite integrals to find the area of bounded regions.
  • The region must be bounded by a curve, the x-axis (or y-axis), and two ordinates (or abscissae).
  • Imagine summing up infinitely many thin rectangles.
  • This is the foundation of all area calculations.

🎙️ The most fundamental application is finding the area bounded by a curve and one of the axes. We're essentially visualizing the area as being made up of countless tiny rectangles, each with an infinitesimal width, and then summing their areas using integration.

Method 1: Area Bounded by y = f(x)

  • Region bounded by y = f(x), x-axis, x = a, and x = b.
  • Formula: Area = ∫[a to b] y dx = ∫[a to b] f(x) dx.
  • Ensure f(x) is continuous and non-negative over [a, b].
  • If f(x) is negative, the integral gives a negative value; take absolute value for area.

🎙️ When the curve is given as y in terms of x, and we need the area with the x-axis, we integrate with respect to x. Remember to always check the sign of f(x) in the given interval; if it goes below the x-axis, you'll need to split the integral or take the absolute value for the physical area.

1Identify curve y=f(x)
2Identify limits x=a, x=b
3Integrate ∫ f(x) dx
4Evaluate at limits
5 / 25

Method 2: Area Bounded by x = g(y)

  • Region bounded by x = g(y), y-axis, y = c, and y = d.
  • Formula: Area = ∫[c to d] x dy = ∫[c to d] g(y) dy.
  • Ensure g(y) is continuous and non-negative over [c, d].
  • This is useful for curves that are easier to express in terms of y.

🎙️ Similarly, if the curve is defined as x in terms of y, and we need the area with the y-axis, we integrate with respect to y. This approach is particularly helpful for curves like parabolas opening to the side or other relations where x is a function of y.

1Identify curve x=g(y)
2Identify limits y=c, y=d
3Integrate ∫ g(y) dy
4Evaluate at limits

Worked Example: Area of a Circle using Integrals

  • Find the area of the circle x² + y² = a².
  • Due to symmetry, we find the area of one quadrant and multiply by 4.
  • In the first quadrant, y = √(a² - x²).
  • Limits for x are from 0 to a.

🎙️ Let's apply our knowledge to a familiar shape: the circle. We can calculate the area of the entire circle by finding the area of just one quadrant and then multiplying it by four, thanks to its symmetry. Remember, for the first quadrant, y is positive.

Area Between Two Curves: Subtracting Regions

  • Often, we need the area enclosed by two or more curves.
  • The basic principle is to subtract the area of the 'lower' curve from the 'upper' curve.
  • This applies whether integrating with respect to x or y.
  • Visualizing the region is crucial.

🎙️ Moving beyond simple areas, we now tackle finding the area enclosed between two functions. The core idea is to find the area under the upper curve and then subtract the area under the lower curve within the specified boundaries. A good diagram makes all the difference here.

Method 3: Area Between y=f(x) and y=g(x)

  • Region bounded by y = f(x) and y = g(x) from x = a to x = b.
  • Assume f(x) ≥ g(x) in the interval [a, b].
  • Formula: Area = ∫[a to b] (f(x) - g(x)) dx.
  • If curves intersect, split the integral at intersection points.

🎙️ When integrating with respect to x, identify which function is 'above' the other. If the curves cross, you'll need to find the intersection points and set up separate integrals for each sub-region, ensuring you always subtract the lower curve from the upper one.

1Identify upper curve f(x)
2Identify lower curve g(x)
3Find intersection points (limits)
4Integrate ∫ (f(x)-g(x)) dx
10 / 25

Method 4: Area Between x=f(y) and x=g(y)

  • Region bounded by x = f(y) and x = g(y) from y = c to y = d.
  • Assume f(y) ≥ g(y) in the interval [c, d] (f(y) is to the right).
  • Formula: Area = ∫[c to d] (f(y) - g(y)) dy.
  • This is useful when curves are easier to express in terms of y.

🎙️ Similarly, for integration with respect to y, you need to identify which curve is to the 'right' and which is to the 'left'. The principle remains the same: Area = Integral of (Right Curve - Left Curve). This is often simpler for horizontally-oriented regions.

1Identify right curve f(y)
2Identify left curve g(y)
3Find intersection points (limits)
4Integrate ∫ (f(y)-g(y)) dy

Common Mistake: Forgetting Absolute Value

  • If f(x) goes below the x-axis, ∫ f(x) dx will yield a negative value.
  • Area is always a positive quantity.
  • If f(x) changes sign, split the integral and take absolute value of each part.
  • Example: ∫[-1 to 1] x dx = 0, but area is 1 unit².

🎙️ This is a critical point! While a definite integral can be negative or zero, area cannot. If a part of the curve lies below the x-axis, the integral for that part will be negative. You must take the absolute value of each segment's integral to get the true area.

Worked Example: Parabola and Vertical Line

  • Find the area bounded by y² = 4x and the line x = 3.
  • The parabola y² = 4x is symmetric about the x-axis.
  • We can find the area in the first quadrant and multiply by 2.
  • In the first quadrant, y = 2√x. Limits for x are from 0 to 3.

🎙️ This example shows the power of symmetry. Instead of integrating with respect to y, which would involve two functions x=y²/4 and x=3, we can integrate y=2√x with respect to x from 0 to 3 and double the result for the total area. Always look for symmetry!

Real-Life: Work Done in Physics

  • Integrals calculate work done by a variable force.
  • Work = ∫ F(x) dx, where F(x) is the force.
  • Also used in calculating fluid pressure, moments of inertia.
  • Essential for designing structures and machines.

🎙️ Beyond geometry, integrals are fundamental in physics and engineering. For instance, if a force isn't constant but varies with position, integration is the only way to calculate the total work done. This is vital in fields like mechanics and civil engineering.

Advanced Concept: Area with Modulus Functions

  • Functions involving |x| or |f(x)| require careful handling.
  • Break the function into piecewise definitions.
  • Identify intervals where the expression inside modulus is positive or negative.
  • Integrate separately over each interval.

🎙️ Modulus functions are tricky because their definition changes based on the sign of the argument. You must redefine the function as a piecewise function, find the points where the argument changes sign, and then integrate over those separate intervals.

Worked Example: Area with |x|

  • Find the area bounded by y = |x|, x-axis, x = -2, x = 2.
  • y = |x| is defined as -x for x < 0 and x for x ≥ 0.
  • Split the integral: ∫[-2 to 0] (-x) dx + ∫[0 to 2] x dx.
  • Calculate each part and sum them up.

🎙️ Let's apply the modulus concept to a specific example. The graph of y=|x| forms a 'V' shape. We need to split the integral at x=0, which is where the definition of |x| changes. This ensures we correctly account for the function's behavior in both negative and positive domains.

Advanced Concept: Area with Multiple Curves

  • Sometimes a region is bounded by more than two curves.
  • The strategy is to divide the region into smaller sub-regions.
  • Each sub-region can be calculated using Method 3 or 4.
  • Sum the areas of all sub-regions for the total area.

🎙️ When a region is complex, bounded by three or more curves, the trick is to break it down. Visualize how you can divide the total area into simpler, non-overlapping sub-regions, each of which can be calculated using the methods we've already learned. Then, simply add them up.

Exam Tips: Acing Application of Integrals

  • **Draw a neat diagram:** Always sketch the region clearly.
  • **Identify limits:** Correctly find intersection points or given boundaries.
  • **Choose dx or dy:** Select the easier variable of integration.
  • **Absolute values:** Handle areas below axis or modulus functions carefully.

🎙️ To excel in this chapter, remember these tips. A clear diagram is your best friend. Accurately determining limits and choosing the right integration variable can save a lot of effort and prevent errors. And never forget that area is always positive!
