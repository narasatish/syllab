What is Linear Programming (LPP)?

  • Mathematical technique for optimization
  • Maximize or minimize a linear function
  • Subject to linear constraints

🎙️ Linear Programming is a mathematical technique used to optimize (maximize or minimize) a linear objective function, subject to linear equality and inequality constraints. Think of it as finding the 'best' possible outcome given a set of limitations or rules.

🎯
Finding the Best

The Pillars of LPP

  • Objective Function: What to optimize?
  • Constraints: The limitations
  • Non-negativity: Realistic values

🎙️ Every LPP stands on three main pillars: the Objective Function, which tells us what we want to optimize; the Constraints, which are the limitations; and Non-negativity Restrictions, ensuring our variables make sense in the real world.

Component 1: The Goal - Objective Function

  • Expression to maximize or minimize
  • Always a linear function
  • E.g., Profit, Cost, Sales, Time

🎙️ This is the mathematical expression that represents the quantity we want to maximize (like profit or sales) or minimize (like cost or time). It's always a linear function of the decision variables. For Mrs. Sharma, it would be her total profit from Laddoos and Barfis.

Component 2: The Boundaries - Constraints

  • Limitations on resources or conditions
  • Expressed as linear inequalities/equalities
  • E.g., limited raw materials, machine hours

🎙️ Constraints are the limitations or restrictions on the resources or conditions. These are expressed as linear inequalities or equalities. For Mrs. Sharma, these are her limited flour, sugar, and time available for making mithai.

Component 3: Realistic Choices - Non-negativity Restrictions

  • Decision variables cannot be negative
  • Always x ≥ 0, y ≥ 0
  • Ensures practical solutions

🎙️ Decision variables (like the number of Laddoos or Barfis) cannot be negative in real-world scenarios. You can't make -5 Laddoos! So, all decision variables must be greater than or equal to zero. This is a crucial, often implicit, constraint.

Solving LPP Graphically: The Feasible Region

  • Used for problems with two variables
  • Intersection of all constraints
  • Contains all possible valid solutions

🎙️ For problems with two variables, we can solve LPPs graphically. Each constraint defines a half-plane. The intersection of all these half-planes, including non-negativity, forms a region called the Feasible Region. This region contains all possible solutions that satisfy the constraints.

The Corner Point Theorem: Finding the Optimum

  • Crucial for graphical solutions
  • Optimal solution lies at a vertex
  • Check objective function at each corner

🎙️ A fundamental theorem states that if an optimal solution exists for a linear programming problem, it must occur at a corner point (vertex) of the feasible region. This significantly narrows down our search for the best solution!

📍

Graphical Solution: Step-by-Step

  • Graph all constraints
  • Identify and shade the feasible region
  • Find coordinates of all corner points
  • Evaluate objective function at each point

🎙️ First, plot all inequalities as lines and shade the feasible region. Then, identify the coordinates of all corner points of this region. Finally, substitute these coordinates into the objective function to find the maximum or minimum value. The point giving the optimal value is our solution.

Example 2 Solution: Finding the Maximum

  • Evaluate Z = x + y at each corner point
  • (0,0) -> Z = 0
  • (5,0) -> Z = 5
  • (0,5) -> Z = 5
  • (4,3) -> Z = 7

🎙️ Now, substitute these corner points into Z = x + y: At (0,0), Z = 0. At (5,0), Z = 5. At (0,5), Z = 5. At (4,3), Z = 4 + 3 = 7. The maximum value of Z is 7, occurring at (4,3).

Feasible Regions: Bounded or Unbounded?

  • Bounded: Can be enclosed in a circle
  • Unbounded: Extends indefinitely
  • Optimal solution may not exist for unbounded

🎙️ A feasible region is 'bounded' if it can be enclosed within a circle. If it extends indefinitely in any direction, it's 'unbounded'. For unbounded regions, an optimal solution may or may not exist. If it exists, it will still be at a corner point.

Example 3 Solution: Finding the Minimum

  • Evaluate Z = 3x + 2y at each corner point
  • (0,8) -> Z = 16
  • (5,0) -> Z = 15
  • (6.25, 1.75) -> Z = 22.25
  • Smallest value is 15 at (5,0)

🎙️ At (0,8), Z = 16. At (5,0), Z = 15. At (6.25, 1.75), Z = 3(6.25) + 2(1.75) = 18.75 + 3.5 = 22.25. The minimum value appears to be 15 at (5,0). However, for unbounded regions, we must check if Z can be made smaller. Draw the line 3x + 2y < 15. If this region overlaps with the feasible region, no minimum exists. Here, it does not, so 15 is the minimum.

Common Mistakes in LPP

  • Incorrectly shading feasible region
  • Errors in finding intersection points
  • Forgetting non-negativity constraints
  • Not checking for unbounded solutions

🎙️ Students often make errors in: 1. Incorrectly shading the feasible region. 2. Miscalculating intersection points of lines. 3. Forgetting non-negativity constraints. 4. Not checking for unbounded solutions in minimization problems. Always double-check your graph and calculations!
