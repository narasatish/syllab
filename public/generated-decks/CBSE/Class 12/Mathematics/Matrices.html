Formal Definition: The Rectangular Array

  • A matrix is an ordered rectangular array of numbers or functions.
  • These numbers or functions are called the 'elements' or 'entries' of the matrix.
  • Enclosed in square brackets [ ] or parentheses ( ).

🎙️ Formally, a matrix is a collection of elements arranged in rows and columns. The key is 'ordered' – the position of each element matters. We typically use capital letters like A, B, C to denote matrices.

Order of a Matrix: Rows by Columns (m x n)

  • The 'order' of a matrix tells us its size.
  • It's defined as the number of rows (m) by the number of columns (n).
  • Written as 'm x n' (read as 'm by n').

🎙️ Understanding the order is crucial for almost all matrix operations. Remember, 'm' always comes first for rows, and 'n' for columns. A 3x2 matrix has 3 rows and 2 columns, not the other way around!

Elements of a Matrix: Your Position Matters (a_ij)

  • Each entry in a matrix is called an element.
  • Its position is denoted by 'a_ij', where 'i' is the row number and 'j' is the column number.
  • For example, a_23 refers to the element in the 2nd row and 3rd column.

🎙️ Just like a seat number in a cinema hall, each element has a unique address. This notation, a_ij, is fundamental for defining and working with matrices, especially when constructing them based on rules.

Worked Example 1: Constructing a Matrix

  • Problem: Construct a 2x3 matrix A = [a_ij] where a_ij = (i + j).
  • Step 1: Determine the number of rows (m=2) and columns (n=3).
  • Step 2: Calculate each element using the given formula.

🎙️ Let's put our understanding of order and elements into practice. For a_11, i=1, j=1, so a_11 = 1+1=2. Similarly, a_12 = 1+2=3, a_13 = 1+3=4. Then for the second row: a_21 = 2+1=3, a_22 = 2+2=4, a_23 = 2+3=5. So the matrix A is [[2,3,4],[3,4,5]].

Types of Matrices: Row & Column Matrix

  • Row Matrix: A matrix with only one row. E.g., [1 2 3]
  • Column Matrix: A matrix with only one column. E.g., [[1],[2],[3]]
  • Think of a single shopping list (row) vs. a single person's scores (column).

🎙️ These are special cases of matrices. A row matrix will always have an order of 1 x n, while a column matrix will have an order of m x 1. They are simple but important for specific operations and definitions.

Types of Matrices: Square & Diagonal Matrix

  • Square Matrix: Number of rows equals number of columns (m=n). E.g., a 2x2 or 3x3 matrix.
  • Diagonal Matrix: A square matrix where all non-diagonal elements are zero.
  • Main diagonal elements can be anything.

🎙️ The square matrix is a very important type, as many operations and theorems apply specifically to them. A diagonal matrix is a specialized square matrix, easily recognizable by its zeros everywhere except the main diagonal.

Types of Matrices: Scalar & Identity Matrix

  • Scalar Matrix: A diagonal matrix where all diagonal elements are equal.
  • Identity Matrix: A scalar matrix where all diagonal elements are 1.
  • Acts like the number '1' in multiplication for matrices, denoted by 'I'.

🎙️ Scalar and Identity matrices are subsets of diagonal matrices. The Identity matrix is particularly significant because it behaves similarly to the number '1' in scalar multiplication, maintaining the original matrix after multiplication.

Equality of Matrices: When are they 'Same-Same'?

  • Two matrices A and B are equal if they have the same order.
  • AND their corresponding elements are equal.
  • Think of two identical 'rangoli' designs; every petal must match.

🎙️ For matrices to be equal, it's not enough to just have the same numbers; they must be in the exact same positions, and the overall size must be identical. This concept is often used to solve for unknown variables.

Worked Example 2: Finding Unknowns with Equality

  • Problem: If [[x+y, 2], [5, x-y]] = [[7, 2], [5, 3]], find x and y.
  • Step 1: Check if orders are equal (2x2 = 2x2). Yes.
  • Step 2: Equate corresponding elements.

🎙️ From the equality, we get a system of linear equations: x+y=7 and x-y=3. Adding these equations gives 2x=10, so x=5. Substituting x=5 into x+y=7 gives 5+y=7, so y=2. Simple, right?

Operations on Matrices: Addition (Same Order Only!)

  • To add two matrices, they must have the same order.
  • Add corresponding elements together.
  • Like combining two shopping lists item by item.

🎙️ Matrix addition is very intuitive. If you have two matrices of the same size, you simply add the elements that are in the same position. If their orders are different, addition is not defined.

Worked Example 3: Matrix Addition

  • Problem: If A = [[2, 3], [1, 4]] and B = [[1, 5], [0, 2]], find A + B.
  • Step 1: Check orders. Both are 2x2. Addition is possible.
  • Step 2: Add corresponding elements.

🎙️ Here, A+B will be [[(2+1), (3+5)], [(1+0), (4+2)]]. This results in the matrix [[3, 8], [1, 6]]. Remember to be careful with signs if any elements are negative.

Operations on Matrices: Scalar Multiplication

  • Multiplying a matrix by a scalar (a single number).
  • Multiply EACH element of the matrix by that scalar.
  • Like doubling all prices in a menu.

🎙️ Scalar multiplication is straightforward. Every element inside the matrix gets multiplied by the scalar value. This means the order of the matrix remains unchanged, only its values scale up or down.

Worked Example 4: Scalar Multiplication & Subtraction

  • Problem: If A = [[2, 3], [1, 4]], find 3A.
  • Problem: If B = [[1, 5], [0, 2]], find A - B.
  • Subtraction is defined as A + (-1)B.

🎙️ For 3A, we get [[(3*2), (3*3)], [(3*1), (3*4)]] = [[6, 9], [3, 12]]. For A-B, it's [[(2-1), (3-5)], [(1-0), (4-2)]] = [[1, -2], [1, 2]]. It's essentially element-wise subtraction.

Operations on Matrices: Matrix Multiplication (The Tricky One!)

  • Unlike scalar multiplication, it's NOT element-wise.
  • Row-by-column multiplication: Sum of products of elements from a row of the first matrix and a column of the second.
  • Requires a specific condition for compatibility.

🎙️ Matrix multiplication is where students often make mistakes. It's a bit more complex than addition or scalar multiplication. Visualize taking a row from the first matrix and 'sweeping' it across a column of the second matrix, multiplying and adding as you go.

Condition for Matrix Multiplication: The Inner Match

  • For A (m x n) and B (p x q) to be multiplied (AB), n must equal p.
  • Number of columns of the first matrix MUST equal the number of rows of the second matrix.
  • The resulting matrix (AB) will have an order of m x q.

🎙️ This 'inner match' condition is non-negotiable. If it's not met, multiplication is undefined. Always check the orders first! The outer dimensions (m and q) determine the order of the product matrix.

Worked Example 5: Matrix Multiplication

  • Problem: If A = [[1, 2], [3, 4]] and B = [[5, 6], [7, 8]], find AB.
  • Step 1: Check orders. A is 2x2, B is 2x2. Columns of A (2) = Rows of B (2). Result will be 2x2.
  • Step 2: Calculate each element of the product matrix.

🎙️ For (AB)_11: (1*5) + (2*7) = 5+14 = 19. For (AB)_12: (1*6) + (2*8) = 6+16 = 22. For (AB)_21: (3*5) + (4*7) = 15+28 = 43. For (AB)_22: (3*6) + (4*8) = 18+32 = 50. So AB = [[19, 22], [43, 50]]. Practice makes perfect here!

2Calculate (AB)_11
3Calculate (AB)_12
4Calculate (AB)_21, (AB)_22

Transpose of a Matrix: Flipping Rows & Columns

  • The transpose of a matrix A, denoted as A' or A^T, is obtained by interchanging its rows and columns.
  • If A is an m x n matrix, then A^T is an n x m matrix.
  • Imagine rotating the matrix 90 degrees and then reflecting it.

🎙️ Transposing a matrix is like rotating it. The first row becomes the first column, the second row becomes the second column, and so on. It's a simple operation but very useful in various matrix properties and applications.

Worked Example 6: Finding Transpose

  • Problem: If A = [[1, 2, 3], [4, 5, 6]], find A^T.
  • Step 1: Identify rows and columns.
  • Step 2: Convert rows into columns.

🎙️ Matrix A is 2x3. Its transpose A^T will be 3x2. The first row [1, 2, 3] becomes the first column. The second row [4, 5, 6] becomes the second column. So, A^T = [[1, 4], [2, 5], [3, 6]].

Common Mistakes in Matrices: Beware the Traps!

  • Matrix Multiplication: Forgetting 'columns of 1st = rows of 2nd' condition.
  • Matrix Multiplication: Doing element-wise multiplication instead of row-by-column.
  • Equality: Not checking if orders are identical before equating elements.

🎙️ These are the typical pitfalls students encounter. Always verify the conditions for operations and double-check your calculations, especially with matrix multiplication. A small error in one element can lead to a completely wrong answer.
