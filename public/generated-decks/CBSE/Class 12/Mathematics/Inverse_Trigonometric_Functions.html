Recap: Functions and Their Inverses

  • A function f: A → B assigns each element of A to exactly one element of B.
  • An inverse function f⁻¹ exists if f is both one-one (injective) and onto (surjective).
  • The domain of f becomes the range of f⁻¹, and vice-versa.

🎙️ Before diving into inverse trigonometric functions, let's quickly recall what an inverse function is. Remember, for an inverse to exist, the original function must be bijective – meaning it maps each input to a unique output and covers all possible outputs.

The Challenge: Inverting Trigonometric Functions

  • Trigonometric functions are periodic and many-one.
  • This means they do not have a unique inverse over their entire domain.
  • To define an inverse, we must restrict their domains to make them one-one and onto.

🎙️ Here lies the core challenge: how do we find an inverse for a function that isn't one-to-one? The solution is to cleverly 'cut' the domain of the original trigonometric function so that within that specific interval, it behaves as a one-to-one and onto function. This restricted domain is crucial.

Inverse Sine Function (arcsin x or sin⁻¹ x)

  • We define sin⁻¹ x as the angle whose sine is x.
  • The domain of sin⁻¹ x is [-1, 1].
  • To make sin x invertible, we restrict its domain to [-π/2, π/2].

🎙️ The inverse sine function, denoted as arcsin x or sin⁻¹ x, gives us the angle whose sine value is x. For this inverse to be a true function, we must restrict the domain of the original sine function. The standard, or principal, branch for sine is from -π/2 to π/2.

Domain and Range of sin⁻¹ x

  • Domain: [-1, 1] (This is the range of sin x).
  • Range (Principal Value Branch): [-π/2, π/2] (This is the restricted domain of sin x).
  • The output of sin⁻¹ x is always an angle in radians.

🎙️ Understanding the domain and range is absolutely critical for all inverse trigonometric functions. For sin⁻¹ x, the input 'x' must be between -1 and 1, inclusive. The output, which is the angle, will always lie between -π/2 and π/2, inclusive. This range is known as the principal value branch.

Inverse Cosine Function (arccos x or cos⁻¹ x)

  • cos⁻¹ x is the angle whose cosine is x.
  • The domain of cos⁻¹ x is [-1, 1].
  • We restrict the domain of cos x to [0, π] to define its inverse.

🎙️ Similarly, for the inverse cosine function, arccos x or cos⁻¹ x, we are looking for the angle whose cosine value is x. Again, the input 'x' must be within the range of the original cosine function, which is [-1, 1]. The restriction for the cosine function is different from sine, it's [0, π].

Domain and Range of cos⁻¹ x

  • Domain: [-1, 1] (Range of cos x).
  • Range (Principal Value Branch): [0, π] (Restricted domain of cos x).
  • The output angle is always non-negative.

🎙️ For cos⁻¹ x, the domain is also [-1, 1]. However, its principal value branch, or range, is from 0 to π. This means the angle returned by cos⁻¹ x will always be positive or zero, and never negative. Keep these ranges in mind when solving problems.

Inverse Tangent Function (arctan x or tan⁻¹ x)

  • tan⁻¹ x is the angle whose tangent is x.
  • The domain of tan⁻¹ x is all real numbers, R.
  • We restrict the domain of tan x to (-π/2, π/2) for its inverse.

🎙️ Now let's look at the inverse tangent function, arctan x or tan⁻¹ x. This function gives us the angle whose tangent is x. Unlike sine and cosine, the domain of tan⁻¹ x is all real numbers, as the range of tan x is all real numbers. The restricted domain for tan x is (-π/2, π/2), excluding the endpoints where tan x is undefined.

Domain and Range of tan⁻¹ x

  • Domain: R (Range of tan x).
  • Range (Principal Value Branch): (-π/2, π/2) (Restricted domain of tan x).
  • The output angle is strictly between -π/2 and π/2.

🎙️ For tan⁻¹ x, the input 'x' can be any real number. The output angle will always be strictly between -π/2 and π/2, never including the endpoints. This means the principal value branch for tan⁻¹ x is an open interval. Pay attention to these open versus closed intervals.

Inverse Cosecant Function (cosec⁻¹ x)

  • cosec⁻¹ x is the angle whose cosecant is x.
  • Domain: R - (-1, 1) or |x| ≥ 1.
  • Range: [-π/2, π/2] - {0}.

🎙️ Moving to the reciprocal functions, cosec⁻¹ x is the inverse of cosec x. Its domain excludes values between -1 and 1. The range is similar to sin⁻¹ x, but it excludes 0 because cosec x is undefined at 0.

Worked Example 1: Finding Principal Value

  • Find the principal value of sin⁻¹(1/√2).

🎙️ Let's work through an example. To find the principal value, we set the expression equal to 'y'. Then we recall the standard angles for which sine takes that value. The final step is to ensure that the angle we found lies within the principal value branch for sin⁻¹.

1Let y = sin⁻¹(1/√2).
2This means sin y = 1/√2.
3We know sin(π/4) = 1/√2.
4Since π/4 ∈ [-π/2, π/2], the principal value is π/4.

Worked Example 2: Finding Principal Value (Negative)

  • Find the principal value of cos⁻¹(-1/2).

🎙️ This example involves a negative value. For cos⁻¹ of a negative number, the angle will be in the second quadrant. Remember that the principal value branch for cos⁻¹ is [0, π]. So, if cos y is negative, y must be greater than π/2.

1Let y = cos⁻¹(-1/2).
2So, cos y = -1/2.
3We know cos(π/3) = 1/2. Cosine is negative in Q2.
4Therefore, y = π - π/3 = 2π/3.
5Since 2π/3 ∈ [0, π], the principal value is 2π/3.

Worked Example 3: Composite Function

  • Evaluate sin(tan⁻¹(1)).

🎙️ This type of problem involves evaluating a composite function. First, determine the value of the inner inverse trigonometric function, ensuring it's within its principal value branch. Then, use that angle to evaluate the outer trigonometric function.

1Let θ = tan⁻¹(1).
2Then tan θ = 1. The principal value is θ = π/4.
3Now we need to find sin(θ) = sin(π/4).
4sin(π/4) = 1/√2.

Properties of Inverse Trigonometric Functions - Part 1

  • sin⁻¹(sin x) = x, if x ∈ [-π/2, π/2]
  • sin(sin⁻¹ x) = x, if x ∈ [-1, 1]
  • Similar properties hold for other inverse trig functions within their specific domains/ranges.

🎙️ These are identity properties. It's crucial to note the conditions on 'x'. For example, sin⁻¹(sin x) is not always x; it is x only if x lies within the principal value branch of sin⁻¹.

Properties of Inverse Trigonometric Functions - Part 2

  • sin⁻¹ x + cos⁻¹ x = π/2, for x ∈ [-1, 1]
  • tan⁻¹ x + cot⁻¹ x = π/2, for x ∈ R
  • cosec⁻¹ x + sec⁻¹ x = π/2, for |x| ≥ 1

🎙️ These properties are very useful for simplifying expressions and solving equations. They show a complementary relationship between pairs of inverse trigonometric functions. Make sure to remember the conditions for x.

Properties of Inverse Trigonometric Functions - Part 3

  • sin⁻¹(-x) = -sin⁻¹ x
  • cos⁻¹(-x) = π - cos⁻¹ x
  • tan⁻¹(-x) = -tan⁻¹ x
  • These properties help in handling negative arguments.

🎙️ These properties are essential when dealing with negative inputs for inverse trigonometric functions. Notice the difference: sine and tangent are odd functions, while cosine behaves differently due to its principal value branch.

Worked Example 4: Using Properties

  • Simplify: sin⁻¹(1/2) + cos⁻¹(1/2).

🎙️ This example demonstrates the power of using properties. Instead of calculating each inverse function separately and then adding, we can directly apply the property to get the answer quickly. Always check if the value of 'x' falls within the valid domain for the property.

1We know the property: sin⁻¹ x + cos⁻¹ x = π/2.
2Here, x = 1/2, which is in [-1, 1].
3Therefore, sin⁻¹(1/2) + cos⁻¹(1/2) = π/2.

Common Mistakes to Avoid

  • Confusing principal value branches (e.g., using [-π/2, π/2] for cos⁻¹ x).
  • Incorrectly applying properties outside their valid domains.
  • Assuming sin⁻¹(sin x) = x for all x (it's only for restricted x).
  • Algebraic errors when manipulating expressions.

🎙️ To excel in this chapter, be mindful of these common pitfalls. The most frequent errors stem from not remembering the correct principal value branches or misapplying the properties. Always double-check the domain and range conditions.
