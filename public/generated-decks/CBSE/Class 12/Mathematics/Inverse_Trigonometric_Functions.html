Recalling Inverse Functions

  • A function f: A → B has an inverse f⁻¹: B → A.
  • For f⁻¹ to exist, f must be one-to-one (injective).
  • And f must be onto (surjective).

🎙️ Remember from Class 11 that a function needs to be both injective and surjective to have an inverse. This is a crucial foundation for ITFs.

Why Regular Trig Functions Aren't Enough

  • Trigonometric functions are periodic (many-to-one).
  • e.g., sin 0 = sin π = sin 2π = 0.
  • This means they are not one-to-one over their natural domain.

🎙️ If sin x = 0, x could be 0, π, 2π, etc. How do we define sin⁻¹(0) uniquely? We need a way to make them one-to-one.

The 'Main Path': Principal Value Branch

  • To ensure one-to-one mapping, we restrict the domain.
  • This restricted domain is called the Principal Value Branch (PVB).
  • It's the smallest interval containing 0 where the function is one-to-one.

🎙️ Think of it like choosing the most direct or 'principal' route on a map. For ITFs, we select a specific interval to get a unique output.

🎯
Focusing on the main branch

The Arcsin Function: sin⁻¹x

  • y = sin⁻¹x means x = sin y.
  • Domain: [-1, 1] (values x can take).
  • Range (PVB): [-π/2, π/2] (values y can take).

🎙️ The domain of sin⁻¹x is the range of sin x, and the range of sin⁻¹x is the restricted domain of sin x. Always remember the PVB!

Finding Principal Value of sin⁻¹(1/2)

  • Step 1: Let y = sin⁻¹(1/2). So, sin y = 1/2.
  • Step 2: We know sin(π/6) = 1/2.
  • Step 3: Since π/6 ∈ [-π/2, π/2], the PVB of sin⁻¹x.
  • Solution: y = π/6.

🎙️ Always check if your angle falls within the principal value branch. This is the most common pitfall.

Finding Principal Value of cos⁻¹(-1/√2)

  • Step 1: Let y = cos⁻¹(-1/√2). So, cos y = -1/√2.
  • Step 2: We know cos(π/4) = 1/√2.

Property Type 1: Inverse of its Own Function

  • sin⁻¹(sin x) = x, if x ∈ [-π/2, π/2].
  • cos⁻¹(cos x) = x, if x ∈ [0, π].
  • tan⁻¹(tan x) = x, if x ∈ (-π/2, π/2).

🎙️ These properties are true *only* when x lies within the principal value branch of the *inverse* function. This is a common mistake area!

Simplify sin⁻¹(sin(2π/3))

  • Step 1: Check if 2π/3 is in [-π/2, π/2]. No, it's not.
  • Step 2: Find an angle α in [-π/2, π/2] such that sin α = sin(2π/3).
  • Step 3: sin(2π/3) = sin(π - π/3) = sin(π/3).
  • Step 4: Since π/3 ∈ [-π/2, π/2], sin⁻¹(sin(2π/3)) = sin⁻¹(sin(π/3)) = π/3.

🎙️ This example highlights the importance of the domain restriction. Never simply cancel if the angle is outside the PVB.

Property Type 2: Negative Arguments

  • sin⁻¹(-x) = -sin⁻¹(x) for x ∈ [-1, 1].
  • tan⁻¹(-x) = -tan⁻¹(x) for x ∈ R.
  • cosec⁻¹(-x) = -cosec⁻¹(x) for |x| ≥ 1.

🎙️ These functions are 'odd' in nature. Their negative arguments directly translate to negative outputs.

Property Type 2: Negative Arguments (The 'Pi' Ones)

  • cos⁻¹(-x) = π - cos⁻¹(x) for x ∈ [-1, 1].
  • sec⁻¹(-x) = π - sec⁻¹(x) for |x| ≥ 1.

🎙️ These functions behave differently with negative arguments, adding π to the positive inverse. This is due to their principal value branches.

Property Type 3: Sum/Difference Identities

  • sin⁻¹x + cos⁻¹x = π/2 for x ∈ [-1, 1].
  • tan⁻¹x + cot⁻¹x = π/2 for x ∈ R.
  • sec⁻¹x + cosec⁻¹x = π/2 for |x| ≥ 1.

🎙️ These identities are very useful for simplifying expressions and solving equations. They relate complementary pairs of ITFs.

Prove tan⁻¹(1/2) + tan⁻¹(1/3) = π/4

  • Step 1: Use the identity tan⁻¹x + tan⁻¹y = tan⁻¹((x+y)/(1-xy)).
  • Step 2: Substitute x=1/2, y=1/3. Sum = tan⁻¹((1/2 + 1/3) / (1 - 1/2*1/3)).
  • Step 3: Simplify: tan⁻¹((5/6) / (1 - 1/6)) = tan⁻¹((5/6) / (5/6)) = tan⁻¹(1).
  • Step 4: We know tan⁻¹(1) = π/4. Hence Proved.

🎙️ This identity is extremely important for CBSE exams. Make sure to remember the conditions for its application (xy < 1).

Beware! Common Pitfalls in ITFs

  • Ignoring Principal Value Branch (PVB) for sin⁻¹(sin x) etc.
  • Incorrectly applying negative argument properties (e.g., cos⁻¹(-x) ≠ -cos⁻¹x).
  • Confusing domains and ranges of different ITFs.
  • Algebraic errors in simplification.

🎙️ These are the areas where students frequently lose marks. Always double-check your PVB and property applications.
