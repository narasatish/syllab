Understanding Inverse Functions

  • An inverse function 'reverses' the action of the original function.
  • If f(x) = y, then its inverse f⁻¹(y) = x.
  • Only one-to-one (injective) and onto (surjective) functions have inverses.
  • Graphically, an inverse is a reflection about the line y=x.

🎙️ Think of an inverse function as undoing what the original function did. For a function to be invertible, it must pass both the horizontal and vertical line tests, meaning it's one-to-one and onto its codomain. This ensures a unique output for every input.

Revisiting Trigonometric Functions: Domain & Range

Why Restrict Domains?

  • Trigonometric functions are periodic, meaning they repeat their values.
  • This periodicity makes them NOT one-to-one over their entire domain.
  • To define an inverse, the function must be one-to-one and onto.
  • We restrict the domain to a 'principal value branch' where they are invertible.

🎙️ Since trig functions are periodic, a single output value corresponds to infinitely many input values. To ensure a unique inverse, we must 'lock down' a specific interval of the domain where the function is one-to-one and covers its entire range. This chosen interval is crucial.

Defining Inverse Sine Function: arcsin(x)

  • Denoted as sin⁻¹(x) or arcsin(x).
  • If sin y = x, then y = sin⁻¹(x).
  • The domain of sin⁻¹(x) is the range of sin(x).
  • The range of sin⁻¹(x) is the restricted domain of sin(x).

🎙️ The inverse sine function, arcsin(x), tells us the angle 'y' whose sine is 'x'. It's important to remember that sin⁻¹(x) does not mean 1/sin(x). The domain and range swap roles compared to the original function.

arcsin(x): Domain and Principal Value Branch (Range)

  • Domain of sin⁻¹(x): [-1, 1].
  • Range (Principal Value Branch) of sin⁻¹(x): [-π/2, π/2].
  • This specific range ensures a unique output for each input 'x'.

🎙️ The input 'x' for arcsin(x) must always be between -1 and 1. The output 'y' (the angle) will always lie within the interval from -π/2 to π/2 radians, inclusive. This is the convention for the principal value.

Understanding the Principal Value Branch (PVB)

  • The PVB is the specific range chosen for each inverse trigonometric function.
  • It ensures that for every valid input, there is a unique output angle.
  • Crucial for solving problems and evaluating expressions correctly.
  • Always express your answers within this defined branch.

🎙️ The concept of the Principal Value Branch is fundamental. It's not just a definition, but a rule that dictates the correct answer when evaluating inverse trigonometric expressions. Failing to adhere to it is a common source of errors.

Worked Example 1: Principal Value of sin⁻¹(1/2)

  • Let y = sin⁻¹(1/2).
  • This implies sin y = 1/2.
  • We know sin(π/6) = 1/2.
  • Since π/6 ∈ [-π/2, π/2] (the PVB of sin⁻¹), y = π/6.

🎙️ To find the principal value, first set the expression equal to 'y'. Then, convert it into the corresponding trigonometric equation. Finally, identify the unique angle within the specified principal value branch that satisfies this equation.

Worked Example 2: Principal Value of cos⁻¹(-1/2)

  • Let y = cos⁻¹(-1/2).
  • This implies cos y = -1/2.
  • We know cos(π/3) = 1/2. Since cos(π - θ) = -cos(θ), cos(π - π/3) = cos(2π/3) = -1/2.
  • Since 2π/3 ∈ [0, π] (the PVB of cos⁻¹), y = 2π/3.

🎙️ For negative values in arccos, remember that its principal value branch is [0, π]. You'll often use quadrant rules or identities like cos(π - θ) = -cos(θ) to find the correct angle in the second quadrant.

Common Mistakes to Avoid

  • Confusing sin⁻¹(x) with (sin x)⁻¹ or 1/sin(x).
  • Not checking if the angle falls within the principal value branch.
  • Incorrectly applying properties or identities.
  • Forgetting domain restrictions for 'x' in the ITF expressions.

🎙️ Be extremely careful with notation; sin⁻¹(x) is an inverse function, not a reciprocal. Always verify that your final answer for a principal value lies within the correct branch. Incorrect application of properties is another frequent error.

Properties of Inverse Trigonometric Functions (Set 1)

  • sin⁻¹(sin x) = x, if x ∈ [-π/2, π/2].
  • cos⁻¹(cos x) = x, if x ∈ [0, π].
  • tan⁻¹(tan x) = x, if x ∈ (-π/2, π/2).
  • Similar properties exist for cosec⁻¹, sec⁻¹, and cot⁻¹.

🎙️ These properties seem straightforward, but the conditions on 'x' are absolutely vital. The output 'x' must be within the principal value branch of the *outer* inverse function for the identity to hold directly. If not, you need to simplify first.

Worked Example 3: Using Properties (sin⁻¹(sin x))

  • Evaluate sin⁻¹(sin(2π/3)).
  • Note that 2π/3 is NOT in [-π/2, π/2].
  • We know sin(2π/3) = sin(π - π/3) = sin(π/3).
  • Since π/3 ∈ [-π/2, π/2], sin⁻¹(sin(2π/3)) = sin⁻¹(sin(π/3)) = π/3.

🎙️ This example perfectly illustrates why checking the principal value branch is critical. If the given angle is outside the valid range, you must use trigonometric identities to find an equivalent angle that *does* lie within the principal value branch.

Properties of Inverse Trigonometric Functions (Set 2)

  • sin⁻¹ x + cos⁻¹ x = π/2, for x ∈ [-1, 1].
  • tan⁻¹ x + cot⁻¹ x = π/2, for x ∈ R.
  • cosec⁻¹ x + sec⁻¹ x = π/2, for |x| ≥ 1.

🎙️ These additive properties are extremely useful for simplifying complex expressions and solving equations in competitive exams. Always ensure that the value of 'x' satisfies the specified domain condition for each property to be valid.

Worked Example 4: Using Sum Properties

  • Evaluate tan⁻¹(√3) + cot⁻¹(√3).
  • Here, x = √3.
  • Since √3 ∈ R, we can directly apply the property tan⁻¹ x + cot⁻¹ x = π/2.
  • Therefore, tan⁻¹(√3) + cot⁻¹(√3) = π/2.

🎙️ This example demonstrates a direct application of one of the sum properties. Once you correctly identify the property and verify that the input 'x' falls within its valid domain, the solution is immediate and simplifies calculations significantly.
