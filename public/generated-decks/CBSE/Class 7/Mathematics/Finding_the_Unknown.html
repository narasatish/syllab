What is an Unknown?

  • An unknown is a quantity whose value is not given.
  • It's like a mystery number we need to discover.
  • It could be a missing age, price, or quantity.

🎙️ An unknown is simply a value that we don't know yet. Imagine you have some chocolates, but you don't know the exact number. That number is your unknown. Our goal is to find out what that unknown value is.

Introducing Variables

  • A variable is a symbol representing an unknown value.
  • Usually denoted by letters like x, y, z, a, b.
  • It can take on different numerical values.

🎙️ In mathematics, we use variables to stand in for our unknowns. Instead of writing 'the missing number', we use a letter like 'x'. This makes our mathematical expressions much cleaner and easier to work with. These letters are like placeholders for the numbers we want to find.

What is an Equation?

  • An equation is a statement that two expressions are equal.
  • It always contains an equality sign (=).
  • Example: x + 5 = 10.

🎙️ An equation is like a balanced scale. Whatever is on one side must be equal in value to what is on the other side. The equals sign is crucial, indicating that both sides hold the same value. Our goal is to keep this balance while finding the unknown.

Components of an Equation

  • Left Hand Side (L.H.S.): Expression to the left of '='.
  • Right Hand Side (R.H.S.): Expression to the right of '='.
  • Equality Sign (=): Shows that LHS and RHS are equal.

🎙️ Every equation has these three main parts. Think of the equality sign as the pivot point of our balance scale. The expressions on the left and right are the weights on each pan. For the scale to be balanced, the weights on both sides must be exactly the same.

Worked Example 1: Age Problem

  • Problem: 'My father is 35 years old. He is 10 years older than my mother. How old is my mother?'
  • Let mother's age be 'm'.
  • Equation: m + 10 = 35.

🎙️ Here's how we'd set up the equation for the age problem. We identified the unknown as the mother's age and assigned it the variable 'm'. Since the father is 10 years older, adding 10 to the mother's age gives the father's age, which is 35. So, m + 10 = 35.

Solving Equations: The Goal

  • To find the value of the unknown variable.
  • We need to 'isolate' the variable.
  • This means getting the variable by itself on one side of the equation.

🎙️ The ultimate goal when solving an equation is to figure out what number our variable stands for. We want to get 'x = some number' or 'y = some number'. To achieve this, we use various methods to move all other numbers away from the variable, leaving it 'isolated'.

Method 1: Trial and Error

  • Substitute different values for the variable.
  • Check if the LHS equals the RHS.
  • Simple for very basic equations, but not efficient.

🎙️ The trial and error method is like guessing and checking. You pick a number, put it into the equation, and see if it works. If not, you try another number. While it can work for very simple equations, it's not practical for more complex ones, as it can be time-consuming.

Worked Example 2: Trial and Error

  • Solve: x + 3 = 7
  • Try x = 1: 1 + 3 = 4 (Not 7)
  • Try x = 2: 2 + 3 = 5 (Not 7)
  • Try x = 4: 4 + 3 = 7 (Correct!) So, x = 4.

🎙️ Let's see trial and error in action. For x + 3 = 7, if we try x=1, it doesn't work. If we try x=2, still no. But when we try x=4, we get 4+3=7, which matches the RHS. So, x=4 is the solution. You can see how this might take a few tries.

Method 2: Systematic Method (Balancing)

  • Maintain the equality of the equation.
  • Perform the same operation on BOTH sides of the equation.
  • This keeps the 'balance' intact.

🎙️ The systematic method is much more powerful and efficient. It's based on the idea of maintaining balance. Whatever you do to one side of the equation, you must do to the other side. This ensures the equality remains true and helps us isolate the variable step-by-step.

Balancing Equations: Addition/Subtraction

  • To remove a number added to the variable, subtract it from both sides.
  • To remove a number subtracted from the variable, add it to both sides.
  • Inverse operations cancel each other out.

🎙️ If you have 'x + 5', to get 'x' alone, you subtract 5. To keep the equation balanced, you must subtract 5 from the other side too. Similarly, if you have 'x - 3', you add 3 to both sides. These are inverse operations that undo each other, helping us isolate the variable.

Inverse Operations

Worked Example 3: Addition

  • Solve: x + 5 = 12
  • Subtract 5 from both sides:
  • x + 5 - 5 = 12 - 5
  • x = 7

🎙️ Here's an example: x + 5 = 12. To get x by itself, we need to remove the '+5'. The inverse operation is '-5'. So, we subtract 5 from the LHS. To maintain balance, we also subtract 5 from the RHS. This gives us x = 7.

16 / 25

Worked Example 4: Subtraction

  • Solve: y - 3 = 7
  • Add 3 to both sides:
  • y - 3 + 3 = 7 + 3
  • y = 10

🎙️ Now, let's look at y - 3 = 7. Here, 3 is being subtracted from y. To undo this, we perform the inverse operation: addition. We add 3 to the LHS, which cancels out the -3. Remember to add 3 to the RHS as well, leading to y = 10.

Balancing Equations: Multiplication/Division

  • To remove a number multiplying the variable, divide both sides by it.
  • To remove a number dividing the variable, multiply both sides by it.
  • These are also inverse operations.

🎙️ The same principle of inverse operations applies to multiplication and division. If a variable is multiplied by a number, we divide both sides by that number. If a variable is divided by a number, we multiply both sides by that number. This keeps the equation balanced and helps us solve for the unknown.

Worked Example 5: Multiplication

  • Solve: 3x = 15
  • Divide both sides by 3:
  • 3x / 3 = 15 / 3
  • x = 5

🎙️ Consider the equation 3x = 15. Here, '3x' means 3 multiplied by x. To isolate x, we perform the inverse operation: division. We divide both sides of the equation by 3. This cancels out the 3 on the LHS and gives us x = 5.

Worked Example 6: Division

  • Solve: x / 4 = 5
  • Multiply both sides by 4:
  • (x / 4) * 4 = 5 * 4
  • x = 20

🎙️ For x / 4 = 5, x is being divided by 4. To undo this, we multiply both sides by 4. This cancels out the division by 4 on the LHS. Multiplying the RHS by 4 gives us 20. So, the solution is x = 20.

Combining Operations

  • Some equations involve both addition/subtraction AND multiplication/division.
  • Always address addition/subtraction first.
  • Then, deal with multiplication/division.

🎙️ When an equation has multiple operations, we usually work backwards from the order of operations. First, we remove any numbers that are added to or subtracted from the variable term. After that, we tackle the numbers that are multiplying or dividing the variable. This systematic approach ensures we solve it correctly.

Worked Example 7: Two-step Equation

  • Solve: 2x + 3 = 11
  • Step 1: Subtract 3 from both sides: 2x + 3 - 3 = 11 - 3 => 2x = 8
  • Step 2: Divide both sides by 2: 2x / 2 = 8 / 2 => x = 4

🎙️ Let's solve 2x + 3 = 11. First, we remove the '+3' by subtracting 3 from both sides, leaving us with 2x = 8. Next, to isolate x from '2x', we divide both sides by 2. This gives us our final answer, x = 4.

Recap: Finding the Unknown

  • Unknowns are represented by variables.
  • Equations show equality between expressions.
  • Use the systematic (balancing) method to solve.
  • Perform inverse operations on both sides to isolate the variable.
