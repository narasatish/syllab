What is an Equation?

  • A statement that two expressions are equal.
  • Contains an equality sign (=).
  • Helps us find the unknown.

🎙️ An equation is like a balanced scale. It says that whatever is on one side is exactly equal to what's on the other side. The equals sign is the crucial part that tells us these two sides are balanced.

Anatomy of an Equation

  • Left Hand Side (LHS): Expression on the left of '='.
  • Right Hand Side (RHS): Expression on the right of '='.
  • Equality Sign (=): Shows balance.

🎙️ Every equation has a Left Hand Side (LHS) and a Right Hand Side (RHS), separated by the equality sign. The goal is always to maintain this balance while we try to figure out the value of our unknown.

Equation in Action: Balancing Weights

  • Imagine a scale: LHS = RHS.
  • If you add 2kg on one side, you must add 2kg on the other.
  • This keeps the scale balanced.

🎙️ Think of a traditional weighing scale. If you put 3 kg on the left pan and 3 kg on the right pan, the scale is balanced. If you add or remove weight from one side, you must do the exact same thing on the other side to keep it balanced.

How to Form Simple Equations

  • 1. Identify the unknown and represent it with a variable.
  • 2. Read the problem carefully to find relationships.

🎙️ Forming an equation from a word problem is a crucial skill. First, decide what quantity you don't know and give it a letter. Then, look for keywords that describe how different quantities relate to each other, like 'sum,' 'difference,' 'product,' or 'quotient.'

Worked Example: Forming an Equation

  • Problem: 'The sum of a number and 5 is 12.'
  • Let the number be 'x'.
  • Equation: x + 5 = 12.

🎙️ Here's a simple example. We don't know the number, so we call it 'x'. The problem says 'the sum of a number and 5,' which means x + 5. And it says this sum 'is 12,' so we set it equal to 12.

Solving Equations: What's the Goal?

  • To find the value of the unknown variable.
  • We want the variable to be alone on one side.
  • This is called isolating the variable.

🎙️ When we solve an equation, our main objective is to figure out what number the variable stands for. We want to get the variable all by itself on one side of the equals sign, like 'x = 7' or 'y = 3'. This process is called isolating the variable.

Method 1: Trial and Error

  • Guess a value for the variable.
  • Substitute it into the equation.
  • Check if LHS = RHS.

🎙️ The trial and error method is exactly what it sounds like: you guess a value for the unknown, put it into the equation, and see if it works. If it doesn't, you try another value. It can be time-consuming but helps understand the concept of a solution.

🎲
Guess & Check

Trial and Error Example

  • Equation: x + 3 = 7.
  • Try x = 1: 1 + 3 = 4 (Not 7).
  • Try x = 4: 4 + 3 = 7 (Correct!). So x = 4.

🎙️ Let's try it with x + 3 = 7. If we guess x=1, 1+3=4, which is not 7. If we guess x=2, 2+3=5, still not 7. But if we guess x=4, then 4+3=7, which is correct! So, 4 is the solution.

Method 2: The Balancing Method

  • Perform the same operation on both sides of the equation.
  • This maintains the balance.
  • Uses inverse operations to isolate the variable.

🎙️ The balancing method is more systematic and efficient. The key idea is that whatever you do to one side of the equation, you must do to the other side to keep it equal. We use inverse operations to undo what's being done to our variable.

⚖️
Keep it Balanced
14 / 25

Balancing: Addition & Subtraction

  • To remove a number added, subtract it from both sides.
  • To remove a number subtracted, add it to both sides.
  • Example: x + 5 = 10 (Subtract 5 from both sides).

🎙️ If you have 'x + 5 = 10', to get 'x' alone, you need to get rid of the '+5'. The inverse operation of addition is subtraction, so you subtract 5 from both sides. Similarly, if you have 'x - 3 = 7', you would add 3 to both sides.

Balancing: Multiplication & Division

  • To remove a number multiplying, divide both sides by it.
  • To remove a number dividing, multiply both sides by it.
  • Example: 2x = 8 (Divide both sides by 2).

🎙️ If you have '2x = 8', meaning 2 multiplied by x, to isolate 'x', you perform the inverse operation: division. So, you divide both sides by 2. If you have 'x/3 = 4', you would multiply both sides by 3.

Worked Example: Solving (Addition/Subtraction)

  • Solve: y - 7 = 15.
  • Add 7 to both sides: y - 7 + 7 = 15 + 7.
  • Result: y = 22.

🎙️ Let's solve 'y - 7 = 15'. To get 'y' by itself, we need to undo the '-7'. The inverse operation is '+7'. So, we add 7 to both sides of the equation. This gives us 'y = 22'.

Worked Example: Solving (Multiplication/Division)

  • Solve: 3p = 21.
  • Divide both sides by 3: 3p / 3 = 21 / 3.
  • Result: p = 7.

🎙️ Now, let's solve '3p = 21'. Here, 'p' is being multiplied by 3. To isolate 'p', we perform the inverse operation: division. We divide both sides by 3, which gives us 'p = 7'.

Worked Example: Age Problem

  • Problem: 'Rohan is 5 years older than his sister. If Rohan is 17, how old is his sister?'
  • Let sister's age be 's'.
  • Equation: s + 5 = 17. Solving: s = 17 - 5 = 12. Sister is 12 years old.

🎙️ Here, the unknown is the sister's age, so let's call it 's'. We know Rohan is 5 years older, so 's + 5' represents Rohan's age. Since Rohan is 17, we set 's + 5 = 17'. Subtracting 5 from both sides gives us 's = 12'.
