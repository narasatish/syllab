Adding Integers: Same Signs

  • Rule: Add their absolute values.
  • Keep the common sign.
  • Example: (+3) + (+2) = +5

🎙️ When you add two positive integers, you just add them normally and the result is positive. Similarly, if you add two negative integers, you add their numerical values and the result will be negative. It's like adding two debts together – you get a bigger debt.

4Reach +5

Example: Adding Same Signs

  • Problem 1: (+7) + (+4)
  • Solution: 7 + 4 = 11, so +11
  • Problem 2: (-5) + (-3)
  • Solution: 5 + 3 = 8, so -8

🎙️ Let's try these. For (+7) + (+4), both are positive, so we simply add 7 and 4 to get 11. For (-5) + (-3), both are negative. We add 5 and 3 to get 8, and since both are negative, the answer is -8.

Adding Integers: Different Signs

  • Rule: Subtract the smaller absolute value from the larger.
  • Keep the sign of the integer with the larger absolute value.
  • Example: (+5) + (-2) = +3

🎙️ This is like a tug-of-war! If you have a positive and a negative number, they 'cancel out' parts of each other. You find the difference between their numerical values, and the sign of the bigger number wins.

Example: Adding Different Signs

  • Problem 1: (+8) + (-3)
  • Solution: 8 - 3 = 5, larger is 8 (positive), so +5
  • Problem 2: (-10) + (+4)
  • Solution: 10 - 4 = 6, larger is 10 (negative), so -6

🎙️ In (+8) + (-3), the positive 'pulls' more. So, 8 minus 3 is 5, and it's positive. In (-10) + (+4), the negative 'pulls' more. So, 10 minus 4 is 6, and it's negative. Remember, the sign of the number with the greater magnitude determines the sign of the sum.

Subtracting Integers: The Inverse

  • Rule: Change subtraction to addition.
  • Change the sign of the second integer (its additive inverse).
  • Then, follow addition rules.

🎙️ Subtracting an integer is the same as adding its opposite. This is a very important trick! For example, subtracting 5 is the same as adding -5. And subtracting -5 is the same as adding +5. This converts every subtraction problem into an addition problem.

🎙️ Imagine you're walking. Walking 5 steps forward is +5. If someone tells you to 'subtract walking forward 5 steps', it means you should walk 5 steps backward! So, subtracting a positive is like adding a negative. It's a reversal of action.

Multiplying Integers: Same Signs

  • (+) x (+) = (+)
  • (-) x (-) = (+)

🎙️ When multiplying integers, if both numbers have the same sign – both positive or both negative – the result is always positive. Think of it as a happy outcome when things are aligned!

Dividing Integers: Same Rules as Multiplication

  • Rule: The sign rules are identical to multiplication.
  • Same signs (e.g., + ÷ + or - ÷ -) result in a positive quotient.
  • Different signs (e.g., + ÷ - or - ÷ +) result in a negative quotient.

🎙️ Good news! The rules for dividing integers are exactly the same as for multiplying integers. Just divide the numerical values, and then apply the same sign rules. This makes it much easier to remember!

Properties of Integers: Closure

  • An operation is 'closed' if the result is always an integer.
  • Addition: Yes (e.g., 2 + 3 = 5)
  • Subtraction: Yes (e.g., 2 - 3 = -1)
  • Multiplication: Yes (e.g., 2 x 3 = 6)

🎙️ The property of closure means that when you perform an operation on two integers, the answer will always be another integer. Integers are closed under addition, subtraction, and multiplication. This is like saying if you start with integers, you'll always end up with an integer for these operations.

Properties of Integers: Commutativity

  • Order doesn't matter for the result.
  • Addition: Yes (a + b = b + a)
  • Multiplication: Yes (a x b = b x a)
  • Subtraction & Division: No (e.g., 5 - 3 ≠ 3 - 5)

🎙️ Commutativity means you can swap the order of the numbers and still get the same answer. It works for addition and multiplication of integers. But be careful, it does NOT work for subtraction or division!

Properties of Integers: Associativity

  • Grouping doesn't matter for the result (for 3+ numbers).
  • Addition: Yes (a + (b + c) = (a + b) + c)
  • Multiplication: Yes (a x (b x c) = (a x b) x c)
  • Subtraction & Division: No

🎙️ Associativity applies when you have three or more numbers. It means you can group them differently using parentheses, and the final result will be the same. This also works for addition and multiplication, but not for subtraction or division.

Properties of Integers: Distributivity

  • Multiplication distributes over addition/subtraction.
  • a x (b + c) = (a x b) + (a x c)
  • a x (b - c) = (a x b) - (a x c)

🎙️ The distributive property is very useful! It tells us how multiplication interacts with addition or subtraction. You can 'distribute' the multiplication to each term inside the parentheses. This helps simplify expressions.

Common Mistakes to Avoid!

  • Sign Errors: Forgetting to change sign during subtraction.
  • Mixing up rules: Applying addition rules to multiplication.
  • Order of Operations: Not following BODMAS/PEMDAS.

🎙️ Many students make these common errors. Always double-check your signs, especially when subtracting. Remember that addition/subtraction rules are different from multiplication/division rules. And always follow the correct order of operations!
