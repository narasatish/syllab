# Private, signed-in areas: only the bare /profile and /parent are real
# routes. Fixed 2026-09-14: the wildcard rewrites (/profile/**, /parent/**
# -> /index.html) were removed from firebase.json, since the app never uses
# a path segment under either — so any invented sub-path now gets Firebase's
# real 404 instead of 200 + the homepage document. That closes the duplicate
# factory: a crawler minting /profile/<anything> now hits a 404 it can act on
# immediately, rather than a 200 it has to fetch, classify, and eventually
# reclassify as noindex. The 2026-08-14 fix (serve noindex, allow the crawl)
# was a genuine improvement over the original Disallow, but "Duplicate without
# user-selected canonical" moved only 1,291 -> 1,283 in three weeks — a 404
# is a stronger, faster signal than noindex ever was, so no crawl allowance
# is needed here any more.
